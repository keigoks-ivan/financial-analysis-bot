雙軌投資流程

70% 指數軌（機械訊號）＋ 30% 個股軌（判斷選股）＋ 8~10% 現金。兩軌各自獨立、不交叉污染，共用一層「市場情境」——情境層只餵個股軌的質性判斷，絕不干預指數軌的機械訊號。本頁把全站工具串成一條可執行的路徑，每個工具名皆可直達；每日晨檢、每週定位的讀法與頁面速查表在後段。
投資流程 實單主系統 選股主控台 市場監測 量化回測

總架構：兩軌 ＋ 現金 ＋ 共用情境層

資金先切三塊，兩條投資軌用完全不同的決策模式，互不干涉。

指數軌

70%
純機械。唯一訊號源＝W52 × 自適應波動率實單主系統（52 週線動能規則，美 QQQ+SMH／台 0050+2330）。不憑盤面操作、不預測、不手動干預，只執行 email 訊號。

個股軌

30%
純判斷。想法 → 漏斗 → 深度研究 → 三錨裁決 → 席位制進場 → 監控 → 歸帳（下方七步）。質性、逐案、有容量上限。現階段母體與席位只涵蓋美股（含 ADR），台股尚未併入，是刻意分開建置的獨立系統。

現金

8~10%
另計的乾火藥。用於個股軌機會與再平衡緩衝，不併入兩軌績效計算。
共用市場情境層（只讀、不驅動指數軌）：市場監測、大類資產 regime、產業輪動、擁擠交易監測——這層是給個股軌的質性背景（該加減哪個主題、哪裡太擠）；指數軌完全無視這層，只認自己的機械訊號，避免「看法污染系統」。

指數軌 · 五步機械

整條軌只有一個訊號源、一組執行規則、一條禁止手動干預的鐵律。無信 ＝ 不動作。
  1. 唯一訊號源 ＝ W52 × 自適應波動率實單主系統
    2026-10-19 起美股為債金版、台股為不借錢版，股票部分曝險上限 100%、email 驅動。每交易日台股／美股收盤後自動檢查，只有可行動變化才寄信（任一腿目標與現持差 ≥ 20pp、現持高於新上限，或美股公債、黃金的成立條件數有變動）。沒收到信＝不動作。
  2. 執行
    股票部分（QQQ/SMH／0050/2330）上限 100%，不借錢放大股票曝險。美股另有公債、黃金兩條疊加腿：週線三個條件每成立一條，該腿加三分之一，各最多 20%，疊加時股票曝險不減少。期貨口數與名目換算用 期貨部位計算機。
  3. 禁止手動干預條款
    不因新聞／盤感／回撤而提前加減碼；不覆寫閘門；不「這次不一樣」。系統的價值來自紀律地執行機械訊號，任何手動 override 都是在破壞回測所依據的規則。
  4. 回顧點（非前置關卡）
    2026-10-19 起滿 60 個追蹤交易日或首次 ≥ 10% 組合回撤時回顧一次：實單（美股債金版、台股不借錢版）對照 舊規則 cap 1.5 對照線，確認水下體驗與回測分布一致；背離才按 charter 調整。
  5. 股票以外的資產
    2026-10-19 起，美股實單另含公債（IEF）與黃金（GLD）兩腿，各最多 20%，各看週線三個條件，同樣是機械訊號、不手動干預。原本紙上追蹤的商品 Sleeve 與 GLD 金 sleeve 已於 2026-10-18 歸檔，見系統主控台歸檔區。

個股軌 · 七步漏斗判斷

想法很多、席位很少。用漏斗收斂、用容量控制排隊、用三個獨立錨點裁決，買的那天就定義好賣的條件。
  1. 想法四路
    四條進料管道並行——
    品質路：DD Screener 品質進場、Momentum-5、P10 價格動能、個股階段雷達
    主題路：產業輪動 ＋ 產業深度 ID
    事件路：偵測警報網 ＋ 催化劑日曆
    財報路：財報分析
  2. 漏斗收斂 ＋ 席位制容量控制
    所有想法進 選股主控台 收斂排序，出手前過三關：資格閘（品質、三年成長 15%、市值、站上 52 週線；耐久只是旗標，不擋資格）→ 池（財報後 EPS 上修 ≥5%，池內依上修幅度排序）→ 核心席（池內時機燈亮著的名字取前 5，每週六依週五收盤重算，亮燈不足就空席）。個股 DD 在這一層只做否決（迴避的名字踢出候選）與角色標籤，不主導排序分數。席位有限，而且是觸發不是排名——新想法必須贏過現有席位才擠得進來，沒亮燈就空席，不硬填；精選榜是席位規格外的另一個獵場（爆發型／十倍股候選），一樣只回答「看誰」不回答「買不買」。
  3. 深度研究
    留下的候選做深度盡調：研究清單先找到該檔有哪些 DD；單一代號的完整頁是個股儀表板（網址 /stock-dash/?t=代號），一頁看投資摘要、獲利預估、估值、護城河、價格與風險，最後一章列出本站對該檔的研究；產業面查產業深度 ID與供應鏈地圖。
  4. 裁決三錨（三錨不同意 ＝ 不進場）
    蒙格獨立裁決外部裁判，讀語料＋DD 獨立對質
    ID 冷審產業 ID 冷讀 checklist，論點是否仍成立
    帳本實績裁決實績，過往同類判斷的實際命中率
    三個錨點互相獨立、任一否決即不進場——避免單一視角過度自信。
  5. 席位制進場
    買的那天就定義賣的條件：進場即寫下否證指標（論點被推翻的量化門檻）並存進 DD，之後由監控層盯這些門檻。
  6. 自動監控
    持倉週掃（每週掃全持倉的否證指標與論點老化）、否證指標對帳表、偵測警報網、催化劑鏈——被動抓到人眼會漏掉的沉默衰退。
  7. 出場歸帳
    出場後歸帳進 裁決實績，餵回正向循環——每次判斷的對錯都留痕，讓下一輪裁決三錨的「帳本實績」更準。

節奏表

每天固定花 10 分鐘讀盤面，大部分日子不動作。固定節奏把「該看什麼、什麼時候看」寫死，避免盤感驅動。
頻率時間盒做什麼
每日（開盤前）~ 10 分晨檢：先開首頁讀「市場現況」，30 秒定調。讀數異常，或跨資產壓力與警戒度分歧時，開市況主控台；要看當日機械層明細才開情報監視器。接著開輪動雷達，切 20 日看短線資金流向，再切 120 日確認是趨勢。最後處理 email，共四種信：①指數軌可行動變化（目標與現持差 ≥20pp／美股債金條件數變動）②偵測警報③催化劑觸發 ④持倉否證指標破線。沒有信就不動作。各頁怎麼讀見下方「晨檢與週會怎麼讀」。
每週六早~ 30 分財報分析掃下週 EPS ＋ 總經行事曆，標記要盯的事件。另看「每週選股結果」email（週六 11:00 寄）：核心席已依週五收盤算好，換席與原因都在信裡。
週日晚／週一早~ 60 分週會：regime → crowding → rotation 各過一遍；手上有想深入的主題，再讀總經深度報告 → 選股主控台（核對週六席位與燈號） → 持倉週掃報告 → 掃 RSS，看本週新上架的報告 → 定本週動作。
每月（2 號後）~ 20 分EPS 快照更新，對照持倉論點的財務假設是否還成立。
每季事件觸發指數軌回顧點（若滿 60 日或 ≥10% 回撤）、ID staleness 重審、出場歸帳、裁決三錨對帳。
節奏的重點是把「不作為」變成預設：指數軌無信不動、個股軌無席位不加、核心席沒亮燈就空著，都屬於「不作為」預設，週會才是唯一主動決策的窗口。

晨檢與週會怎麼讀

上面講看哪些頁，這裡講看到什麼算異常。一律以當日頁面為準，本節不放當天的數字。
首頁市場現況：先看跨資產壓力與警戒度是同向還是分歧。跨資產壓力是多條序列的滾動百分位，反映市場現在多緊繃；警戒度把偵測層「有東西在壞」的訊號（股市重挫、信用變差、波動升高這類）加總成 0 到 100 分，亮紅燈的訊號越多分數越高。兩者同向偏高，值得點進市況主控台，但同向不等於兩個獨立確認。分歧才是重點：壓力低而警戒度高，是異常先於壓力出現；壓力高而警戒度低，代表已經身處高壓環境。兩者都在平靜區間，才算平靜。
市況主控台：看「主要力量」與「傳導與內部訊號」是否指向同一個方向，「部位與流量」是否偏擁擠，以及「什麼會改變這個判讀」列出的條件有沒有接近。判讀與機械數字不一致時，頁面會直接寫出來，那是要注意的訊號。
情報監視器：壓力與警戒度同向、又都在安全區時，看完首頁和市況主控台就夠，不必每天單獨巡這頁。要看當日機械層的完整明細，或某條警報今天為什麼觸發，才開。
輪動雷達：20 日框架看短線資金流向，120 日框架確認那是趨勢延續還是單週雜訊。兩個框架同向才算數；只有一個亮，不必動作。
週會四頁：regime 看大類資產目前的定位，擁擠交易監測看誰太擠、解除擁擠的觸發條件有沒有亮，產業輪動看站內產業主題誰在加速，總經深度報告在有想深入的主題時才讀。四頁都是描述器，衡量部位集中度、下方緩衝，或政策與流動性的傳導；不預測轉折時點，也不給買賣指令。用途是體檢持倉對環境是順風還是逆風。

本站的邊界

先講清楚這個站不做什麼。
描述器，不擇時：市況主控台、市場監測、擁擠交易監測、總經深度報告衡量的是部位集中度、下方緩衝、放大回撤與相關性，以及政策與流動性的傳導。它們不給進出場時點，也不給部位大小，執行是持有人自己的責任。
名單只回答看誰：席位名單、精選榜、DD Screener 各層的態度常常不一致，這是分工。多層同時亮的名字是高信心觀察池，先看；各層意見分歧的名字是研究隊列，要去查原因。「值得投資」的判定不歸任何一份名單，一律走個股 DD 的統一裁決（進場／觀望／迴避），再過裁決三錨。
實績還短：裁決實績從 2026-03 開始累積，樣本年輕。它能說明裁決的品質有沒有在進步，不能當成可以外推的期望值。
一句話：市場層每天掃，產業層按需查，個股研究當第二意見，心智模型在下單前逐項檢查，裁決實績用來檢驗判斷。
