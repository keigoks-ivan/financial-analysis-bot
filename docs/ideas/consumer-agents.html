消費級代理人：AI 開始替人上網，需求從 GPU 擴散到 CPU、記憶體和身分驗證

建立 2026-09-23·追蹤中·早報新證據：讀取中
Meta 的 Muse 讓 AI 代替人訂位、比價、下單。每個用戶一台常駐雲端電腦，需求從 GPU 擴散到 CPU、記憶體和硬碟；網站也必須分辨人和代理人，多出一層身分驗證的生意。

一頁摘要

  • Muse 9 月 8 日上線，不到兩週下載超過 250 萬，iPhone 每日活躍用戶 35.9 萬。
  • 每個用戶配一台獨立雲端電腦，關掉 App 工作還在跑。
  • 一次行程比價，有用戶實例跑了 146 次搜尋；大部分工作在 CPU 上執行。
  • CPU:GPU 4:1～40:1 是外部估計，不是 Meta 公布的數字，不拿來算獲利。
  • Nvidia 的 Vera 機櫃每顆 CPU 平均跑 88 個代理人環境，每個用戶用掉的資源會被壓縮。
  • 記憶體和硬碟比 CPU 更吃緊：CPU 可以輪流用，每個用戶的登入狀態和資料要一直留著。
  • 網站分成兩派：Amazon 擋下 Muse，Shopify、PayPal 直接接進結帳。
  • Cloudflare 已經讓代理人用數位簽名表明身分，但這是公開標準，AWS 也支援。
  • 最該盯的是每日活躍用戶，不是下載量。

五個判斷

1. 40:1 不能直接比，方向是對的

市場熟悉的 1:2、1:4，是 GPU 伺服器裡面 CPU 和 GPU 的顆數比。Muse 用的 CPU 大多在另一批專門跑用戶雲端電腦的一般伺服器上，兩個比例量的東西不同。

比較準的算法是看用戶數。Wccftech 用每人 2 顆虛擬 CPU、8GB 記憶體、100GB 硬碟估算，1 億用戶、10% 同時在線，大約要 16 萬顆 AMD EPYC。CPU 需求跟著使用人數走，模型降價影響不大。

2. 每人用掉的資源會被壓縮

拿用戶數乘上規格去算市場大小，會高估很多。Nvidia 的 Vera 機櫃 256 顆 CPU 同時跑超過 22,500 個環境，平均一顆 88 個。業界從設計階段就在做共用和壓縮。

Intel 執行長說目前產能只能滿足約一半需求，缺貨會讓 Meta 更有動機把每人一台虛擬機改成多人共用。這是 CPU 論點最大的變數。

3. 記憶體和硬碟比 CPU 更被低估

代理人要記住登入狀態、購物車、郵件、做到哪一步。CPU 可以輪流給在線的人用，這些資料卻要一直留著。1 億用戶在理想情況下要 800 PB 記憶體、10,000 PB 硬碟，實際會因休眠和共用打折，方向不會變。

4. 網站會分成擋和開兩派

Amazon 擋，因為代理人不看廣告，還會進到用戶帳戶。Shopify、PayPal 開，因為代理人能直接帶來訂單。兩派最後都需要同一套東西：確認這是誰的代理人、誰授權的、能做什麼、出事誰負責。

5. Cloudflare 位置最好，但不是唯一一家

Cloudflare 已經讓代理人用數位簽名（Web Bot Auth）表明身分，網站可以設定簽過名的放行、沒簽的擋下。它的優勢是流經它的網站流量大。

這套簽名是公開標準，AWS 的代理人服務也支援。大商家像 Amazon 會自己擋，Cloudflare 主要吃中小網站。營收要等財報提到機器人管理加速才算看到。

什麼情況收回這個想法

  • 這個想法建立在用戶真的每天用。若 Muse 每日活躍用戶連續兩個月下滑，收回。
  • CPU 那一段建立在每人一台常駐雲端電腦。若 Meta 改成多人共用、或公布每人資源大幅下降，CPU 論點降一級。
  • 身分驗證那一段建立在網站需要分辨代理人。若多數大商家不設任何條件直接開放，這一段收回。
  • 若監管機關限制消費級代理人代替用戶登入或付款，整體重新評估。
