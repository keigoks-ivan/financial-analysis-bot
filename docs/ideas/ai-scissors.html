AI 剪刀差：token 越來越便宜，算力、電力、記憶體越來越貴

建立 2026-09-23·追蹤中·早報新證據：讀取中
OpenAI 和 Anthropic 同一天把模型價格降了 20–50%，但 GPU 租金、伺服器 CPU、記憶體和發電設備同時在漲價。利潤會往交期最長、又不用背債的供應商集中。

一頁摘要

  • 9 月 22 日 OpenAI 和 Anthropic 同一天降價：GPT-6 Sol 比前代便宜 50%，Opus 5.5 單價降 20%。
  • 同一週 Nebius 宣布 10 月 1 日起 GPU 租金漲 17–21%，三個月內第二次漲。
  • Opus 5.5 省的 40% 裡，有一部分來自每個任務少用 token，這部分會減少算力需求。
  • CoreWeave 新簽的高價約是 3–6 個月的短約，長約有沒有跟漲還沒看到。
  • 代理人（agent）大量用 CPU 跑工具和程式，伺服器 CPU 從 3 月以來漲了 10–20%。
  • 今天下單的大型燃氣渦輪要 2031 年才交貨，是整條鏈上交期最長的一段。
  • HBM 現貨價是長約價的 4–5 倍，長約一年談一次，2027 年新約才會反映。
  • 台積電 CoWoS 產能 2028 年底要翻倍，屆時 GPU 不再那麼缺，雲廠的漲價空間會縮小。
  • 最該盯的是 AI 營收。營收等於用量乘單價，降價後營收還在長，就代表用量成長跑贏降價。

四個判斷

1. 降價只有一部分會變成新需求

Opus 5.5 的 40% 可以拆成兩塊。單價降 20%，這一塊會刺激用量。剩下來自每個任務用的 token 變少，做同一件事需要的算力也跟著變少。

所以 token 降價對算力需求的推升，比表面數字小。真正要看的是總用量：Google 5 月每月處理 3.2 千兆（quadrillion）個 token，年增 7 倍；OpenRouter 9 月每天超過 10 兆個。只要總用量每年成長幾倍，單價腰斬也吸收得掉。

2. GPU 雲的高租金目前只簽在短約

CoreWeave 每 MW 年化 4,000 萬美元的新約是 3–6 個月。客戶願意付高價，代表現在很缺。但短約到期就重新議價，這個價格沒有鎖住。

另一個壓力在 2027–28 年。台積電 CoWoS（把 GPU 和 HBM 封在一起的先進封裝）產能預計從 2026 年底每月 13 萬片，增加到 2028 年底 26 萬片。GPU 供給翻倍之後，Nebius、CoreWeave 的漲價空間會縮小。

3. 交期越長的環節，漲價撐得越久

GPU 可以加產，HBM 可以擴廠，一座燃氣電廠卻要等渦輪五年。GE Vernova 的大型渦輪排到 2031 年，Siemens Energy 燃氣服務部門的訂單出貨比 2.65 倍。Oracle Jupiter 延宕 7 個月，也是卡在許可和電力。

記憶體的時間差不同。HBM 長約一年談一次，現貨已經是長約的 4–5 倍，2027 年新約談下來時，營收才會一次反映。

4. 缺電對賣設備的人有利，對背債蓋廠的人不利

Oracle Jupiter 貸款跌到 89–91，Nscale 上半年虧 10.2 億美元、一個客戶佔一半營收。蓋資料中心要先借錢，電力和設備又越來越貴、越來越慢，蓋的人承擔了延宕和利率的風險。

賣渦輪、變壓器、記憶體的公司拿的是訂單和預付款，不承擔這些風險。這是這個想法裡把供應商排在雲廠前面的原因。

對 CPU 業者的影響

代理人工作時要搜尋、跑 Python、開瀏覽器、查資料庫，這些大多在 CPU 和一般記憶體上跑。Nebius 這次純 CPU 機器漲 25%、記憶體漲 41%，漲幅都比 GPU 大。伺服器 CPU 從 3 月以來漲了 10–20%，KeyBanc 說 Intel 和 AMD 2026 年的伺服器 CPU 都已賣完。

公司受惠方式限制
AMD第二季伺服器 CPU 營收年增超過 70%；由台積電代工，產能擴得動，量和價都吃得到估值反映多少要看個股報告
Intel能漲價Intel 7 產能不足，公司表示不擴舊製程；只吃得到價格，吃不到量
Arm每顆核心收權利金；AWS 超過一半的 CPU 需求已是自家 Arm 晶片，Nvidia Vera 有 88 核；Meta 4 月向 AWS 租數千萬顆 Graviton 核心跑代理人開始自己賣晶片，跟客戶直接競爭

對台積電的影響

GPU、AMD CPU、AWS Graviton、Nvidia Vera、各家自研晶片（ASIC）都在台積電投片。價值不管最後落在哪一層，晶圓都要在這裡做。8 月營收年增 53.3%，2 奈米晶圓一片約 3 萬美元，3 奈米約 1.8–2 萬美元。

CPU 缺貨對台積電也有利。Intel 不擴舊製程，多出來的伺服器 CPU 需求會流向 AMD 和 Arm 陣營，兩邊都用台積電。

要分開追的是 CoWoS 擴產。這件事對台積電是營收，對 GPU 雲廠是供給增加。同一則新聞，可能在查核點 8 算支持，在查核點 2 算推翻。

什麼情況收回這個想法

  • 這個想法建立在用量成長跑贏降價。若 OpenAI、Anthropic 與雲端 AI 營收在降價後連續兩季放緩，收回。
  • GPU 雲的論點建立在租金守住。若同一代旗艦卡租金或長約每 MW 價格下跌，雲廠那一段收回；舊世代卡降價不算。
  • 電力設備的論點建立在交期拉長。若 GE Vernova 或 Siemens Energy 說交期開始縮短，這一段收回。
  • 融資是整條鏈的前提。若資料中心貸款普遍跌破 85、或雲廠延後上市，整體重新評估。
