世界往哪走

每題用一籃股票回答。分析師把獲利預估往上改、三年成長預估變高、股價贏大盤，代表市場站在「是」那邊。警戒線碰到，代表答案可能要翻。

九題其實是幾個押注

把每題的股票籃（總經題用利率、美元）近兩年的週漲跌拿來比。常常一起漲跌的題目，其實是同一個押注：答案一翻，會一起翻。

九題沒涵蓋、但還在發展的事

情報監視器正在追的故事線，配不到任何一題的列在這裡。某一條一直出現，就該考慮加成第十題。

自己考自己

每天記下每題「市場站哪邊」。30 天、90 天後回頭看：當時站的那邊，後來股價有沒有贏。

公司最怕什麼

壓力測試：過去三次大跌重演一次

把現在的部位放回過去的大跌期間，看會跌多少。「部位不動」是照今天的權重一路抱著；「照系統規則」是實單主系統當時真的會怎麼減碼（2021 年 8 月以後才有紀錄）。

      怎麼算的
      • 每天自動重算，不呼叫模型，也不靠任何報告更新。報告只放在各題下面當「當初怎麼想」的連結。
      • EPS 上修：籃內公司近 3 個月獲利預估的變化，取中位數。三年成長預估：分析師預估未來兩個財年的年化 EPS 成長，每月一筆。一年股價對大盤：個股一年報酬減 SPY，取中位數。
      • 新聞：情報監視器的故事線，用關鍵字配到各題，配到的會一直留著，越積越多。
      • 「今天先看」的順序：警戒線碰到而且席位押在那題、公司系統出問題、市場嚴重異常、7 天內的大事、長期風險。最多 5 件。
      • 九題幾個押注：近兩年週漲跌的相關係數，0.6 以上併成同一組，0.4 以上列在各題「一起動」。
      • 自有資金撐得起的成長：增量資本報酬率乘再投資率，代表公司不向外拿錢、不提高利潤率，靠自己賺的錢能長多快。
      • 市場站哪邊：EPS 上修、三年成長預估月變、一年股價對大盤三個訊號，多數是正的算「偏是」。成對的題目看兩籃的差。
