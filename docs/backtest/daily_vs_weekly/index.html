問題：把週線長軌（W52/104/250）搬到日線，再加上各種濾網，能不能做得比週線更好？四個檢驗用同一把尺：同樣的 CAGR 下，日線版的最大回撤要比「稀釋後的週線」更淺，Calmar 也要比週線高，才算過尺。

結果在美股與台股都一樣：美股 0/72、台股 0/24，沒有任何一格過尺。全球 14 國裡的「過尺」全擠在週線最弱的市場。第四節說明為什麼，以及這個差異能不能用輪動吃到。

一、美股 SPY/QQQ/SMH：0/72 過尺

✓ 全軸封閉：週線 long-only 是最優，動不得

把同一條長軌規則搬到日線、再加遍出場確認 / 盤整閘門 / 多空 / 200日方向濾網 / 各種 MA 組合 —— 0/72 真過尺

用同一把 matched-CAGR 尺(同 CAGR 下 MDD 要比稀釋週線更淺、且 Calmar > 週線)。結果：日線在每個標的、每個 MA 組合、每種濾網下都贏不了週線。 盤整閘門(ER/R²/ADX/CHOP)只是重建週線那個免參數的濾網——逼近卻不超越；加在週線上反而破壞它(錯過 V 反彈); 空單側則是任何濾網組合都救不活的災難。週線時間架構的「不被盤整洗」不是可有可無的選項，它本身就是這套系統的 alpha。

最接近的兩個嘗試 — 提升日線、且不拿 DD 換

目標：提高 Calmar 但靠降變異/改善每筆品質，不靠加槓桿換 DD。這兩個是整個搜尋裡離週線最近的——但仍指向同一個結論。

① MA 組合 ensemble(分數倉) — 穩健有效，但逼近不超越

部位 = 多組日線 0/1 訊號的平均(0/.33/.67/1)。每組在不同時點被洗，平均掉 = 純粹降變異(分散),DD 因此變淺。

單一 60/120/2000.270.390.26
3 組合0.290.430.23
4 組合0.340.440.24
廣組合0.270.360.28
週線採用0.440.430.57
MDD 全部下降、Calmar 全部上升(QQQ 4組逼到 0.44≈週線)——「降變異的免費午餐」是真的，而且 DD 變淺正是「不拿 DD 換」。但沒一個過 matched-CAGR 尺：分散把日線推近週線，沒推過。

③ ATR 出場帶(出場 close < MA1 − k×ATR) — 唯一過尺，但只在 SPY、不可移植

用 ATR 帶讓部位在正常波動裡不被掃出(讓贏家呼吸),k 控制寬度；保護線仍在。

整個調查鏈唯一真正過尺的技術：SPY 的 ATR 出場帶，k=1.5(Calmar 0.45)與 k=2.0(0.49)皆 > 週線 0.44(且過 matched-CAGR 尺),而且 k=0→2.0 平滑單調上升，不是海市蜃樓。 但不穩、不可用:QQQ 反被它害(寬帶讓輸家也亂跑、MDD 加深),SMH/0050 微幫遠不及週線。機制上寬 ATR 帶 = 把出場拉慢 = 又在重建週線的耐心——在 SPY(低波動平順)剛好合身就過，在 QQQ(高波動)耐心過頭就扛爆。屬 SPY 特性的曲線擬合，非通則。
綜合：能穩健提升日線的是 ① ensemble(四檔 DD 全降、Calmar 全升),但逼近不超越；③ ATR 帶能在 SPY 真過尺但不可移植。 兩者本質都是「用分散或放慢出場去重建週線」——做得好就逼近、做過頭就扛爆。週線那個免參數的點，就是效率前緣。

三條鐵律

1. 慢打敗快。週線把日線雜訊平滑掉、不被盤整洗，這是 edge 本身，不是可調選項。日線怎麼修都只能逼近、不能超越。
2. 做空股票指數結構性失敗。上漂逆勢 + 熊市暴力反彈軋空，方向濾網、盤整濾網、出場確認、時間架構、MA 組合，任何組合都救不了。
3. whipsaw 是保險費，消不掉。它買到的是「吃得到 V 反彈」；任何想濾掉它的閘門(加在週線上)濾掉的反彈比省的盤整更多，淨虧。

方法與限制

  1. 判生死的尺(matched-CAGR):過尺 = Calmar > 週線 且 同 CAGR 下 MDD 比「把週線稀釋到同 CAGR」更淺。raw Calmar 會在不同 CAGR 間誤導(軸6 的海市蜃樓),這把尺才公平。
  2. 固定軸：日線斜率 N=5、出場確認 N=2(掃過 1/2/3)、ER window 20、ADX/CHOP period 14。週線 = W52/104/250、4 週斜率、破 W52 即出(N=1)。成本單邊 7bps,閒置 SHY/BIL(美股)或現金(台股)。
  3. 方法論收穫：24 格 × 多個調過的參數裡冒一個 raw 高 0.05 的本是噪音；matched-CAGR 尺 + 跨標的複製檢驗正確擋下它。別信單一 in-sample 最佳格。
  4. 真實資料：yfinance,週線基準對齊站上長軌頁發佈值。

三條鐵律

1. 慢打敗快。週線把日線雜訊平滑掉、不被盤整洗，這是 edge 本身，不是可調選項。日線怎麼修都只能逼近、不能超越。
2. 做空股票指數結構性失敗。上漂逆勢 + 熊市暴力反彈軋空，方向濾網、盤整濾網、出場確認、時間架構、MA 組合，任何組合都救不了。
3. whipsaw 是保險費，消不掉。它買到的是「吃得到 V 反彈」；任何想濾掉它的閘門(加在週線上)濾掉的反彈比省的盤整更多，淨虧。

方法與限制

  1. 判生死的尺(matched-CAGR):過尺 = Calmar > 週線 且 同 CAGR 下 MDD 比「把週線稀釋到同 CAGR」更淺。raw Calmar 會在不同 CAGR 間誤導(軸6 的海市蜃樓),這把尺才公平。
  2. 固定軸：日線斜率 N=5、出場確認 N=2(掃過 1/2/3)、ER window 20、ADX/CHOP period 14。週線 = W52/104/250、4 週斜率、破 W52 即出(N=1)。成本單邊 7bps,閒置 SHY/BIL(美股)或現金(台股)。
  3. 方法論收穫：24 格 × 多個調過的參數裡冒一個 raw 高 0.05 的本是噪音；matched-CAGR 尺 + 跨標的複製檢驗正確擋下它。別信單一 in-sample 最佳格。
  4. 真實資料：yfinance,週線基準對齊站上長軌頁發佈值。

結論 — 靜態選市場，不要動態輪動

  1. edge 結構性、可事前預測(r=+0.88)。市場的週線趨勢度(ER)就能預判長軌在那裡行不行——這是真關係。
  2. 但靜態關係 ≠ 動態訊號。「有些市場數十年來持續比較會趨勢(美國)」是慢的結構事實；它不能轉成「這個月該押哪國」的擇時訊號——滾動趨勢度/動量排名跨市場無預測力，追高還反咬。
  3. 正確吃法 = 靜態選市場。把長軌部署在結構上會趨勢的市場(美國),就對了——這正是站上 US / 0050 長軌的現役配置。沒有任何全球輪動打得贏。
  4. 方法論：橫斷面 r=0.88 很誘人，但把它當動態訊號用就是過度外推。結構關係要用結構手段(選市場)吃，不是用時序輪動吃——這也呼應全站「真關係存在、但花俏 overlay 失敗、簡單結構勝出」的一貫主題。
