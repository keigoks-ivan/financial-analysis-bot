淨值圖採對數尺度，避免後期金額放大掩蓋早期差異；買進持有基準是 50% QQQ/SMH 籃子加 50% SPY/TLT/GLD/DBC 籃子，同樣月底再平衡。

交易邏輯

A0 研究來源

QQQ/SMH兩腿；週收>52週均線 gate；RV20為20日log return年化波動；sigma_t為RV20的756日rolling median(min252)；ratio=sigma_t/RV20、cap1.0；A2每腿目標轉組合pp後差距≥20pp才調整、10pp取整、clamp50pp。

D1 研究來源

SPY/TLT/GLD/DBC四腿；W40/W52/TSMOM各0/1，E3=(三者和)/3；TSMOM為12月資產總報酬>同期現金；Chandelier=22週最高收盤−2×Wilder ATR10；gate失效時只保留E3一半。

execution 研究來源

空閒資金賺現金；訊號在bar結束形成，回測用前一日權重承擔今日close-to-close；A0/D1月內漂移，月底回50/50，7bps。滿倉時帳戶層QQQ/SMH各25%，D1四資產各12.5%。

caveat 研究來源

不等於已驗證next-open券商成交。

怎麼使用這個結果

這是一個值得 forward paper 的配置，不是已驗證實單。
  • 全部歷史都已被本 repo 的策略研究反覆查看，這不是未觸碰的樣本外驗證。
  • A0 與 D1 沿用各自既有成交假設；回測結果不等於券商帳戶可實現報酬。
  • 訊號為bar結束後可知、以次日持有權重計算close-to-close；未驗證next-open券商成交、滑價或流動性。
  • D1 自 2007-07 才開始，原因是 DBC 歷史與暖機期限制。
  • 最大回撤與最差短期回撤都可能被未來未曾出現的市場路徑突破。
