美股：0.955 的機率系統贏——穩健； 台股：0.925 的機率系統贏——穩健

上一頁（已採用系統的統計不確定性帶）把歷史價格切成固定 長度的小段（63 個交易日）打亂重排，用電腦模擬很多個「平行世界」版本的歷史，看系統贏過買進持有 的機率有多高。但這個切法有個問題：段切得越長，算出來系統贏的機率就跟著單調上升 （段長 126 天→0.62、252 天→0.69、504 天→0.81）——這代表固定切法會把「跌了一年半的慢熊」 硬剁成好幾小段、打散它的連續性，對「需要撐好幾季才見效」的趨勢規則天生不公平。本頁換一種 切法：不用固定天數，改用真實發生過的整段多頭／空頭週期當最小單位，段的內部結構完全 保留，只打亂段跟段誰先誰後——這樣算出來的機率，對趨勢規則才公平。如果換成這種公平切法後， 機率仍不到 0.90，「系統能過關只是運氣」這句話才真正站得住；如果過了，前一頁的結論要加註 「這個結果會因為洗牌方式不同而改變」。

四、把歷史換一種順序重來，系統還贏嗎？（主判準）

做法：把上一節的段（牛段、熊段、復原段）當積木，隨機抽、抽到總長度和原本的歷史一樣長為止 （最後一段截斷），重新拼成一條新的價格路徑（起點用真實的起點價），現金利率也同步拼接；再對這條 新路徑重新跑一次完整的交易規則（52 週線閘門 → 部位比例 → 槓桿上限鎖 1.5 倍 → 執行層權重 20／10／75 → 含利差淨值 → 加總）跟買進持有各自的表現。抽的時候不分牛熊復原，任意順序都可能抽到。

六、最中性的對照版：整個循環一起洗牌（補充，不進判準）

重抽單位改成「整個觀察到的循環」＝實際發生過的連續 (牛段、熊段、復原段) 三元組 （領先的不完整牛段與尾端未完成段各自獨立成一個單位）；循環內部順序與熊段配對到自己的復原段 完全保留，有放回抽循環直到補滿長度為止（最後一個循環截尾），其餘（重跑規則鏈、暖機、成本） 與方法 R 完全相同。美股共 10 個循環單位，台股共 7 個。

  • 段是用「B&H 淨值」切的，不是用系統淨值——避免用規則自己的表現定義重抽單位（那會循環論證）。
  • 段有放回抽樣意味著同一個 2008 可能出現兩次或零次；這正是「歷史換一種順序」的定義。

本檔的 JUDGMENT CALL 完整記錄（11 條）
  • 段的重抽單位母體：與 adopted_bootstrap 方法 B 相同，母體＝各市場 ev（US 2005-01-03／TW 2014-01-01）到資料末端的原生共同索引，不延伸到 ev 之前。
    理由：spec 未指名母體起點；沿用方法 B 既有選擇讓兩份 bootstrap 研究可比。
  • 段的 50/50 B&H 合成序列：用兩腿各自的 bh_nav（真實 adjclose，日對數報酬）做 return-weighted 50/50 合成（沿用 run_combo_qs.combine），在這條合成序列上切段——不是用系統淨值切。
    理由：spec 明文『避免用規則自己的表現定義重抽單位（那會循環論證）』。
  • 峰谷切段演算法：單趟掃描：bull 狀態追蹤 running max；一旦相對目前 running max 回撤達門檻，bear 段＝〔前一個 running max 日、之後到回到該高點為止全程的最低點〕；bear 段結束後立刻接 recovery 段＝〔該最低點、回到 running max 那天〕；隨後新 bull 段從該天開始。
    理由：spec 定義是敘述性的（『谷』＝ next ≥15% 回撤的谷，『復原』＝谷到下一個創高），此為其唯一自洽的演算法化——bear 段的谷必須是『整個未創新高期間』的全域最低點，否則『下一個創高』會定義不出對應的谷。
  • 段的收尾（首尾邊界）：領先段（視窗起點到第一個峰值）標記為 bull；資料結尾若仍在 bull／recovery／bear 狀態中，標記為該狀態的 open（未完成）段，用掃描到當下的資訊計算長度與報酬。
    理由：spec 明文『leading bull from window start to first peak；trailing open segment to data end（label its type by state）』，逐字照做。
  • 零長度段：峰谷演算法偶爾會產生 n_days=0 的 recovery 段（谷值當天就直接創新高，無中間交易日）；這類段仍保留在段清單中（重抽時貢獻 0 天），不特別剔除。
    理由：spec 沒有要求剔除零長度段；保留最忠實反映真實歷史（V 型反轉本來就沒有中間可言）。
  • 段內現金利率序列：與 adopted_bootstrap 方法 B 相同，取兩腿之一的 panel['r']（兩腿同市場本來就同一利率來源）依段的日期範圍切片重抽；重抽路徑的第 0 天利率固定用真實序列的第 0 天值（不參與段重抽），僅第 1 天起的利率隨段拼接。
    理由：與『重建價格路徑從真實起點價出發、day-0 強制』的既有慣例一致：day-0 是錨點不是被重抽的對象，價格與利率都在這一天固定。
  • R-alt 抽樣規則：每次抽段：若上一段抽到的是 bear，下一段強制從 recovery 段池中均勻抽；否則（上一段是 bull／recovery／或這是第一段）從全部段池（bull+bear+recovery）均勻抽。
    理由：spec：『強制熊段後必接復原段（牛→熊→復原的自然順序，只打亂哪一個牛接哪一個熊），bull segments drawn freely』——bear 之後的下一段只能是 recovery（且是均勻抽的哪一個 recovery），其餘時候完全自由抽，是對這句話最直接的翻譯。
  • 段抽樣是否分市場獨立：US 與 TW 各自用自己的段池抽樣，不跨市場混用段。
    理由：兩市場貨幣、波動率結構完全不同，跨市場混段沒有經濟意義，spec 也未提及跨市場抽樣。
  • 最後一段截尾：抽段抽到累計長度 ≥ n-1（原始窗的報酬天數）時停止，並將最後一段的對數報酬與利率陣列從頭截到剛好補滿所需長度（不是整段丟棄，也不是從段尾部截）。
    理由：spec『最後一段截尾』的最自然讀法——保留該段開頭的连续結構（段內部仍是真實連續交易日），只是段的『尾巴』被砍掉不用，較砍頭破壞的段內連續性少。
  • R-cycle 循環（cycle）的分組演算法：從段清單最前面開始，貪婪地把連續三段依序驗證是否恰好是 (bull, bear, recovery) 型別，是就打包成一個『循環』單位；一旦某個位置配不上這個型別順序，或剩不足三段，就停止分組，把剩下的每一段各自當成獨立單位（不與任何段合併）。
    理由：supervisor 指示『the leading partial bull and the trailing open segment are their own units』——本檔的切段演算法固定以 bull 開頭，實測 US／TW 兩市場的段序列恰好都能從頭起整除成完整的 (bull,bear,recovery) 三元組，只在尾端留下一段未配對的 open bull，這正好自動滿足『領先 bull 併入第一個循環、只有尾端 open 段落單』的描述，不需要額外特判。
  • R-cycle 抽樣單位截尾：抽循環單位抽到累計長度 ≥ n-1 時停止；若最後一個循環單位需要截尾，從該循環內部『打平後的段序列』（bull 段接 bear 段接 recovery 段）的頭部保留、尾部砍掉，與方法 R 的段內截尾規則完全一致，只是換成對循環（可能橫跨三段）操作。
    理由：與既有『最後一段截尾』判斷一致沿用，維持全檔唯一的截尾慣例，不另立規則。

九、這頁用到的名詞

  • bootstrap（拔靴法）：從一組已觀察到的資料裡反覆隨機抽樣、重建出很多個「平行世界」版本的同一段歷史，藉此估計一個統計量（例如 Calmar 比）到底有多不確定，而不是只看一次算出來的單一數字。
  • regime（狀態／格局）：市場長期處在的某一種特徵性狀態，例如「多季度的慢熊」或「多年的順風多頭」——跟單日或單週的漲跌不同，regime 講的是持續一段時間的結構，趨勢規則的績效高度依賴 regime 有沒有被完整保留。
  • 牛段／熊段／復原段：本頁把 50/50 買進持有的淨值曲線切成三種段：牛段＝創新高的多頭期間；熊段＝從歷史高點跌到某次至少 15% 回撤的谷底；復原段＝谷底漲回原本高點為止。
  • 以段為單位的重抽：跟方法 B 逐日打散不同，本頁把整段（例如一整段 132 天的熊市）當成一個不可分割的積木，有放回地抽這些積木來拼出新的一千條平行歷史，段內部的漲跌順序與相依結構完全保留。
  • 循環（cycle，方法 R-cycle 的重抽單位）：把「一次完整的熊市＋它自己的復原」再往前接上帶出這次熊市的那段牛市，三段合成一個更大的積木——熊段永遠跟它自己的復原段配對在一起，不會被拆散，只有「這一整套循環跟另一套循環誰先誰後」被打亂。
  • p 值（本頁的 p_R）：在很多個以段重抽出來的平行世界裡，系統的 Calmar 比贏過買進持有的比例。
  • 分位數帶：把重抽出來的一千個數字由小到大排序，取第 5%、25%、50%（中位數）、75%、95% 位置的值，用來呈現「這個數字的合理範圍」而不是只給一個點。
  • Calmar 比：年化報酬 ÷ 最大回撤的絕對值，衡量「每承受一分回撤風險換到多少報酬」，數字越高越好。
  • Martin 比（Ulcer Performance Index）：年化報酬 ÷ Ulcer Index（把整段期間所有時點的回撤幅度平方後取均方根），比 Calmar 更在意「長期泡在回撤裡」而不只是單一最深的那一次。
  • matched-cash 尺：把買進持有用現金稀釋到跟系統同樣的年化報酬，看稀釋後的回撤是不是比系統淺——如果稀釋更淺，代表系統的下檔保護其實可以用「單純少放一點錢」複製，而且更省。

十、一分鐘版

  • 我們問了什麼：上一頁用固定長度切歷史來測系統贏面，切法越長機率越高，這樣公平嗎？如果 改用真實發生過的整段多頭／空頭週期來切、只打亂順序不動內部結構，答案會不會不一樣？
