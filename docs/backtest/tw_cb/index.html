CBAS 是什麼、市場長什麼樣子

券商買入 CB 後拆成兩端分售：債券端（ASW）——投資人出本金收固定利息、扛發行人信用風險； 選擇權端（ASO）——以該 CB 為標的、履約價約 100 元的美式買權（實物履約或現金結算）。 買進成本（權利金）＝（CB 委買價 − 100）＋百元報價（預付利息，賣出時未用天數退還）；天期 1–3 年， 選擇權到期日通常＝下次賣回日前約 14 天。槓桿實例：CB 105.6 元、權利金 11,960 元/張 → 8.85 倍， 深度價外可近 20 倍。最大地雷：CBAS 到期或 CB 被強制贖回時不自動結算——未主動賣出/履約， 權利金整筆歸零（深度價內也一樣）。

2026-08 市場快照：掛牌 CB 386 檔、流通餘額約 NT$3,175 億；單日有成交檔數 378 檔中僅約 201 檔（~53%）； 單日等價成交金額約 NT$19.2 億。CBAS 承作券商 16 家申報，前八大：元大、台新、凱基、群益金鼎、富邦、永豐金、 統一、第一金。CBAS 是店頭議價（券商為對手方），無集中市場、無公開成交回報；CBAS 歷史百元報價表與 bid-ask spread 統計均無公開存檔——這是回測 CBAS 本身（而非底層 CB）的根本限制，本專區的五個回測全部 建立在底層 CB 現券的公開行情上，CBAS 只在「總排名」一節作槓桿化的定性判斷。

① 折價 CB 組合 —— 買 <100 元的可轉債，2007–2026 全樣本外驗證

限制：基準 ^TWII 為價格指數，未含息，低估含息報酬約 3–4pp/年；本版不含轉換價／賣回價條款， 無法區分「折價因體質差」與「折價因流動性」，也無法計算 YTP；持倉逐日以最近成交價 forward-fill mark， 月內路徑可能失真（交易點位不受影響，只在有成交日發生）；疑似違約清單（下市時最後成交價 <70）僅供人工覆核， 非精確違約認定。

② 停止轉換期收斂 —— NO-GO（機會太稀、S2 到期窗是逆選擇陷阱）

規則：台灣 CB 發行後前 3 個月與到期前 10 日依規定停止轉換，套利者無法「買 CB→轉股→賣股」收斂折價； 理論上恢復轉換日起折價應收斂。世代 cohort 674 檔試算，訊號窗 2015-04 ~ 2020-08。
方法論教訓（本策略是抓出這個 bug 的地方）：前一版用 yobond 快照自報的「CB 理論價」欄位當轉換價值， 14 個 S1 訊號裡有 13 個是假的——快照月頻、常常已過期一個月，「折價」其實是股價在快照後下跌造成的幻影。 改用交易所官方 API 抓事件日當天真實母股收盤價重算後，S1 只剩 5 個真事件，另有 1 筆（288602 兆豐金E2） 疑似為海外可交換公司債（EB，標的未必是發行人自己股票），已標記但未剔除。

⑤ 折價收斂（股期對沖規劃）—— Phase A 過關，但是個人手工利基

規則：CB 市價低於轉換價值（折價 ≥3%，扣轉股成本與 T+5 風險緩衝）時買入，追蹤是否在 20 個交易日內收斂。 Phase A（無對沖）驗證錯價是真的、會收斂；先導檢查已知機會稀薄（52 個月度抽樣日僅 32 筆、集中深度價內券）。 資料窗 2015-03 ~ 2019-08。

方法論教訓（三條，全站共用）

①內嵌股價的快照欄位不能當事件日訊號：yobond「CB 理論價」欄位內嵌的是快照當時的股價， 月頻快照常常已過期一個月——停止轉換回測曾因此把 14 個訊號裡的 13 個判成假訊號。任何「合約條款＋內嵌市價」 混在一起的欄位，必須拆開來源，市價一律用官方 API 抓事件日當天真實值，條款可以 asof 過期使用（過期方向保守）。
②多 tranche 權益合併，pre-launch 期須填閒置資金：月營收 3 個月疊代變體三個 tranche 各自只分到總資金 1/3、同時並存、互不重疊，逐日加總即代表全部資金——這與「兩個各自滿額的獨立回測不可直接相加」 （本站 Rule 1）不是同一情境，須先判斷資金是否重複計算再決定合併方式。
③台股 CB 賣回／到期前常停牌，「當日市價」須用停牌前最後成交價：賣回保底攤大餅初版要求賣回日 「當天」剛好有成交才採用市價，實測後發現台股 CB 常在賣回/到期日前數日到數週停牌（例：24391 美律一 2018-01-17~01-29 停牌，賣回日恰好落在停牌窗內，停牌前最後成交價 167 遠高於賣回價 100.5），嚴格要求「當天成交」 會把「停牌前市價明明遠高於賣回價」的事件錯判成「無市價可比、只能拿賣回價」，逐日 MTM 路徑上產生假崩盤 （初版組合年化曾算出 −38%、MDD −97.6%，與逐筆勝率 95.5%完全矛盾——這個矛盾本身就是抓到 bug 的信號）。 修正後一律用「停牌前最近一次真實成交價」，並記錄陳舊天數供讀者自行打折扣。

總排名與對「CBAS 操作策略」問題的正式回答

  1. 賣回保底攤大餅（最佳，可小資金實盤）——合約錨、零周轉、壓力測試後仍穩健。
  2. 低溢價 CB 全買（意外存活者）——月營收研究線的對照組本身，不看營收、只看溢價率與價格門檻， alpha 顯著（t=3.79）且 beta 低。
  3. 折價收斂（股期對沖）（手工利基）——邊際優勢真實存在（對沖後 t=6.5），但容量小到只能個人手工操作。
  4. 折價 <100 組合（低 beta 現金增益）——alpha 存活但薄，絕對報酬水準遠不如原論文年代。
  5. 停止轉換期收斂（NO-GO）——機會太稀（<30 件），且到期窗子策略是逆選擇陷阱。

對原始問題「CBAS 可轉債選擇權操作策略」的正式回答：把上面任何一個策略用 CBAS 槓桿化都不划算—— 這五條研究線裡報酬最厚的（賣回保底攤大餅）年化也只有個位數 %，CBAS 的槓桿成本（百元報價預付利息、深度價外選擇權 時間價值歸零風險）會把這麼薄的報酬源吃光，付了利息之後大機率歸零。CBAS 本身是正規槓桿工具，不需要再疊加槓桿策略 去榨這批報酬源。

詞彙表

CB（可轉換公司債）公司發行的債券，附帶「可依約定轉換價換成該公司股票」的權利。
CBAS券商把 CB 拆成債券端（ASW）與選擇權端（ASO）分售，ASO 是以該 CB 為標的、履約價約 100 元的美式買權，槓桿工具。
轉換價值 CVCV = 100 ÷ 轉換價 × 母股收盤價——這張 CB 若立刻轉股可拿到的股票市值。
溢價率／折價率CB 市價相對轉換價值的偏離——市價 >CV 是溢價（股性強），<CV 是折價（可能存在轉股套利空間）。
賣回權（put）持有人有權在約定的賣回日以賣回價（常 >100 元）要求發行人買回，是合約保底的來源。
停止轉換期發行後前 3 個月與到期前 10 日依規定不可轉股，套利機制在此期間失效。
YTP（Yield to Put）以進場價買入、持有到賣回日行使賣回權的年化報酬率——把賣回權當固定收益資產估值的指標。
