給沒有統計背景的讀者： 這一頁問的是：系統要靠「慢熊」（跌很久很深的行情）才能發揮保險價值，那慢熊歷史上到底多久發生一次？ 做法是拉 150 年、7 個股市的歷史回撤事件，算慢熊的歷史發生頻率（base rate——某件事在真實歷史裡實際 發生的比例，不是憑印象猜）。看主要數字時，重點看「十年內至少發生一次的機率」與「平常年份要付出的保費 （跑輸大盤的年化報酬差）」——兩個數字合起來才看得出這張保單划不划算。本頁不做任何「現在該不該持有」 的建議，也不預測下一次慢熊什麼時候來，它只回報歷史上這種行情發生的頻率與代價。
慢熊約十年一遇：保費要用十年攤

美股慢熊每十年約 0.81 次（1990 後 0.82 次）； 合併多市場池每十年約 0.87 次；未來十年至少一次慢熊的機率約 58.3%。

base rate（基礎機率——不看個別故事、只看長期歷史裡某類事件平均多久發生一次的統計基準率） 問的是「慢熊多久來一次」而不是「該不該續保」。峰谷 ≥9 個月的回撤定義為「慢熊」，<3 個月為「急跌」， 3–9 個月為「中」；門檻先驗凍結、跑完不改（見下方判準）。

一、判準與定義（預註冊原文，跑之前鎖死）

「慢熊」＝峰到谷（自歷史高點回撤首次 ≤ −20% 起算之谷底）之時長 ≥9 個月； 「急跌」＜3 個月；3–9 個月為「中」。9 個月的門檻由來：約是 W52 週線閘門從觸發（跌破 52 週均）到 有意義減少曝險所需典型時滯的兩倍；3 個月＝一季，也是 bootstrap 敏感度顯示規則失去 edge 的區間下限。 兩者皆為先驗設定，跑完不因單一結果回頭調整。

慢熊每十年次數（美股 GSPC 1928 起＋各市場合併池，兩者皆看）讀法
≥ 1.5慢熊是常態：保單十年內大概率理賠 ≥1 次
0.7 – 1.5慢熊約十年一遇：保費要用十年攤
< 0.7慢熊罕見：保費多半白付
附帶必印：λ（Poisson λ——卜瓦松過程的年發生率參數，這裡是「每年平均出現幾次慢熊」） 的 95% 信賴區間；1990 後（現代市場結構）與全樣本分開算，若 1990 後 λ 明顯低於全樣本， 必須明說「慢熊頻率在下降」而不是只印全樣本數字。本回測不調規則、不掃門檻擇優、不寫續保建議—— 只回答資料在說什麼。
