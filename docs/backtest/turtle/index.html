一、Turtle 多資產趨勢系統

===== VERDICT HERO =====
△ 邊際補充 — 全額版平庸，僅商品 sleeve 有條件價值

修正後真相：全額 System 2 是平庸的高回撤系統(CAGR +7.72% / MDD -52.67%),舊 22.5% 是停損成交假象；殘餘價值只剩 GLD/USO 低相關危機 sleeve

Turtle 是多資產 trend-following 系統，設計目標是商品/外匯/利率市場， 與本站其他系統(Long Track / 雙軌 / 六狀態機 / GEM / W52 都聚焦 SPY/QQQ)不可直接比較， 因此不進主比較表。本回測用 6 個 ETF 作為期貨代理。2026-06 引擎修正後三個結論： (1)原始 System 2(55/20)全額 6-ETF 版是平庸的高回撤系統 — CAGR +7.72%、MDD -52.67%、Sharpe 0.39、勝率僅 16.4%、獲利因子 1.20,期末 $4.24M。 舊頁的 ~22.5% CAGR 是停損成交假象(停損以收盤觸發卻以停損價成交，雙重樂觀), 已修正為盤中觸發 / 跳空以 min(開盤，停損價)成交，並補上 §2.3 組合風險上限 — 這是錯誤修正，不是過擬合、也不是「槓桿解釋」； (2)白皮書 6.2 節的「2026 修正版」(+1.5x 成交量 +T+2 確認)更差: CAGR +0.90%(-6.82pp)、MDD -55.64%、期末 $1.19M — 此結論不變； (3)殘餘價值不在全額系統，而在 GLD/USO 兩腿當 20% 低相關危機 sleeve(見下方拆解): 組合 Calmar 0.65 → 0.85、MDD 收窄，但修正後邊際效益明顯縮水(不再是舊頁的 0.64 → 1.03), 且不增加報酬、只削回撤。SPY 腿在修正版勝率 0.0%(33 筆)再次驗證 「指數不適用突破」，股票部位請用 E3 等專用框架。

===== LIMITATIONS =====

已知限制

  1. ETF 是期貨的不完美代理 — 全額保證金、無槓桿；USO 內含展期損耗、FXE 不含利差收益。 真實期貨帳戶下槓桿與保證金壓力會放大回撤，本頁數字偏樂觀的一面是無保證金追繳，偏保守的一面是無法用名目槓桿放大 Sharpe。
  2. 隱含槓桿(2026-06 修正後量測) — sizing 公式使總名目曝險平均 2.50×、中位 2.32×、p90 4.61×、最大 8.81× (已被 §2.3 組合單位上限約束；舊版未上限為 3.31× / 10.7×)。即便在 2.5× 平均曝險下 headline CAGR 也只有 +7.72%, 與本站無槓桿系統的 CAGR 不在同一基底上，比較請用 Sharpe / Calmar。現金 ETF 帳戶無法執行全額本系統，需期貨保證金。
  3. 有效樣本自 2007-01-05 起 — 引擎取 6 市場交集，DBA 上市最晚； 「2005 起」的名目窗實際少了兩年，且錯過 2005-06 的商品行情前段。
  4. SPY 腿結論 — 「0.0% 勝率」出自修正版；修正後原始版 SPY 腿全期 P&L 亦為負(勝率 17.4%、佔總損益 -8.0%)。 「指數不適用突破」的證據強度來自多個獨立來源(本頁 + 做空系統 + 雙軌做空腿),不依賴單一數字。
  5. 交易紀錄只含已平倉交易 — 期末仍持倉的部位計入淨值但不入交易表； 引擎不追蹤分單位進場日期，交易表以出場日排序、進場價為各單位均價。
  6. 成本模型簡化 — 2bps/邊滑價近似，未含佣金與市場衝擊； 高頻加碼(最多 4 單位)下實際成本略高。
  7. 敏感度網格是樣本內掃描 — 「最佳區間 Entry 40-45」是描述性證據，不構成參數變更的採用依據； 本頁維持 55/20 原始規格。

原始 System 2(Donchian, 1980s)

  1. 進場： 收盤價突破 55 日最高(做多)/ 最低(做空)
  2. 出場： 收盤價跌破 20 日最低(多)/ 最高(空)
  3. 止損： 進場價 ± 2 × ATR(20)
  4. 單位規模： (資金 × 1%) / (2 × ATR)
