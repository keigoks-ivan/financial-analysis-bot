這一頁要回答一個很直白的問題：現在已經在用的兩套規則（美股、台股各一套，槓桿最高鎖在 1.5 倍、 再加一層把訊號轉成實際下單的執行層 A2——美股實際跑出來的 Calmar 比是 0.595、 台股是 1.217，兩者都領先各自的買進持有對照組），贏過「單純買進持有」這件事， 有多少是真本事、多少只是運氣好剛好遇到 20 年的歷史剛好那樣走。因為每日漲跌， 我們手上只有唯一一條真實發生過的路徑，沒辦法重來一次。所以我們用電腦把這條路徑的順序 重新洗牌 1,000 次、假裝歷史可能用另一種順序發生，一次一次重跑整套規則（先看要不要進場的閘門、 再算要壓多少槓桿、最後才落成實際下單），總共洗牌重跑 1000.00 次。每一次都問一遍 「這套規則贏了買進持有嗎」，算下來贏的次數佔比，就是 p_B。p_B 越高代表越像真本事； p_B < 0.60 表示這次贏，運氣的成分比規則本身還大（下方「給沒有統計背景的讀者」段有更完整的說明）。

給沒有統計背景的讀者： 這一頁問的是：如果把系統已經跑出來的歷史報酬順序打亂、重新排列很多次，系統贏過稀釋對照組 （用現金稀釋到同樣風險的買進持有）的次數比例（p 值）有多高。看主要數字時，重點看 p 值離 0.5 （丟銅板的機率）有多遠——愈接近 0.5 代表愈分不出高下，愈接近 0 或 1 代表結果愈不像純運氣。 本頁的 p 值大多落在 0.4～0.6 之間，也就是接近丟銅板。這不代表系統沒有用，也不是叫你現在該 買或該賣什麼——它只說明「用這個特定統計方法重排歷史」分不出系統跟稀釋版誰比較可靠，方法本身 對趨勢型規則不利這件事，頁面內文另有說明。

五、這頁沒有告訴你的事

  • 這種重排方法（block（重抽時整段搬動保留前後關聯） bootstrap）保留了 63 天以內漲跌之間的關聯，但打散了更長的 市場狀態（多年牛市／熊市各自的先後順序）——它給你看的是「同一種歷史劇本、換一種播放順序」的世界， 不是「換一齣完全不同劇本」的世界。
  • 台股能用的歷史窗只有約 12.5 年，用 63 天當一個搬動單位時，實際上真正獨立的區塊大概只有 50 個 左右，所以算出來的合理範圍會很寬——這正是這一頁想讓你看到的事，見上方主表百分位欄位之間的差距有多大。
  • 方法 B 重排歷史時，融資利率、現金利率也跟著新的歷史序列變動，但執行層裡「把倍數取整到某個 百分點」這個動作固定不變，重跑時保持一致。
每一個判斷背後的理由（完整記錄，共 8 條）
  • Method B 基期窗：以各市場 ev（US 2005-01-03／TW 2014-01-01）起到資料末端的原生共同索引為重抽母體（與 A 的原始序列同窗），不延伸到 ev 之前的暖機期歷史——spec 的「前 505 個交易日暖機」在此母體上算，指標（raw_ratio min_periods=252、gate_w52 52週）在暖機期內是用重抽後的資料自己建立，不借用 ev 之前的真實歷史。
    理由：spec 未指名母體起點；505≈2×252 恰好對齊 raw_ratio 的 min_periods=252（留一倍緩衝），強烈暗示暖機是設計成『路徑自給自足』而非借用暖機期外的真實資料——選 ev 為母體起點讓暖機長度與原始判準窗的量級一致，也讓方法 A／B 用同一段原始序列，可比。
  • Method B 現金利率：US／TW 兩腿各自的 panel['r'] 在建構時已是同一來源（US 兩腿皆用^IRX、TW 兩腿皆用 1% 平盤），本檔取兩腿其一（legs[0]）作『現金利率序列 r』，與spec『現金利率序列 r 從 panel 取得』的單數用法一致。
    理由：兩腿本來就相同，取一即代表另一腿，不需要另外合成。
  • Method B 合成 panel 的 close 欄：重抽路徑只有 adjclose（總報酬）序列，沒有獨立的未調整價；close 設為等於 adjclose。
    理由：與現有 SMH／0050／2330 三腿的既有慣例完全一致（那三腿本來就 close==adjclose，見 run_vol_target.load_panel），且 eng 的 DRIP 邏輯在 close==adjclose 時退化為恆等（無額外股利調整雜訊），是最保守的簡化。
  • Method B 路徑起點：重抽後的 log 報酬陣列，第 0 個元素強制設回 0（不論重抽到什麼），確保 price[0] 精確等於真實起點價。
    理由：spec 明文要求『重建價格路徑從真實起點價出發』；若不強制歸零，重抽到非零值會讓day-0 價格偏離真實起點，違反此要求。
  • Method B 美股 GFC 分期指標改列：spec 原文『美股 GFC 分期（2005-2008）CAGR 符號為正的比例』在重抽路徑上不可行（block bootstrap 打散了『哪一段是 2005-2008』這個日曆概念，重抽後的路徑沒有『2005-2008 那一段』可指認），改報『系統最差 12 個月報酬優於B&H 最差 12 個月報酬的比例』（僅美股）。
    理由：使用者任務指示已明確拍板此替代指標（『JUDGMENT CALL: 報 fraction of resamples where system's worst-12-month return is better than B&H's worst-12-month return』）。
  • Method A／B 的 matched-cash 尺：尺的定義＝解 k 使『k·B&H＋(1-k)·現金』的 CAGR 等於該次重抽系統的 CAGR，再看系統的 MDD 是否比這條稀釋線淺（pass＝系統 MDD 較淺）。
    理由：與 insurance_premium/run_premium.py 既有 ruler1『A 勝 E』的邏輯同構——那是本 repo既有的『matched-cash 尺』唯一實作範例，沿用其判準形狀而非另立新規則。
  • 方法 B 執行層 clamp：exec_leg_weight(w, 20, 10, 75.0) 的 clamp 固定用 75（＝cap1.5 的50×1.5），比照 build_market 內 cap1.5 分支的 clamp 慣例。
    理由：spec 已明講 exec_leg_weight(20,10,75)，與現行追蹤主系統的執行層 A2 clamp 完全一致。
  • Method A 現金序列：與 Method B 同一條 panel['r']（legs[0]）——現金利率序列本身不分方法 A／B，是同一組資料。
    理由：spec 沒有要求兩法用不同現金定義；沿用同一序列可比。

六、這頁用到的名詞

  • bootstrap（拔靴法）：從一組已觀察到的資料裡反覆隨機抽樣、重建出很多個「平行世界」版本的同一段歷史，藉此估計一個統計量（例如 Calmar 比）到底有多不確定，而不是只看一次算出來的單一數字。
  • block（區塊）：bootstrap 不是逐日打散重抽（那會破壞股價本身「今天跟明天有關聯」的相依性），而是連續抽出一整段（例如 63 個交易日）當作一個單位再重新拼接，保留短期內的相依結構。
  • p 值（本頁的 p_B）：在很多個重抽出來的平行世界裡，系統的 Calmar 比贏過買進持有的比例。p_B=0.514 代表：1,000 個平行世界裡大約只有 51%（一半多一點）系統會贏，跟丟銅板差不多。
  • 分位數帶：把重抽出來的一千（或一萬）個數字由小到大排序，取第 5%、25%、50%（中位數）、75%、95% 位置的值，用來呈現「這個數字的合理範圍」而不是只給一個點。
  • Calmar 比：年化報酬 ÷ 最大回撤的絕對值，衡量「每承受一分回撤風險換到多少報酬」，數字越高越好。
  • Martin 比（Ulcer Performance Index）：年化報酬 ÷ Ulcer Index（把整段期間所有時點的回撤幅度平方後取均方根），比 Calmar 更在意「長期泡在回撤裡」而不只是單一最深的那一次。
  • matched-cash 尺：把買進持有用現金稀釋到跟系統同樣的年化報酬，看稀釋後的回撤是不是比系統淺——如果稀釋更淺，代表系統的下檔保護其實可以用「單純少放一點錢」複製，而且更省。

一分鐘版

  • 我們問了什麼：把美股、台股各自已經走過的歷史，用電腦重新洗牌排出很多種 「可能發生過的另一種順序」，再重新跑一遍完整的進出場規則，看規則贏過單純買進持有的次數佔比有多高。
  • 我們發現了什麼：美股、台股的贏面都落在「邊際」或以下——多數重排出來的世界裡， 規則沒有壓倒性地贏過買進持有；把搬動的歷史區塊拉得更長會讓贏面上升，但就算拉到本頁測過的最長區塊， 兩個市場都還沒到「過尺穩健」那條線。
  • 這不代表什麼：這不是叫你現在該買或該賣什麼，也不是說規則沒有用或該立刻停用—— 這一頁只回答「用這種特定的統計方法重排歷史，能不能證明規則穩定勝過買進持有」這一個窄問題， 其他判斷（要不要繼續用、要不要調整）不在本頁範圍內。
