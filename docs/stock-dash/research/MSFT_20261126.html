微軟的資本支出，能在 Google 追上之前換回現金嗎？

MSFT｜資料日 2026-11-26｜現價 489.93（2026-11-25 收盤）｜精簡版

Azure 加速、利潤率守住，生意仍在變好；但自由現金流÷淨利只剩 0.51、報酬率四年降 5 個百分點，Google Cloud 規模已逼近 Azure，現價對 FY28 共識 20 倍，預設現金轉換兩年內回升。

結論

微軟的生意還在變好。上一季營收年增 19%，營業利益年增 21%，Azure（微軟的公有雲）成長 48%，Microsoft Cloud 加速到 30% 1。弱點在現金：同一季每一元淨利只換回約 0.51 元自由現金流，因為資本支出年增一倍 2。

價格不算貴，但現價已經假設這筆投資兩年內開始回收。現價對明年度（FY28）共識是 20.2 倍，trailing 倍數在近四年取樣的低段 3。前提是資本支出撐住 15～25% 的獲利成長，而且現金轉換回升；這兩件事目前都還沒發生。

最該盯的一件事：每季「自由現金流÷淨利」能不能連兩季回到 0.6 以上。上一份報告把它設為重新加碼的條件，當時最近兩季是 0.55 和 0.51，之後還沒有新的一季公布。

股價從 11-02 上一份報告的 521.91 跌到 489.93，期間 11-04 曾創 555.80 的新高 4。之後跌了 11.9%，有三個原因：

  • 11 月 12 至 13 日 Exchange Online、Teams、Copilot 中斷將近一天，公司內部啟動「Code Red」。
  • 10 月 PCE 通膨升到 3.8%，市場押注 12 月升息，軟體股整體下跌（MoneyCheck，2026-11-25）。
  • 同期公司發行 250 億美元公司債 5，加重市場對 AI 資本支出的疑慮。

生意怎麼賺錢

FY27 起公司改成兩個分部 6：

  • Agents and Infra：賣雲端運算、M365 訂閱與 Copilot 給企業。單季營收 768 億美元，營業利益率 52.8%（40,558÷76,795）。
  • Devices and Consumer：Windows 授權、Xbox、搜尋廣告。營收 155 億，營益率 34.6% 1。

利潤有接近九成來自前者，因為 40,558÷45,915＝88%。

上一季營收比去年同期多了 146 億美元，各品類貢獻如下 1：

成長幾乎全靠 Azure。管理層對 Q2 指引 Azure 固定匯率成長 49～50% 7，原因是需求仍大於供給。

下一個成長來源是 M365 的 Copilot 與用量計費：

  • Q2 指引 M365 商用雲成長約 19%，管理層說全年會一路加速。
  • 付費席位只成長 5%，成長主要靠每位用戶營收（ARPU）7。

正在放慢的是 Windows OEM（預授權給電腦廠的 Windows）。Q2 指引年減 30% 中段，原因是去年 Windows 10 停止支援墊高了基期，加上電腦廠庫存偏高 7。

客戶集中度是要另外記住的數字。法說會上分析師提到 OpenAI 占當季營收 11%，管理層沒有否認 7。換算約 101 億美元（92.3×11%），相當於 Azure 單季營收的三成，但有多少實際落在 Azure，公開資料沒有拆。

護城河與競爭

跟誰比、差多少。 微軟的利潤率與投入資本報酬率都明顯高於其他雲端與 AI 基礎設施廠商。但它的資本支出占營收比重，兩年內從 18% 升到 35%（FY24 到 FY26） 8。

微軟的報酬率比同業中位數高的幅度，三年依序是 14.7、12.6、13.6 個百分點 9。差距沒有在拉開，也沒有縮小。

優勢從哪來。 有兩個，都對得上數字：

  • 轉換成本：M365、Entra（身分驗證）、資安三者綁在一起，企業換掉的成本很高。對應的數字是 M365 商用雲連年 17～18% 的成長，而席位只成長 5% 7。量不大幅增加也能把價格往上推。
  • 規模：資料中心、電力與晶片的採購規模。對應的數字是 Agents and Infra 分部營益率在擴產期仍守在 53% 左右 1，同業只有 Google 和甲骨文超過 30%。

份額。 公開資料裡能直接核對的第三方市占數字，這次無法開原文確認，只能用各家財報的雲端營收比大小：

  • Google Cloud 上季營收 307.1 億美元，年增 103%（9to5Google）。Azure 是 331.7 億、成長 48% 1。
  • 一年前 Azure 是 Google Cloud 的 1.48 倍（22,384÷15,160），現在只剩 1.08 倍（33,165÷30,710）。
  • Google Cloud 的營收含 Workspace（Google 的辦公軟體），所以這是方向，不是精確的市占。

誰最可能打破、用什麼方式。 威脅最大的是 Google：

  • Google 有自研晶片與 Gemini 模型，雲端成長是 Azure 的兩倍。
  • Workspace 同時正面對上 M365，兩條戰線都碰得到。

第二個是 OpenAI 的鬆綁。2026-04-27 新協議生效（OpenAI）：

  • OpenAI 可以在任何雲端提供所有產品，微軟對 OpenAI 智慧財產的授權改為非獨家，期限到 2032 年。
  • 新產品仍優先上 Azure。

占營收一成一的客戶不再綁定 Azure，Azure 的高成長裡有多少能留下，就要看價格與產能。

定價權。

  • 守得住的部分：M365 消費版漲價後營收成長 17%，現在進入對比去年漲價的基期，管理層說成長會回落到十位數低段 7。上季 Foundry（模型平台）的每 token 營收高於預期 7，代表高階模型還收得到溢價。
  • 往下走的部分：Microsoft Cloud 毛利率從去年同期降到 66%，Q2 指引約 65% 7。管理層歸因於營收組合移向毛利較低的 Azure；單一產品層級的毛利率仍在改善，但沒有單獨揭露數字。

判斷。 有兩條說得出來、但還沒被數字證明的優勢：

  • 6,770 億美元的商業剩餘履約義務（RPO，已簽約未認列的營收）是否穩當，要看 12 個月內認列部分的年增率，目前是 29%。
  • 自研 MAI 模型與 Maia 晶片能壓低單位成本，目前只有管理層引用的每瓦 token 數。要看 Microsoft Cloud 毛利率能否在 Azure 占比上升時止跌。

護城河判為寬：投入資本報酬率三年平均比同業中位數高 13.6 個百分點，每年都是正的，也沒有適用的上限條件。走勢判為持平：差距三年在 12.6～14.7 之間。

已經出現、但兩年數字還沒反映的訊號有三個：Google Cloud 的規模幾乎追平 Azure、OpenAI 改成多雲、M365 E3 銷售執行偏弱 7。

程式用 yfinance 年報自算：稅後營業利益÷年底（股東權益＋總債務－現金）；最近一年標藍。

水準與走勢。 程式自算的投入資本報酬率四年從 31.0% 降到 26.2% 10，仍高於 Google 的 24.2% 與 Amazon 的 13.5% 8。dd-screener 口徑是 21.82%，只有五年平均的 0.86 倍，被歸為下滑 10。

從哪來。 報酬率靠利潤率撐，被周轉率拖下來：

  • 稅後營業利益率從 33.8% 升到 37.7%。
  • 投入資本周轉從 0.92 次降到 0.69 次 10。

錢投進資料中心的速度，比營收跟上的速度快。利潤率還在升，所以報酬率是緩降，不是崩跌。

新投入的錢賺多少。 兩個口徑的增量報酬率與再投資率相乘，都在 17～18%：

共識 EPS 的成長是 FY28 +21%（24.23÷20.03）、FY29 +25%（30.2÷24.23）11，都高過這個上限。差額要靠兩個來源：

  • 單位資本支出換到更多營收，也就是周轉率止跌。
  • 再投資率超過 100%，用舉債與融資租賃補上。250 億美元公司債已經在做這件事 5。

口徑。 兩個因素都讓帳面報酬率偏低：

  • 收購 Activision 留下的商譽：扣掉 1,197 億美元商譽後，FY26 報酬率是 34.9%（125,127÷(478,278−119,651)）。
  • 現金只扣了現金及約當，沒扣 559 億美元短期投資：一起扣掉後是 29.6%（125,127÷422,370）。

另外，OpenAI 相關的損益記在營業外，不在稅後營業利益裡，所以不影響這組數字。

判斷： 資本報酬在變弱。程式自算從 31.0% 降到 26.2%，主因是周轉率從 0.92 降到 0.69。

乾淨基期有兩個：

  • 過去十二個月調整後 EPS 是 18.04。
  • FY26 調整後 EPS 是 17.28（4.13+4.14+4.27+4.74），比年報 GAAP 的 17.95 低 0.67。

現金流有兩個異狀。

第一，自由現金流四年沒有長，淨利卻成長 85%：

  • 自由現金流依序是 595、741、716、670 億美元。
  • 淨利從 724 億增加到 1,337 億 13。
  • 年度「自由現金流÷淨利」從 0.82 降到 0.50。

第二，上季的 186 億自由現金流沒扣融資租賃：

  • 當季資本支出含融資租賃是 452 億美元，用這個數字算，自由現金流是 128 億（58.0−45.2）。
  • 換算「自由現金流÷淨利」只有 0.35 7。

折舊正在追上來。 單季折舊攤提 117 億美元，年增 44%，營收只成長 19% 1。資本支出約四分之三是 CPU、GPU 這類短年限資產 7。這筆費用會在未來幾年持續壓低營益率。

其他。

  • Q1 應收帳款收回 171 億美元，去年同季是 165 億，屬於季節性，不是異常 1。
  • 投資活動的「其他」流出 129 億美元，比去年同季的 62 億多一倍。內容沒有揭露，可能是預付或對外投資。
  • 呆帳準備從 10.4 億降到 7.3 億 1。
  • Q2 的成本指引含自願離職方案的費用，金額沒有揭露 7。

微軟比 Google 貴約 13%（20.2÷17.9−1）。理由是微軟的營益率高出 15 個百分點、投入資本報酬率高 2 個百分點。但 Google Cloud 成長是 Azure 的兩倍，所以這個溢價建立在利潤率上，不在成長上。Oracle 便宜，因為它的資本支出已經超過營收的八成。

歷史位置。 trailing 本益比 25.6，落在近四個年度取樣點的 22.7% 分位。區間從 21.67（2026-06）到 38.86（2024-06）3。trailing 獲利含 OpenAI 收益，用調整後的 27.2 倍看會略高，但仍在區間下半段。

現價預設了什麼。 拿歷史取樣低點 21.67 倍反推：

  • 現價需要 trailing EPS 22.61（489.93÷21.67）。
  • 比乾淨基期 18.04 高 25%。
  • 共識大約在 FY27 與 FY28 之間達到這個水準，也就是一年半左右。

現金面的要求更高。過去十二個月自由現金流是 600 億美元（5,882+15,803+19,639+18,633），只占市值 1.65% 2、14。現價是用獲利定價，不是用現金。它預設現金轉換會回到 FY23～FY25 的 0.70～0.84 水準。

最強的反方意見

反方的論點是：微軟正從輕資本的軟體公司，變成重資本的算力供應商，但市場還用軟體的倍數給它定價。

  • 報酬率四年掉了 5 個百分點。
  • 自由現金流四年沒有成長。
  • 最大客戶 OpenAI 已經可以去任何一家雲。
  • 對手 Google 的雲端成長是它的兩倍。

能回答的部分：利潤沒有被擴產吃掉。Agents and Infra 分部的營益率在資本支出翻倍的同一季仍有 52.8%，與去年的 53.1% 相近 1。管理層也說需求仍大於供給 7。

答不了的部分有兩個：

  • 這批短年限 GPU 在折舊期內能不能維持現在的 token 價格。
  • OpenAI 的長期合約付款能力。

6,770 億美元的 RPO 有七成在 12 個月以後才認列，這一段年增 98% 7。其中有多少來自 OpenAI，公開資料沒有拆。

  • Azure 固定匯率成長連兩季 <30%，而資本支出仍在上升
  • OpenAI 營收占比 >15%，或相關應收 >100 億美元、提列呆帳
  • 往正面翻：自由現金流÷淨利連兩季 ≥0.6，同時 Azure 成長 ≥40%
  • Google Cloud 單季營收超過 Azure，且 Azure 成長 <35%

監管事件目前沒有實質進展：

  • 美國 FTC 對雲端授權與綑綁銷售的調查，公開資料沒有起訴或結案的消息。
  • 英國 CMA 的策略市場地位認定尚未定案。

兩者都可能帶來行為要求，但目前沒有可以量化的影響。
