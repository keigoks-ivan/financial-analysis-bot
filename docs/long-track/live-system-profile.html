實單主系統體檢：美股少賺一點換到回撤減半，台股換得太貴

現行實單規則全史重播，數據截至 2026-11-06。上半頁照站內評估標準 v3 的五層漏斗判定，下半頁是完整量化報告與逐筆交易。
判定

美股：有效交換。2002 年起每年少賺 1.27 個百分點，夏普值（每承受一單位波動多賺多少）與 Calmar（年化報酬除以最大回撤）都贏，換五個終點重算也沒有翻。

台股：混合。每年少賺 6.89 個百分點，回撤淺了但夏普值輸，連「固定放約七成股票、其餘現金」的配置都沒贏。

訊號沒有挑到漲得比較多的日子。16 個訊號拆成前後兩半檢驗，沒有一個兩半都站得住，參數又是看過歷史才挑，所以這些數字應當成上限。

  8. 16 個訊號拆前後兩半檢驗，兩半都站得住的是 0 個。

二、L0 數字有效性：數字能重現，三條方法紀律沒過

最大的問題在訊號：沒有一個訊號在前後兩半都站得住。回撤變淺可以用「高波動時部位小」解釋，挑對方向的能力沒有證據。

一筆交易怎麼算

  • 三塊：每檔水位拆成週線那塊 70%（週線多頭才持有）、月線那塊 30%（月線多頭才持有）、接回那塊 20%（只在下軌接回期間持有）。水位就是三塊相加，例如 100＝70＋30，50＝30＋20。
  • 一筆：某一塊從空手到持有、再回到空手。這一塊的大小固定，中間沒有加減碼。
  • 日期：訊號日是那週（週線、接回）或那個月（月線）最後一個交易日的收盤，成交日是下一個交易日的收盤。週五或月底休市時，實單程式把訊號放到下一個交易日，成交再晚一天，表中以＊標示。
  • 報酬：進場成交日收盤到出場成交日收盤的還原價報酬（含股息），扣買進 0.07%、賣出 0.07%，台股賣出再扣證交稅（0050 0.1%、2330 0.3%）。不含現金利息。代理是價格指數，沒有股息。
  • 價格欄：成交日收盤價，已調整分割、未還原股息，所以兩個價格的漲跌會比報酬少掉股息。
  • 統計只算「計入」的交易。不計的有：還在持有、11-06 剛出訊號還沒成交、樣本第一天就持有（沒有進場點）、指標還在暖身期就進場（第十五節）。
  • 債金：IEF、GLD 沒有接回，只有週線那塊 14%、月線那塊 6%（20% 乘 0.7、0.3）。報酬是還原價報酬減現金利息、再減每年 0.1%，也就是比放現金多賺多少。IEF 從 2002-07-30、GLD 從 2004-11-18 才有價格。
