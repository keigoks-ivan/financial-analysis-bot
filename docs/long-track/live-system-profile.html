7交易統計

一筆＝某一塊從空手到持有、再回到空手。每檔水位拆成週線 70、月線 30、接回 20 三塊，大小固定。報酬是成交日收盤到成交日收盤的還原價報酬，扣成本，不含現金利息。只統計已完成的交易，持有中與樣本起點就在場內的不計。獲利因子＝賺錢那幾筆的報酬加總除以賠錢那幾筆加總的絕對值。
