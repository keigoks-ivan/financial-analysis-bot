Agentic AI 平台：市場殺的是計價基礎，不是應用層

2026 年 2 月的軟體股崩跌被記成「AI 要吃掉軟體」。把一年報酬按收費方式排開，答案更窄也更可用：被殺的是按人頭收費的公司，被買的是按用量收費的——而市場是按標籤分的，不是按消耗曲線分的。

一句話結論Key Call

2026 年 2 月市場殺的不是「應用層軟體」，是「按人頭收費」這件事——而且是按標籤殺、不是按消耗曲線殺。該分辨的是：誰的客戶用 agent 越多、帳單就越大；誰的客戶用越多、席次反而越少。

現在

錢真在流動但極不對稱：企業三大平台揭露的 agent 營收合計約 $31 億，單是 Anthropic 的編碼助理一項年化就 $80 億，同期微軟一季資本支出 $358 億。

未來

勝負不在誰的 agent 聰明，在誰的收費方式跟得上用量。座位計價者把消耗補回來，今天的折價就是錯殺；補不回來就是正確殺。

怎麼做

不追消耗計價那一籃（估值與動能雙高）。力氣放在「座位計價、但消耗曲線正在起來」的名字，先看補購率與合約義務餘額。

三條要盯的否證指標
  • Salesforce 全年指引的有機上修額　現值 +$1.0 億（2026-08-26）→ 連兩季 ≤$1.0 億且合約義務餘額增速破 10%，論點作廢
  • 消耗籃 vs 座位籃 52 週報酬差　現值 約 +49 個百分點（2026-08-31）→ 收斂至 <10 個百分點兩季，分歧已被定價
  • 客服外包三家可比成長率中位數　現值 −1.7% 至 +0.6%（2026 上半年）→ 連兩季回正並 >+3%，取代量不足
怎麼做PM Action
  • ① 候選名單先按「收費方式」分兩籃再談估值，不要放同一張表排序。
  • ② 座位籃只看兩個數字：消耗型收入的補購比重、合約義務餘額增速；同步走弱就不是錯殺。
  • ③ 消耗籃動能與估值雙高（多檔 26 週勝大盤逾 40 個百分點），不因敘事對就追價。
  • ④ 純度最高的資產不在上市市場，別為「純 agent 概念」付溢價。

Section 1

核心判斷Investment Thesis

把一年報酬按「這家公司怎麼收錢」排開，比按「是不是 AI 概念」排開解釋力高得多——這是本篇的全部立論。

2026 年 2 月 3 日 Anthropic 推出 Claude Cowork、2 月 5 日 OpenAI 推出企業版 Frontier，兩天內軟體股蒸發約 $2,850 億，交易員稱之為「軟體末日」。半年後指數已收復不少，但底下的排序沒回到原位——依據不是誰的 agent 做得好。

下表把本篇涵蓋的名字按收費方式分四籃。按用量收費的四檔 52 週報酬中位數 +35.6%，按人頭收費的四檔中位數 −16.5%，相差約 52 個百分點——而且與公司品質幾乎無關：Adobe 資本報酬率 38.6%、護城河 A，一年仍跌 19.8%；Snowflake 資本報酬率是負的，一年漲 35.6%。市場這一年挑的不是好公司，是收費方式。

這個分佈給出三件事。一，2 月崩跌的定價邏輯是「按人頭收費的收入基礎會消失」，不是「軟體公司會倒」。二，市場執行時用的是標籤——被歸為席次股就一起跌、被歸為用量股就一起漲——沒有分辨席次會不會被自己的消耗收入補回來。三，錯價因此住在中間那一格：收費方式看起來是人頭、但消耗曲線正在起來的公司，Salesforce 是最大的樣本。

供需怎麼判：分裂。按人頭賣的泛用 agent 席次明顯過剩——數千家自稱 agent 廠商、開源編排框架幾乎免費、四大平台各自附贈。按用量與按成果賣的執行、資料與治理層相對短缺，因為產能來自別人的資本支出，且被合規要求保護；但短缺這段已被追價，見 §4。

投資時鐘：現在處於擴張中段（Phase II）。換相的兩個條件與資本週期證據見 §3.4。

一句話講完
不要問「這家公司有沒有 agent」，要問「客戶多用一次 agent，它多收到多少錢」——這一年的報酬差距幾乎全由這題解釋，而市場只用標籤回答。
推導與考證

推導：籃子分類依各公司主要收入計量單位——席次數（HUBS／ADBE／WDAY／NOW 訂閱主體）、消耗量（SNOW credit、DDOG host 與事件量、NET 請求量、CRWD 端點與模組）、混合（CRM 席次＋Flex Credit、MSFT 席次＋Azure 消耗）、合約總額（PLTR）。報酬取站內週線快取自算，非公司揭露。

NOW 被歸在按人頭一籃是有爭議的：它的人工智慧年約合約金額已破 $10 億且按消耗計價，但訂閱主體仍是席次與模組。若把 NOW 移到混合籃，兩籃差距擴大而非縮小。🔵 [X: base 分類差異不改變結論；bull 消耗占比提前突破；bear 席次流失快於消耗補位]

Section 2

市場哪裡看錯Key Debates

四張卡：殺對了嗎、成長真的嗎、換計價划算嗎，以及鏡頭外的威脅——入口與結帳。
分歧 1「AI agent 正在結構性摧毀應用層軟體」信心：中
市場最強版本
2026-02-03 Anthropic 發表 Claude Cowork，軟體股單日蒸發約 $2,850 億，為 2020 年 3 月以來最差單日；OpenAI 兩天後推出 Frontier，官方定位是「企業的語意層，讓所有 AI 同事都能據以運作與溝通」，可直接操作既有系統，首批客戶含 Intuit、State Farm、Uber。若 agent 能跨系統操作，付錢買介面的理由就消失了。
我們認為
對一半。被取代的是「人盯著畫面點擊」，不是「權限、稽核與紀錄住在哪裡」——agent 要動作，就要有一個能授權、能留軌跡、能被稽核的系統，這件事只會更值錢。市場用一把尺殺完整層，是整體性折價落在未命中的標的上。已反映：座位籃 52 週中位數 −16.5%，其中資本報酬率最高的 Adobe 也跌 19.8%，折價與基本面脫鉤，屬錯殺。
看什麼分勝負
座位籃消耗型收入占比連兩季上升、合約義務餘額守住兩位數增速 → 錯殺成立；席次與合約義務餘額同步下滑 → 不是錯殺，是提前反映。⚠ Salesforce 合約義務餘額增速跌破 10%（現 +14%），本卡作廢。
分歧 2「agentic 營收曲線已經證明變現」信心：低偏中
市場最強版本
Salesforce 2027 財年第二季揭露 Agentforce 年經常性收入突破 $15 億、年增逾 240%，加 Data 360 合計近 $39 億；ServiceNow 人工智慧年約合約金額同季首破 $10 億；Workday 的 agent 相關年營收破 $6 億；微軟 Copilot 付費席次突破 3,000 萬。這是史上最快的企業軟體新品類。
我們認為
數字是真的，但換不出等量的公司層成長，而且口徑在動。Salesforce 同一份財報把 Agentforce 統計範圍擴大到含 Slackbot 與 Headless 360，年增率因此不可與前期直接比；更關鍵的是全年營收指引只上修 $2 億，其中 $2 億來自併購、$1 億來自有機成長、$1 億是匯率逆風——agent 年經常性收入一年多出十億美元級，全年有機指引只多 $1 億。已反映：不可操作——市場既沒付溢價也沒縮手。
看什麼分勝負
下兩季有機上修額放大且合約義務餘額增速同步走高 → 曲線換成公司層成長；口徑再擴大而上修額續平 → 這是重新標記既有收入。⚠ agent 收入揭露若一年內二度擴大統計範圍，該公司此類數字不再採信。
分歧 3「從人頭換成果計價，等於把市場從軟體池擴到勞動池」信心：中
市場最強版本
賣方把 AI 擴散的可及市場直接框在約 $40 兆的全球勞動市場；成果計價的代表定價已可查——客服 agent 每解決一通對話收 $0.99、每帶進一條合格線索收 $9.99。軟體若按完成的工作收費，單一客戶的付費上限就不再是席次數。
我們認為
分子對，分母被忽略。換成果計價的同時，推論成本被搬進銷貨成本：ServiceNow 本季訂閱毛利率 73.5%（非一般公認會計原則 80.5%），公司把全年目標訂在 81%，等於承認這條線只能守不能升；產業調查顯示以大型語言模型為核心的公司毛利率約 65%，低於過去十年雲端軟體 80% 以上的水準。四大會計師事務所已於 2026 年 6 月為成果計價出具收入認列指引——會計準則開始處理一種定價，代表它要進損益表了。已反映：市場定價了 TAM 的分子，沒定價毛利與可預測性的分母。
看什麼分勝負
成果計價者毛利守住 65% 以上且客戶留存不降 → 換尺成立，該用長期自由現金流看；毛利續探且需以價換量 → 軟體變服務業。⚠ 主要平台商連兩季揭露訂閱毛利下滑且主因是推論成本，成長型倍數不再適用。
分歧 4圈外威脅：入口與結帳權正在被協議層重寫信心：中
市場最強版本
多數人沒把這件事放進 agent 平台的討論框裡。2025 年 9 月 OpenAI 與 Stripe 共同發布代理商務協定，讓使用者直接在對話中完成購買，首批為 Etsy、隨後擴及逾百萬家 Shopify 商家；Google 一側另有商務與付款協定並已交由標準組織治理。同時 Linux 基金會成立代理 AI 基金會，把 Anthropic 的模型脈絡協定與 Google 的 agent 互通協定收進同一治理傘，成員八個月內由不到 40 家增至逾 250 家。
我們認為
威脅不在「agent 取代軟體」，在「誰握住入口與結帳，誰就能對其他人抽稅」。協定發布方的官方說法是商家保留對商品、品牌與履約的完整控制權；但控制權不等於議價權，真正的價格標籤是抽成率，而抽成率至今沒有官方公告。更值得注意的是，協定治理傘明確把企業授權那一層排除在外——最能決定誰對誰抽稅的環節，現在沒有中立治理者。已反映：完全沒有反映在任何一檔應用層股票的估值裡。
看什麼分勝負
抽成率公告且落在個位數低段、授權規格進入中立治理 → 協定是通路不是稅；抽成走高或身分授權由單一模型商定義 → 應用層被切走一層利潤。⚠ 任一模型商對其入口完成的企業交易公告兩位數抽成，應用層利潤池推估全面下修。

市場最低估的風險：不是模型變強，是「同一份 agent 用量，收費權歸誰」還沒有制度定案——治理傘刻意不管授權層，把最貴的一段留給市場先搶。

對投資的意義四張卡只有第一張是可操作的錯價；第二張是等待，第三張決定用什麼倍數，第四張決定五年後利潤池歸誰。
推導與考證

推導：分歧 1 的「錯殺」判定採三步——①折價是否整體性（座位籃全跌）②折價是否命中基本面（Adobe 資本報酬率 38.6% 仍跌 19.8%，未命中）③是否有可觀測的補位機制（消耗型收入占比）。三步齊備才標錯殺。

分歧 2 的口徑變動為公司自述：「Effective Q2 FY27, Agentforce ARR includes our AI offerings, Slackbot and Headless 360」。🟢 [F: Salesforce 2027 財年第二季財報，2026-08-26]

Section 3

機制與供需Industry Mechanics

需求多大、供給誰在做、為何是現在、供需怎麼判——四小節。

3.1 需求：能查到的錢，和被說出來的錢，差了兩個數量級

需求規模有兩種算法，結果差很遠。機構預測分兩個口徑：窄口徑（只算 agent 產品本身）2030 年落在 $245 億至 $526 億、年複合成長率約 46–47%；廣口徑（把內建 agent 功能的既有軟體支出重新歸類）給出 2026 年就有 $2,019 億、2030 年 $9,850 億。差二十倍不是誤差，是定義不同。本報告採窄口徑，因為只有它對得上公司揭露。

由下而上更誠實。把能查到的企業級 agent 收入加總：Salesforce $15 億、ServiceNow $10 億、Workday $6 億，合計約 $31 億；而同年單是 Anthropic 一家的編碼助理年化營收就達 $80 億。寫程式這條垂直的變現規模，是三大企業平台加總的兩倍以上。

需求三角對帳由上而下 vs 由下而上（2026 年）
路徑2026 年規模怎麼讀
由上而下・廣口徑（含既有軟體重新歸類）~$2,019 億約為可查揭露的 60 倍以上，屬重新標記
由上而下・窄口徑（agent 產品本身）~$68 億至 $109 億與可查揭露同一數量級，可用
由下而上・公司揭露加總（下限）~$31 億（企業平台）＋ ~$80 億（編碼）僅四家有量化揭露，實際更高

資料來源：MarketsandMarkets、Grand View 市場預測［#17］［#22］；公司季報［#1］［#3］；Anthropic 向投資人揭露之媒體報導［#20］

需求要長大，卡點不在模型能力，在買方的驗收能力。企業調查顯示只有約三成企業至少有一個 agent 進入生產環境，而治理成熟的僅約兩成；試點畢業率低的主因依序是評測缺口、治理摩擦與可靠度。這解釋了編碼為何領先——寫程式的產出天生可驗收，而客服、法遵、財務的產出要人判斷對錯，驗收成本就是採用成本。

最大的買家可能根本不買：需求天花板還有一個被低估的扣項——超大型企業自建。摩根大通的內部大型語言模型工作台已開放給約 25 萬名員工、約半數幾乎每天使用，450 個以上的 AI 應用進入生產、目標擴至 1,000 個以上，該行 2026 年科技預算約 $180 億、自稱年省約 $20 億。這不是拿開源元件自組，是繞過所有上市標的的策略決策。「自建對採購」的比例統計查不到，故不推估；判別訊號是同級買家未來四季是否公布同等規模自建——出現三家以上，需求 Base 下修一檔。

3.2 供給：四家平台、兩家模型商、無限個開源框架

供給側最重要的事實是：這產業的產能不是自己蓋的。應用層平台的「產能」是模型商的資本支出，而編排本身已被開源做到接近免費——單一開源框架過去十二個月執行了二十億次 agent 動作、近半數財星 500 大企業的技術棧內有它，另一個框架在 2026 年第一季大型企業生產架構文件中的引用比重約三分之一。當編排免費、模型外購，能收錢的只剩三樣：專屬資料、權限與稽核、分發。

中國與開源這條線該怎麼放：低價替代的威脅落在編排層，不在採購清單上。中國的 agent 新創已與當地模型商結盟做境內版，2026 年 4 月一樁跨境收購並被中國主管機關以國安理由駁回、改由當地資本買回——這條線往「境內自成一區」走，不是往西方採購走；中國 agent 平台被西方大型企業採購的案例查不到。反直覺的是，企業採用開源權重模型的比重在最近一份年度調查中不升反降（19% 降到 11%）。判別訊號：任一西方財星 500 企業採用中國模型商的 agent 平台，或開源模型企業份額回升逾 20%，應用層毛利假設整組重算。

3.3 為什麼是現在：可驗收的工作先被自動化

2026 年的分水嶺不是模型變聰明，是「驗收」第一次有了工程解。編碼的產出天生帶著測試，agent 可以自己知道錯了；其他領域要等評測工具成熟，而企業調查把評測缺口列為試點畢業的第一大障礙。這就是編碼垂直變現規模是企業平台兩倍以上的原因——不是預算多，是驗收成本低。

誰是造王者：不是模型商，是稽核與合規要求——哪一類工作先被允許讓 agent 自主完成，決定哪一層先收得到錢，而這個許可權在風控與法遵手上。歐盟人工智慧法時程已定：通用模型透明度義務 2025 年 8 月生效、法規全面適用自 2026 年 8 月起、高風險義務 2027 年 12 月 2 日生效、嵌入受規管產品者延至 2028 年 8 月。但最關鍵的一題未定——歐盟主管機關對「自主 agent 歸哪一類」仍只表示持續觀察。美國聯邦與各州的 agent 責任立法、金融與醫療監管機關的表態，本次查證未取得可引用的一手依據，故不推估也不寫進情境；判別訊號是任一金融監管機關發布 agent 決策指引，或歐盟把自主 agent 納入高風險——任一出現，治理層議價權上升、採用時程延後。

3.4 裁決：供需裁決與三視野推估

資本週期：這個產業的資本強度分佈極端。以最新一季計，微軟資本支出占營收約 39.8%（$358 億／$900 億），而應用層的 ServiceNow 為 2.9%（$1.14 億／$39.87 億）、Palantir 僅 0.75%（$0.15 億／$19.35 億）。第二個指標同向：資本報酬率微軟 25.9%、Palantir 15.1%、ServiceNow 9.8%、Salesforce 8.9%，全數高於一般資金成本，但應用層的超額報酬明顯較薄。合起來讀：過剩壓力全堆在基礎設施層，應用層根本沒有自己的資本週期——它不會因蓋太多產能而崩，只會因賣不動而慢慢失去定價權，所以傳統產能利用率訊號在這裡無效。

持續重大 agent 資安事故：2026 年 3 月已出現開源模型閘道器遭植入後門、三小時內約 47,000 次下載的供應鏈事件，另有 agent 誤刪生產資料庫個案，但迄今沒有帶公開損失金額的企業級案例。四季內仍無重大損失 → 治理摩擦是可管理的成本；出現重大損失或緊急監管規範 → 採用時程延後、治理層議價權上升。

2026 Q4 起代理商務與授權協定：抽成率是否公告、企業授權規格是否進入中立治理。抽成率個位數低段且授權中立化 → 協定是通路不是稅；出現兩位數抽成或授權由單一模型商定義 → 應用層利潤池推估全面下修。

2027-12-02歐盟人工智慧法高風險義務生效。agent 未被歸入高風險 → 採用摩擦低於預期；被納入高風險 → 歐洲部署延後，治理層議價權反而上升。

不明顯的受益者：被殺最凶那一格有兩種公司長得像卻完全不同——一種席次減少後沒東西補上（純工具型），一種席次減少但消耗費補上來（有資料底座與工作流），市場給兩者同一個折價。評測與可觀測層則是罕見的「不管誰贏都要付錢」位置：agent 越多、要監看的越多，且天生按用量收費。

取代到底發生了沒有：獨立統計說有，但規模仍小。人力顧問機構月報顯示，2026 年 5 月單月歸因於 AI 的裁員 38,579 人，創該分類自 2023 年追蹤以來單月新高、占當月四成；至 5 月累計 87,714 人，已超過 2025 全年的 54,836 人，AI 並連續五個月是美國裁員首要理由。但相對每月數百萬的離職流量仍是小數，與客服外包業者成長率只在零上下擺盪一致：取代是真的，速度沒有敘事那麼快。

最大的未揭露風險是客戶集中度：沒有一家拆分過 agent 收入的客戶結構，唯一側面是 ServiceNow 揭露年約合約逾 $500 萬的客戶共 658 家。早期新品類收入常集中在少數指標客戶，流失一家就扭曲判讀。判別訊號＝任一家開始揭露 agent 收入的客戶數或平均合約金額；在此之前，這些成長率一律視為未經集中度校正。

營運槓桿最大的是誰：Salesforce——agent 相關收入基數已具規模，估值卻站在自身五年最低區間，若消耗補位獲證實，估值與盈餘會同向修正。槓桿最負面的是按人頭計價的導入服務業，他們既是 agent 的賣家也是被取代的對象。

背景、歷史與來源Appendix

白話定義、歷史脈絡與來源總表——支撐正文判斷的背景層。

所謂 agent，是能自己拆解任務、呼叫工具、連續執行多步驟並回報結果的 AI 程式，跟聊天助理的差別在於它會「動手」而不只是「回話」。agent 平台則是讓企業建立、部署、授權與稽核這些 agent 的軟體，通常不自己做模型，而是把模型、企業資料與既有系統串起來。

邊界界定：本篇涵蓋企業採購的 agent 平台與應用及其計價與利潤池；不涵蓋模型訓練與晶片層，也不涵蓋消費端助理。單價與用量機制屬姊妹報告範圍。

第一次轉折：1999 企業軟體從永久授權轉為按席次訂閱，這個計價基礎撐了二十五年，撐出一家 2026 財年營收 $415 億的公司。第二次：2006 雲端把計價單位從席次改成用量，日後長出按運算額度計費的資料平台。第三次：2024 客服 agent 開始按「已解決的對話」收費、每通 $0.99，計價單位首度從「誰在用」變成「做完了什麼」。

第四次轉折發生在 2026 年 2 月：兩家模型商在同一週推出可跨系統操作的企業產品，軟體股單日蒸發約 $2,850 億，交易員為此造了一個新詞。到 8 月指數已收復大半，但按人頭與按用量兩籃的報酬差仍有約 49 個百分點——市場沒有收回那個判斷，只是把它做得更精細。
