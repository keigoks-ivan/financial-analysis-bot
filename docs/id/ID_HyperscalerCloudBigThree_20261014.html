這是一份「產業深度報告」（ID），研究整個產業的供需結構、競爭格局與展望，不是單一公司的結論。

結論在哪：報告開頭的「決策摘要層」濃縮全篇重點；完整的情境判斷通常在後段標示「裁決」或「情境」的段落。

常見詞：「論點」（thesis）是這份報告對產業走向的核心假設；「否證指標」是一旦數字打到某個門檻，代表論點可能已經不成立的監測指標；「priced-in」是指這個看法是不是已經反映在股價裡——如果已經反映，代表就算利多兌現，股價也不一定會再漲。

時效提醒：報告日期寫在檔名，產業情勢變化快；相關個股的最新結論請看個別 DD 報告或 /research/。

需求不是風險，時間差才是：capex（資本支出）今年近倍增，折舊與負現金流要到 2027–28 年才結帳。

現在

三家同步高成長，也同時被產能卡住：AWS +37%（18 季最快）、Azure 年營收首次超過 $1,000 億、Google Cloud +82%。分部營業利益率 AWS 39%、微軟智慧雲 41%、Google Cloud 36%，三家 backlog（已簽約未認列的訂單）合計約 $1.7 兆。代價落在母公司：2026Q2 合計 capex 年增約 88%，Amazon 近 12 個月自由現金流 −$7.6B，Alphabet 單季 capex 是折舊的 6.3 倍。

未來

未來兩三年的勝負，看 backlog 能不能按時變成營收，以及營收能不能跑贏折舊。Google Cloud 逾半的 $514B backlog 要在 24 個月內認列，季均至少 $32B，是現值的 1.3 倍。同時，2026 年近倍增的 capex 會在 2027–28 年轉成折舊。過剩不會先以產能閒置的形式出現，會先反映在租價、折舊年限與現金流上。

Section 1

核心判斷Investment Thesis

三巨頭從分化變成一起加速，短缺在產能層；風險從需求移到折舊時間差與現金流。

三家一起高成長：全球雲基礎設施支出年增 43%，是八年最快，AWS +37% 是 18 季最快。短缺在產能層：H100 租價指數 $2.85、7 日 +7.1%；同時 token（模型計價單位）單價在跌，兩者不矛盾。分部 ROI 已經看得到：Google Cloud 營業利益率由 20.7% 升到 35.6%，折舊年增 42% 也沒擋住。

過剩壓力改道到財務面：Amazon 近 12 個月自由現金流 −$7.6B，capex $173.0B（前一年 $107.7B）；Alphabet 2026Q2 單季自由現金流也轉負，為 −$5.9B（近 12 個月仍有 +$53.3B）。帳單在後頭：2026Q2 三家合計 capex 年增約 88%，是雲營收增速的兩倍，2027–28 年會轉成折舊。分化移到估值：三家倍數估算分位 14.3 到 71.7，跟基本面排序無關，只有 Amazon 沒有反映加速。

供需怎麼判：短缺的判斷錨在產能層（電力、記憶體、加速器）；token 單價下跌屬於產品報價層，不改變這一層的裁決。

  • Alphabet 稱供給持續受限，Google Cloud backlog $514B 在等產能交付。
  • 一年期 H100 合約價由 2025-10 的 $1.70 升到 2026-03 的 $2.35，漲約 38%。
  • DeepSeek V4-Pro 輸出每百萬 token $1.98–3.96；量的紅利歸握有算力與自有矽的人。

投資時鐘：現在處於第二階段（Phase II）。換相的兩個條件與資本週期證據見 §3.4。

歷史對照：同格（短缺、第二階段）歷史 24 例，超額報酬中位數 −7.5%，勝率 7/24（91 天成熟樣本，對基準超額；含 2026-06-21 大批補入，並非完全獨立）。本輪三點不同，也有一點相同：

  • 短缺已在買方損益兌現：Google Cloud 營業利益率 20.7%→35.6%，AWS 營業利益 $10.2B→$16.6B。
  • 短缺有撮合價佐證：一年期 H100 合約價 $1.70→$2.35；現貨租價指數 2026-10-13 為 $2.85（7 日 +7.1%，單日讀數波動大）。兩者是不同的價格，都在漲。
  • 同格失敗樣本的典型前兆也在：Amazon 近 12 個月自由現金流 −$7.6B，Alphabet capex 是折舊的 6.3 倍。24 例歷史樣本的特徵無法逐一比對，說不出「這次不同」。

信心因此由高降為中；供需與時鐘判斷維持。以上只證明短缺為真，不能證明市場還沒定價，所以行動只押估值未反映者（Amazon），不再三家齊押。

與姊妹報告的差異：

  • AI 跨領域衝擊判 balanced／I。口徑不同：該篇裁的是 AI 應用層的贏家輸家（流量、SaaS 分化）；本篇錨在雲產能層，且用了較新的 2026Q2 供給受限證據。
  • AI 廣告與零售媒體判 balanced／II。該篇裁的是廣告預算供需，與雲產能無關；時鐘同為 II，差異只在供需層。
  • Apple Intelligence 平台威脅判 balanced／I。該篇裁的是裝置端助理生態；H100 租價上漲只適用於本篇的產能層。
  • AI 推論經濟學判 split／II。該篇判 split，因為 token 單價跌與算力短缺並存；本篇把裁決錨在瓶頸層（產能）。兩篇的事實一致，差別只在裁決層。
  • CUDA／ROCm 護城河判 split／II。該篇裁的是 NVDA 與替代晶片的份額分裂；Broadcom 與 NVDA 營收同漲，不影響雲產能短缺的判斷。
  • LLM 廠商資安經濟學判 balanced／I。資安產品市場，與雲產能無關。
  • AI 算力 capex 週期判 shortage／II。同格、同為中信心；本篇沿用它「capex 年增跌破 +20%」的換相口徑。
  • Token 經濟學判 shortage／II。同格，但本篇信心較低（中）：自由現金流轉負是 2026Q2 的新證據。

Section 2

市場哪裡看錯Key Debates

四個分歧，其中兩個是風險控制線，兩個是 alpha 來源；上游已反映，買方只有 Amazon 反映。
分歧 1capex 回不了本？（alpha 來源）信心：中
市場最強版本
Burry 估 2026–28 年折舊少提 $176B；Amazon 近 12 個月自由現金流 −$7.6B，錢先花、營收後到（iTiger 轉述、Amazon 新聞稿）。
我們認為
分部 ROI 已經出現（Google Cloud 增量稅前報酬約 18%）。就算空方全對，砍 capex 先傷上游，買方現金流回升，偏買方的配置反而更成立。已反映：上游已反映（NVDA 估算已低於 DD 日區間下緣，DD 日 2026-08-31 分位 10）；買方只有 Amazon 反映（估算分位 14.3）。
看什麼分勝負
折舊年增 >40% 的情況下，Google Cloud 利益率仍守在 35% 以上 → 定價權蓋過折舊，ROI 論點成立；Amazon 之外第 2 家縮短伺服器年限或提列 AI 硬體減損 → 會計自白擴散，過剩改道到折舊。⚠ AWS 與 Google Cloud 利益率連 2 季同步下滑逾 5 個百分點（AWS <34%、GC <30%），而營收仍增 >30%。
分歧 2backlog 是集中承諾還是需求？（風險控制線）信心：中
市場最強版本
BofA 等估 OpenAI 約占 Oracle 前季 $638B backlog 的一半；三家 backlog 也被看成少數 AI 實驗室的承諾（分析師估計）。
我們認為
承諾是可調的選擇權，不是鎖死的負債。系統風險在邊緣的 Oracle（capex 是 OCI 營收的 3.9 倍），三巨頭有分部獲利墊底。已反映：Oracle 已反映（26 週 −21.2%、估算分位 16.7）；三巨頭沒有反映集中度。
看什麼分勝負
Google Cloud 季營收往季均 $32B 走 → backlog 按約轉成營收，承諾有剛性；微軟商業 RPO 或 GC backlog 任一出現季減 → 延後開始，緩衝變薄。⚠ 微軟商業 RPO 或 Google Cloud backlog 任一出現季減，且同季揭露主要客戶延後或縮約。

Synergy 三家合計份額守住 63% → 溢出論成立，分流不傷存量；合計份額連 2 季低於 60%，或 AI 實驗室自建算力（如 Anthropic $500 億）上線 → 替代開始，價差成為轉移槓桿。⚠ Synergy 三巨頭合計份額連 2 季低於 60%（現 63%），同時 H100 租價指數下跌。

TrendForce 估 2026 年自研 ASIC 伺服器出貨 +44.6%、GPU 僅 +16.1%；市場給 NVDA 14.22 倍、估算已低於 DD 日區間下緣（DD 日 2026-08-31 分位 10）（TrendForce 經 Introl）。

Section 3

機制與供需Industry Mechanics

需求不是瓶頸，產能交付與折舊之間的時間差才是。

3.1 需求：三家一起加速，backlog 是存量不是流量

  • 全球雲基礎設施支出 2026Q2 $143B，年增 43%，八年最快。
  • 三家雲分部合計營收年增約 43%，只有合計 capex 增速（約 88%）的一半。
  • Google API 每分鐘 token 由 160 億增到 220 億，一季約 +38%；單價在跌，用量漲得更快。
  • backlog 是存量，轉成流量要靠可交付產能：Google Cloud 逾半 $514B 須在 24 個月內認列，季均至少 $32B（現值 1.3 倍）。
