五句話

這家公司靠什麼賺錢：它幫 Cisco、NVIDIA、Nokia、Amazon 這些客戶組裝光通訊模組，靠泰國工廠的精密工藝賺代工費。毛利只有一成二，但廠房周轉快，資本回報約四成。

為什麼現在值得或不值得：股價從五月高點跌掉快一半，本益比從五十倍掉到二十二倍。營收與指引卻還在四成以上成長，市場在懲罰 NVIDIA 那一塊縮水，忽略了其他客戶在補上來。

為什麼是這個倉位／節奏：現在不建倉。它沒有定價權，四大客戶占了近六成營收，賺來的錢幾乎全拿去蓋廠；便宜與否取決於後年盈餘能否兌現，而那正是爭點。驗證後也只能小量持有，護城河只有 C 級。

我最怕什麼：NVIDIA 自己做收發器、共同封裝光學把組裝價值搬走。這兩件事同時發生，資料中心那一半營收會被掏空。

怎麼做：先不買。十一月財報看資料中心有沒有季增、對 NVIDIA 那塊有沒有止跌，兩個都有就買三分之一；明年二月看新客戶放量再補。股價若先跌到三百五十元以下、三個假設沒壞，也可以先買第一段。

這門生意

賣什麼給誰、怎麼收錢：把雷射、光元件與電路組成 800G、1.6T 光模組和資料中心互連設備，賣給網通設備商與雲端巨頭。客戶自己設計，它只負責做。

客戶為什麼離不開：它自己做六到七成的零件、認證週期長，客戶願意給兩到三年的需求能見度。而且它承諾永遠不做自有產品，不跟客戶競爭。

護城河等級、方向與最弱處：護城河 C 級、方向持平。最弱處是定價權：利潤留在晶片與雷射端，它只拿一成二；NVIDIA 那塊的份額正在流失。

我押的三件事，以及什麼時候算我錯

  1. 新客戶補得比 NVIDIA 流失得快，資料中心營收每年仍成長兩成五以上。
    算錯的門檻：資料中心營收連兩季季減，或明年財報年報裡非 NVIDIA 的大客戶不到三家。
  2. 毛利守在一成二、營業利益率守在一成零五以上，成長放緩也不會崩。
    算錯的門檻：營業利益率連三季低於百分之九點五。
  3. 廠蓋完、營運資金不再堆積，自由現金流兩年內轉正。
    算錯的門檻：連續兩個財年自由現金流為負。

我最怕的三件事

  1. ⚡NVIDIA 那塊繼續季減，新客戶又晚一季放量，資料中心總營收連兩季轉負。
  2. 🔥2027 年光模組供給追上需求，客戶開始去庫存，毛利跌破百分之十一點五。
  3. 🐢NVIDIA 自製收發器超過一半、共同封裝把價值搬到晶圓封裝，而它在 2029 年前還沒有相關營收。

市場錯在哪，我跟共識差在哪

市場把它當 NVIDIA 的影子股，看到對 NVIDIA 出貨季減就殺。但 NVIDIA 只剩一成六的營收，資料中心整體反而季增一成三。分歧在於新客戶能不能在十二到十八個月內放量，市場假設不能，我假設部分能。

如果賠錢，最可能是這樣賠的

第一種死法：NVIDIA 自製與共同封裝同時到位，它的組裝價值被抽走，倍數切回代工廠。第二種死法：成長全都兌現了，但每年賺的錢都拿去蓋廠、自由現金流永遠近零，市場給它資本密集代工廠的十二倍，五年後盈餘翻倍股價卻不動。
