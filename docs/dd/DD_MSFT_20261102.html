這是一份「個股深度研究」（DD），從產業、商業模式、護城河到財務體質全面拆解一家公司，最後收斂成一個結論。

結論在哪：報告後段的「統一裁決」——只有三種答案：進場、觀望、迴避，並附建議倉位角色（例如核心或衛星）。可以直接搜尋頁面上的「統一裁決」四個字，或跳到 #decision 錨點。

常見詞：「護城河評等」是公司競爭優勢的等第（S 最強、X 幾乎沒有）；「ROIC」是投入資本報酬率，看公司一塊錢資本能賺回多少；「PEG」是本益成長比（本益比 ÷ 盈餘成長率），數字越低代表相對成長性越便宜。

時效提醒：報告日期寫在檔名與開頭（例如 20260901 即 2026 年 9 月 1 日）。市場會變，這份結論是「當天」的判斷，最新狀態請看 /research/ 的即時清單。

1　白話開場

需求大於供給，但賺到的利潤只有部分變成現金。

  • Microsoft 賺兩種錢。一種是 IT 預算支付的訂閱，包括 M365、Windows 與資安。另一種是業務單位按用量支付的算力與 AI，包括 Azure、Foundry 與 Copilot 點數。FY27 Q1 營收 922.8 億美元，年增 19%，營業利益 459.2 億，營益率 49.8%。Microsoft Cloud 639 億，年增 30%，Azure 年增 48%。
  • 需求面看得到。CFO 說客戶需求仍超過可用供給，Q2 Azure 指引固定匯率 49–50%。商業 RPO 達 6770 億美元，年增 73%，12 個月內認列約 30%，加權平均天期 2.3 年。真正卡住成長的是電力與資料中心殼體，不是客戶下單意願。
  • 報告不建議加碼，原因在現金。Q1 自由現金流 186 億美元，營業利益 459 億，比率只有 41%。FY25 的自由現金流對淨利比是 0.70，FY26 降到 0.50。CFO 本季首次表態，條件合適時會動用租賃以外的外部資金。
  • 價格已經先走一步。股價由前份的 390.54 漲到 521.91，三個月 +33.6%，同期 FY1 共識 EPS 只上修 4.4% 到 20.02 元，Fwd P/E 由約 20.4 倍升到 26.07 倍。估值回到合理區間的中段，安全邊際已經用掉。
  • 什麼會改變看法？往好的方向，是 FY27 到 FY28 任連續兩季自由現金流對淨利比 ≥0.6。往壞的方向，是 OpenAI 縮減或重談算力承諾，OpenAI 約占本季營收 11%，我們估這件事 12 到 24 個月內發生的機率是 15%。統一裁決見§13。

2　論點與三個假設

論點押在三件事：Azure 守住高成長、現金追上淨利、M365 轉向用量計費。

B｜三個假設

#核心假設驗證點具體數字門檻信息來源漂移觸發條件
H1Azure 與 Microsoft Cloud 的高成長由企業廣度撐住，不靠單一客戶；供給逐步解除後，Azure 固定匯率年增仍守在 30% 以上2Y：FY28 每季 Azure 固定匯率年增 ≥30%，Microsoft Cloud 年增 ≥22%FY27 每季 Azure 固定匯率年增 ≥40%；FY28 每季 ≥30%每季財報電話會 CFO 揭露的 Azure 固定匯率成長；新聞稿的 Microsoft Cloud 營收兩年期論點：偏離門檻連 2 季 ≥5% 記削弱，連 3 季 ≥10% 記反轉（例：FY28 連 3 季 Azure 年增 <27%）
H2這輪 AI 資本支出換得回股東現金：折舊高峰過後，自由現金流追上淨利，毛利率止跌5Y：FY29 起 FCF/淨利 ≥0.7，Microsoft Cloud 毛利率 ≥62%；FY27 全年自由現金流維持為正FY28 全年 FCF/淨利 ≥0.6；Microsoft Cloud 毛利率不低於 62%10-Q、10-K 現金流量表（營業現金流減不動產廠房設備現金支出）；季報的 Microsoft Cloud 毛利率五年期論點：偏離門檻連 4 季 ≥5% 記削弱，連 6 季 ≥10% 記反轉
H3M365 由按人頭計費擴展為人頭加用量，由 ARPU 接手席位成長，工作流程入口的地位不被前沿模型公司繞過10Y：到 FY2036，生產力雲營收維持雙位數成長，用量計費占比持續上升M365 商用雲固定匯率年增 ≥15%（席位成長可降到個位數）；Copilot 用量計費客戶數維持季增財報電話會的 M365 商用雲成長、付費席位與 ARPU 拆解；Copilot 點數消費客戶數十年期論點：跨 2 個年度低於門檻記削弱，跨 3 個年度記反轉
  • H1 是成長的廣度。Azure 與 Microsoft Cloud 的高成長要由企業客戶撐住，不能只靠單一客戶。兩年期門檻是 FY27 每季 Azure 固定匯率年增 ≥40%、FY28 每季 ≥30%。本季 48% 與 Q2 指引 49–50% 都在門檻上方，目前沒有偏離。
  • H2 是資本支出換回股東現金。這是五年期論點，條件是折舊高峰過後，自由現金流追上淨利，Microsoft Cloud 毛利率止跌在 62% 以上。FY28 全年自由現金流對淨利比要 ≥0.6，FY29 起 ≥0.7。現值 FY27 Q1 約 0.51，離目標還有距離，這是三個假設裡最弱的一個。
  • H3 是工作入口不被繞過。M365 由按人頭計費擴展為人頭加用量，由單價接手席位成長，十年期要看生產力雲維持雙位數成長。門檻是 M365 商用雲固定匯率年增 ≥15%，本季為 17%（調整後 18%），Q2 指引約 19%，目前達標。
  • 偏離規則先講清楚，避免事後調整標準。兩年期論點偏離門檻連 2 季 ≥5% 記削弱，連 3 季 ≥10% 記反轉。五年期連 4 季記削弱，連 6 季記反轉。十年期跨 2 個年度記削弱，跨 3 個年度記反轉。
  • 三個假設的證據強度不同。H1 有一手財報與電話會，H3 的 Copilot 採用本季只剩管理層描述，席位數不再揭露。H2 需要至少兩年的現金流量表才能驗證。整份論點因此屬於成長已被證實、股東現金尚待證實。

  • 超大規模雲 2026 年資本支出約 6900 億美元（Introl 二手分析）。這是供給端總量，也是未來供需翻轉的來源。電力與資料中心殼體的瓶頸，預計 2026 年底至 2027 年緩解（二手分析，未獨立證實）。緩解後全產業新產能同時上線，租價可能下跌而折舊照提，因此我們把這一點計入 Bear 機率。

  • 利潤池往上游移動。Microsoft Cloud 毛利率年減到 66%，Q2 指引約 65%，管理層歸因於 Azure 組合。10-K 自述 GPU、網通、電力與冷卻等關鍵零組件供應商有限且短缺，競爭者共用同一批供應商，元件漲價直接進資本支出。Microsoft 以自研 Maia 與 Cobalt 晶片部分對沖。
  • 商業 RPO 6770 億美元，年增 73%，是需求最硬的一項證據。結構上要看兩段。12 個月內認列的部分年增 29%，與營收成長一致。12 個月以後認列的部分年增 98%，新增承諾天期拉長，且集中在大額 Azure 合約。這一段的品質取決於 OpenAI 能否履約。
  • 兩項資料缺口要標明。營業利益池五年占比變化，事實表未涵蓋。同業 Fwd P/E 也沒有，終端倍數只能拿 Microsoft 自己三個月前約 20.4 倍與現值 26.07 倍當上下錨。本報告不外推這兩項。

4　品質門檻

生意看得懂，品質高，扣分在資本配置與揭露。

  • 生意看得懂。收費分成訂閱與用量兩軌，決策者也分兩層：訂閱由 IT 出錢，用量由業務單位出錢，Nadella 本季也是這樣描述。使用者是員工與開發者，三個角色都成立。這個結構對一般投資人來說容易追蹤，不需要專業技術判斷。
  • 護城河評 A。執行面 9 分，定價面 8 分，平均 8.5。執行面的證據是 Q1 營收、營業利益與 EPS 全面超標，Azure 交出 48%，高於 7 月指引的約 45%。定價面的證據是 M365 漲價後付費席位仍增 5%，但 E3 與單品銷售偏弱，所以只給 8 分。
  • 資本配置評 B。稀釋股數由 FY23 約 74.75 億降到 FY26 約 74.51 億，三年淨減 0.3%，SBC 占營收 3.4%，這一項過關。回購規模約占市值 0.36%，大致只抵掉 SBC，盈餘殖利率 3.8% 但自由現金流殖利率約 1.5%，回購收益率這一項不過。
  • 併購報酬算不出來。近年最大收購是 Activision，本季 Devices and Consumer 營益率升到 35%，主因是收購無形資產攤銷減少，Xbox 營收年減 2%。投入資本與增量利潤事實表未涵蓋，已實現的增量報酬無從驗證，這一項列為不過。
  • 揭露品質本季退步。7 月法說問答有三題迴避，分別是資本支出的投資報酬、元件漲價對毛利的影響、開源與自訂模型的營收貢獻。本季又不更新 Copilot 付費席位數（7 月時說超過 3000 萬），而同期有集體訴訟指控誇大 Copilot 採用。管理層信用因此打折，列入監測。

社會容忍度美國 FTC、英國 CMA、歐盟同時在審視綑綁與雲端授權折扣，10-K 自述可能遭罰款或被限制產品提供；各國也在推主權雲。監管把實際定價上限壓在經濟上限之下。還不到紅燈，因為仍在調查階段，尚未成案。

  • 護城河的機制是轉換成本加規模。企業身分（Entra）、M365 資料圖譜（Work IQ）與 Azure 合約綁在同一套授權裡，客戶要換的是整套工作流程，不是單一產品。平台層（Foundry、Fusion）可以替換模型，所以模型層可以每個任務換供應商，但換的是 Microsoft 平台上的模型，不是平台本身。模型商在這個平台上互相競價，Microsoft 收的是過路費。商業 RPO 加權平均天期 2.3 年，也說明合約綁定的期間不短。
  • 趨勢判穩定，因為一項擴大、一項持平。執行面 9 分，擴大：Azure 份額由 20% 升到 21%，年增由 7 月指引的約 45% 交出 48%，GB300 從到貨到上線的時間季減約 20%。定價面 8 分，持平：M365 漲價後付費席位仍增 5%，token 單價高於預期，但 E3 與單品銷售執行偏弱。兩項平均 8.5 分，等級 A，趨勢標為持平，E3 弱勢列入監測。

  • 周轉率下滑是這一章最大的保留。Q1 現金資本支出年增 103%，營收只增 19%，象限落在高利益率、周轉率下滑。這輪資本支出約四分之三是 CPU、GPU 短壽資產，更新週期短，再投資負擔比軟體同業重。護城河保住了利潤率，卻沒有保住現金轉換，FCF/淨利 FY26 為 0.50，所以本章結論是等級 A 但不加碼，見§13。

11　矛盾點與裁定

五組矛盾中，營收側都能調和，現金側尚未證實。

  • 需求強度對訂單。Azure 年增 48%，商業 RPO 6770 億美元、年增 73%，但商業訂單年減 12%。裁定可調和，訂單年減來自去年同期大額 Azure 承諾的高基期，12 個月內認列的 RPO 增 29%，與營收成長一致。RPO 中 12 個月以後認列的部分年增 98%，品質取決於 OpenAI 能否履約，交給唯一致命點監測。
  • 營業利益對股東現金。營業利益增 21%，但自由現金流 186 億只有營業利益的 41%。裁定可調和但尚未證實，差額是建置期的時間差，前提是新產能上線即變現。證據到位之前，這是續抱不加碼的唯一約束。價格若先走而 FCF/淨利仍 <0.6，則不追。
  • 管理層前後說法。雲端的兌現優於承諾，Azure 與營益率兩項超標。資本支出下修是延後，不是節省。Windows 裝置端與 Copilot 席位揭露則是退步。裁定：若 FY27 Q2 仍不揭露席位，且 M365 商用雲年增 <17%，H3 記削弱並停止加碼。
  • 客戶集中度。FY26 年報說沒有單一客戶超過營收一成，OpenAI 約 7%。本季分析師提問指出約 11%，應收從 60 億升到 72 億美元。裁定採納為唯一致命點。7 月 CFO 稱雲營收近九成來自前沿模型公司以外，那是全年口徑且早於本季，不降級。
  • 反方最強理由：現在就加碼。Azure Q2 指引高於預期，FY1 至 FY3 共識分別上修 1.3%、1.9%、3.2%，PEG 約 1.15，營業現金流年增 29%。裁定不採納，約束在現金，不在營收。但若 FY27 Q2 的 FCF/淨利 ≥0.6，且 Azure 固定匯率 ≥45%，先加碼半份，下一季確認後補足。

12　最可能怎麼賠

最可能的賠法在現金轉換與 OpenAI，不在 Azure 需求。

  • 論點失敗：OpenAI 縮減承諾。OpenAI 約占本季營收 11%，FY26 Q2 時占商業 RPO 約 45%，自身靠外部融資支付算力。電力瓶頸若在 2027 至 2028 年解除，全產業產能同時上線，GPU 租價下跌而折舊照提。EPS 五年持平，倍數壓到 16 倍，五年虧 30% 到 50%。發生機率約 15%，一旦觸發部位減半。
  • 論點成功但股東經濟變差：Azure 目標全部達成，但每年約 1700 億美元的資本支出、元件漲價與融資租賃利息，讓 FCF/淨利長期卡在 0.5。股東拿到的現金成長遠低於 EPS 成長，倍數向資本密集型公司靠攏。三盞衰退燈都指向這件事，所以本次採納為不加碼的唯一約束。
  • 價格已反映太多：三個月漲幅 33.6%，FY1 共識 EPS 只上修 4.4%。若 Fwd P/E 在現金轉換未改善時越過 32 倍，約 640 美元，報酬風險比就轉差。目前基本情境年化約 12%，不算差，但安全邊際已經用掉。
  • 另一條論點失敗路徑在 M365。10-K 自承多數業務進入門檻低，Ramp 數據中企業 AI 支出 Anthropic 占 37%、OpenAI 占 33%，不含 Microsoft。付費席位只增 5%，若降到 2% 以下且商用雲年增 <12% 連兩季，用量計費的錢就被前沿模型公司拿走，H3 失效。
  • 回撤範圍估 −30% 至 −45%，路徑風險為黃燈。下緣對應 Bear 價 352 附近，歷史最大回撤事實表未涵蓋，只知道 2026-01-29 單日跌約 10%。反壟斷與 Copilot 集體訴訟的金額與時點也未涵蓋，屬額外的尾端風險，監管若成案會直接限制授權折扣機制。

13　統一裁決

觀望　角色：追蹤。續抱不追價，等現金轉換證實。

  • 新資金：不追價，暫不進場。現價 521.91 美元已把安全邊際用掉，營收成長我大致相信，現金轉換還沒有證據。重啟條件是 FY27 至 FY28 任連續兩季自由現金流÷淨利 ≥0.6，這是事件錨，不設價位。若股價先跌至 W104 均線約 448 以下，而 Azure 固定匯率 ≥40%、FCF/淨利不低於 0.45，則分批反買三分之一，這不是停損。
  • 已持有：續抱，不加碼。持有年限沿用前份上限，不因本次上調。若 Fwd P/E 達 32 倍（約 640 美元）而 FCF/淨利仍 <0.6，減碼 20%。OpenAI 公開縮減、延後或重談算力承諾，或應收提列減損，減碼一半。
  • 減碼與清倉：五項指標任一觸發減碼三分之一，任兩項同時觸發清倉。五項為 FCF/淨利連兩季 <0.35 或 FY27 全年自由現金流轉負，OpenAI 占營收 >15%、應收 >100 億美元或提列呆帳，Azure 固定匯率連兩季 <30%，Microsoft Cloud 毛利率 <62%，12 個月內認列 RPO 年增連兩季 <20%。目前 FCF/淨利與 OpenAI 兩項處於警戒，其餘正常。
  • 放寬條件：FY27 Q2 若 FCF/淨利 ≥0.6 且 Azure 固定匯率 ≥45%，先加碼半份，Q3 確認後補足。反壟斷正式起訴或 Copilot 集體訴訟進入集體認證，則停止加碼並重跑研究。下次複審在 FY27 Q2 財報發布後一週內。
