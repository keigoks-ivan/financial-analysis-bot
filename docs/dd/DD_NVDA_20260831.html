這是一份「個股深度研究」（DD），從產業、商業模式、護城河到財務體質全面拆解一家公司，最後收斂成一個結論。

結論在哪：報告後段的「統一裁決」——只有三種答案：進場、觀望、迴避，並附建議倉位角色（例如核心或衛星）。可以直接搜尋頁面上的「統一裁決」四個字，或跳到 #decision 錨點。

常見詞：「護城河評等」是公司競爭優勢的等第（S 最強、X 幾乎沒有）；「ROIC」是投入資本報酬率，看公司一塊錢資本能賺回多少；「PEG」是本益成長比（本益比 ÷ 盈餘成長率），數字越低代表相對成長性越便宜。

時效提醒：報告日期寫在檔名與開頭（例如 20260901 即 2026 年 9 月 1 日）。市場會變，這份結論是「當天」的判斷，最新狀態請看 /research/ 的即時清單。

§2｜投資論點錨定

存在意義：NVDA 賣的不是晶片，是把「運算」變成可規模化生成智能的工廠——GPU 硬體 × CUDA 軟體生態（20 年、數百萬開發者鎖定）× NVLink/網路/機櫃系統整合，三者疊加把單一零件銷售升級為不可拆分的 AI 基礎設施平台。若它明天消失，全球雲端訓練與推論能力會在數年內找不到等效替代——這不是「效率提升」的空泛答案，是具體的運算供給斷點。
逆向一句化：3 年虧 50% 最可能路徑——① custom ASIC 從 inference 進逼 training、CUDA 鎖定被繞過（技術替代）；② HBM／memory 結構性漲價 + AI capex 於 2027-28 進入 digestion + circular financing 網絡任一環節信用事件，三者收斂觸發估值與盈餘雙殺（週期＋反身性）。

§5.R 報酬持續期檢核（ROIC durability）

當期 ROIC 定位：ROIC（NOPAT／期末投入資本）FY26 為 66.8%（NOPAT $110.7B／投入資本 $165.76B），FY25 為 80.4%，呈現「高利益率 + 中高周轉」的混合象限——比典型資產最輕的 Visa/Moody's（高利益率×高周轉）略重（因需自建龐大庫存/預付以鎖定 memory 供應），但遠比先進製程晶圓廠/機場等重資產基礎設施輕。

檢查點判讀證據
①需求基礎值🟢🟡「compute equals revenue」已從想要轉為需要（hyperscaler 自身財報驗證：Meta GEM 模型帶動廣告轉換率提升、Anthropic/OpenAI 營收爆發性成長）；但供給端全面吃緊（管理層自陳供給僅能支撐 ~70% 成長、需求超過此水準），使真實需求曲線頂部無法獨立觀察，屬誠實的資料限制
②決策層級🟢（training）/🟡（inference 租用）客戶決定的是「整座 AI 工廠」而非單一 GPU（rack-scale/CUDA/多年供應鏈承諾），轉換成本高；但純 inference API 租用的決策粒度可下沉至單一請求路由層級，轉換成本大幅降低——這正是 custom ASIC 攻擊 inference 的切入點，也是 moat_trend 維持 → 而非 ↑ 的核心理由
③價值鏈分配🟡（新增追蹤）HBM/memory 供應商（SK 海力士/三星/美光）2026 下半年重新拿回利益分配（NVDA GM guide 75.0%→71-72%，supply commitments 由 $119B 跳增至 $279B「主要與 memory 採購有關」）——重要互補品供應收斂與緊張，符合教科書式的利益分配位移信號
④社會容忍度🟡尚未觸及消費者可感知的定價天花板，但三條政策軸正在加溫：中國出口管制（已將最先進產品完全排除在外的地緣政治先例）＋ DOJ/FTC 反壟斷調查（正式檢視「是否讓客戶難以轉換供應商」，屬「定價逼近上限招致監管介入」的典型訊號，仍在調查階段未有裁罰）＋ 中國 SAMR 已於 2025-09-15 認定 NVIDIA 違反《反壟斷法》（詳見 §9），是三者中唯一已有不利認定落地的一案，惟迄今未見最終罰則

增量 ROIC × 再投資率：增量 NOPAT（FY25→26）$40.1B ÷ 增量投入資本 $77.97B ＝ 增量 ROIC 51.4%（低於當期 66.8%，反映策略性投資與大額預付/庫存稀釋短期報酬）；再投資率（增量投入資本／NOPAT）＝ 70.4%；內生成長天花板 ＝ 51.4% × 70.4% ＝ 36.2%，高於共識 EPS CAGR（FY27-29 兩年 32.7%）——sanity check 通過，內生資本再投放能力足以支撐目前的成長路徑，非靠外部融資堆疊出來的成長。

綜合定位：當期 ROIC 頂尖、持續期四檢查點 2 綠 2 黃（決策層級與價值鏈分配是本輪新增的追蹤重點）、增量 ROIC 天花板通過共識交叉檢查。整體判讀：training/平台級複利引擎持續期長且穩固，inference 租用層與 memory 供應鏈議價力是未來 12-24 個月最需要盯的兩條裂縫，但尚未構成 moat 降級的充分證據。
