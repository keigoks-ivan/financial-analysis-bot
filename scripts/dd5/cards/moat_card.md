# 護城河判斷（競爭結構版，2026-11-27 起）

程式數字 R 在 `moat_long.json`（引用標記 `[p:moat_long]`），事實檔 F 是上網查一次後凍結的八格（F1～F8），每格附出處連結。

要回答的問題只有一個：**對手為什麼搶不走這家公司的利潤？未來五到十年還搶不走嗎？**
報酬率是護城河留下的結果，不是護城河本身。先看競爭結構，報酬率最後才拿來否決。

## 第一步：找來源（最多兩個主要來源）

從下面五種挑，每一種都要附查得到的證據。證據分三級：第三方（研調、客戶、對手、主管機關、媒體實測）＞ 公司公布的數字 ＞ 管理層說法。

| 來源 | 是什麼 | 可以拿來當證據的 |
|---|---|---|
| 轉換成本 | 客戶換供應商要付出時間、錢或風險 | 認證或設計導入要多久、客戶有沒有二供、合約年限、續約率、軟體／生態綁定 |
| 網路效應 | 用的人越多，對每個使用者越有價值 | 雙邊用戶數、份額越來越集中 |
| 成本優勢 | 規模、製程、良率、地點讓單位成本比對手低 | 同一種產品毛利率或營益率高於對手、對手價格跟不上 |
| 無形資產 | 專利、牌照、法規、品牌讓它能多收錢或擋人 | 售價溢價、專利訴訟結果、牌照家數 |
| 有效規模 | 市場只容得下少數幾家，新進者進來大家都賺不到 | 全球家數、近十年新進者數與下場 |

找不到任何一種來源時，寫「找不到結構來源」，寬度直接是「無」。報酬率再高也一樣，只能寫成「報酬率高，但查不到對手為什麼搶不走」。

## 第二步：查侵蝕（四項都要查，查不到就寫查不到）

每項給燈號：綠（沒有侵蝕）、黃（有跡象）、紅（正在發生）、查不到。

1. **份額**：第三方市占與最近兩三年的變化。
2. **新進者與替代**：近三年有沒有新進者拿到份額、客戶有沒有自製、有沒有替代技術。
3. **客戶議價**：前幾大客戶占營收多少、客戶能不能壓價、改寄售或指定二供。
4. **下行年**：只用程式算的 R3（2012～2025，本檔或同業營收年減 ≥5% 的年度）。
   - 同業掉了、本檔沒掉（self_fell: false）：守住，綠燈，這是很強的證據。
   - 本檔也掉了：毛利率相對掉幅（gm_rel_drop_pct）不超過 10% 算守住（綠），超過是紅。沒有毛利率的公司（支付網路、評等、航空等）改看營益率相對掉幅，不超過 20% 算守住。
   - 有好幾個下行年時，看最近兩次；一次守住一次沒守住記黃。
   - 營收下滑如果是分拆、出售事業、改變營收認列造成，不算下行年；要寫出依據（事實檔或營收、毛利率數字的明顯跳動），沒有依據就照下行年處理。
   - R3 寫「未經下行」時，改看 2021～2022 成本大漲年：毛利率相對掉幅不超過 10% 記綠（代理），超過記黃；沒有毛利率的公司改看營益率，相對掉幅不超過 20% 記綠（代理）。不能拿營收還在成長的一般年度當證據。
   - 下行年那時，護城河來源所在的生意（例如評等、企業軟體授權、高階載板）如果還不到營收三成，這次下行不能拿來證明守住，最多黃燈；三成以上就照實判。生意名稱改了但護城河來源相同（例如企業軟體從授權變訂閱），算同一個生意。

**燈號的門檻（四項通用）：**
- 紅：侵蝕已經發生，而且有數字：份額三年掉 ≥5 個百分點、新進者／客戶自製／替代技術三年合計多拿 ≥5 個百分點、下行年毛利率相對掉幅超過 10%、客戶已經把可以量到的訂單或份額移給第二供應商。
- 黃：有跡象，但還沒反映在份額或毛利率上（客戶宣布找二供、對手通過認證、傳聞、預估），或已發生但量很小。
- 綠：查到數字，沒有侵蝕。
- 查不到：不能當成綠燈。
還沒發生的威脅寫進 warnings，寫明哪個數字出現就算成真。

## 第三步：判寬度（看完全部證據後綜合判斷，下面是底線）

- **寬**：至少一個來源有第三方或公司公布的硬數字；侵蝕四項沒有紅燈；四項裡至少三項不是「查不到」（份額只有一個時點的研調或券商估計也算有數字，要標明）；下行年不是紅燈（黃燈或未經下行檢驗不擋寬，但要在證據強度與預警寫出來）；報酬率否決沒有觸發。
- **窄**：有來源，但證據只有管理層說法；或侵蝕有一項紅燈；或下行年沒守住但份額守住；或寬的條件只差查不到。
- **無**：找不到結構來源；或侵蝕有兩項以上紅燈；或下行年沒守住且份額也在掉。

**營益率比對手低，不等於沒有來源。** 先看原因：售價比對手低、營益率只低一點，是把成本優勢讓給客戶，要算成本優勢的證據；是第二名打不過第一名，才是結構不夠。

**報酬率否決（只能往下壓，不能往上拉，用程式算的 R1，2016～2025 十年）：**
- 十年平均（avg_2016_2025）低於 10%（約等於資本成本）→ 最高「窄」。
- 十年平均低於 10%，而且十年最低（min_2016_2025）低於 5% → 最高「無」。
- 併購多、商譽大的公司（例如博通）R1 會被壓低，改看 R2 營益率對對手；權益是負的或資本基數很小（ic_negative_years 有值、small_base: true，或報酬率動輒上百）的不做否決，也不能因為報酬率高就升級。
- 循環股十年最低要 ≥10% 才可以列寬。循環股指記憶體、載板、面板、鋼鐵、石化、航運、航空、汽車、原物料這類，或程式標 cyclical_hint: true 的；程式有標但你判斷不是循環股，要寫理由。

**證據強度**另外寫：強（來源與份額都是研調或公司公布、沒有查不到）、中（份額是券商或媒體估計，或有一項查不到）、弱（兩項以上查不到，或來源只有說法）。

**走勢**（變強／持平／變弱）：看侵蝕四項的方向，加上報酬率對同業的差距。要兩年以上的數字，單季或景氣高峰年不能當唯一證據；只是預警的事不算變弱。

## 規矩

- 只能用程式數字（R）、事實檔（F）和研究正文裡附了出處的事實。憑記憶的數字一律不能用，查不到就寫查不到。
- 不給買賣建議、目標價、機率。
- 中文、白話、結論先行。
