## 讀法與注意

- 「kind」：table＝`.tbl`／`.era`／`.pos` 外框內的完整表格；chart＝`.chart-wrap` 內的 SVG（多系列時前面附 `.legend`）；block＝非表非圖的資料標記。
- 所有 key 的 HTML 已含自己的外框（`.tbl` 等）。**不含**：`<figure>`／`<figcaption>`（圖說見表中「內容」欄，格式為「標題 —— 副標；aria 說明」）、`<details>`／`<summary>`（`q1_ep_table`、`q3_spdr_table`、`q4_edhec_table`、`tw_sector_yearly` 原本放在 details 內，summary 原文見「內容」欄 details: …）、各面向的 `<div class="angle">` 與 `<h3>`。
- 圖表的滑鼠提示靠 `v2_script.txt`（讀 `data-tip` 屬性），合併頁需帶同一段 script。
- `top_years`：主報告頂端 `.now-grid` 的 6 張卡（4 個年度報酬、CAPE、10 年期美債）。原本緊接其後的 `<small>` 說明句（含第 87／99 百分位、SPY 含息至 2026-09-30）在 key 之外，由寫作者重寫。
- `q2_country_chips`：16 國相關係數的 chip 列，已含 `<div class="chips" aria-label="各國相關係數">` 外框。
- `now_pos`：續篇「現在在歷史中的位置」百分位表（7 列加科技業佔市值 1 列，共 8 條 meter）。表後的 `<p class="note">` 說明句（「百分位＝歷史上比現在更便宜…」）在 key 之外。
- 刻意不做 placeholder：主報告 `.answers` 4 張卡與 `vs()` 四個框、續篇 `.answers` 8 張卡與每節 `.effect` 框、各節 oneline／how／angle 文字、更新後的結論 `<ol>`、方法節、header／toc／footer。`#synth` 總表（主報告）也未做 placeholder，因為內容是結論句不是資料；全文列在下面，若要保留可在 `frags_merged.py` 加一行。
- `q2_scatter` 的圖例（兩個 dotkey：「起始年份」「標註：1920、1928、1967、1974、1979、1999」）原寫在 `fig()` 外框內，不在 key 內。

### 兩頁 extra CSS 的衝突（合併時必須處理）

- `.chip`：主報告的 `.chip`（`.chips` 容器內的相關係數小丸，`inline-flex`、含 `<b>`）與續篇的 `.chip`（結論標籤 `.chip.fix|up|down|new`，`inline-block`、粗體、邊框同色）是兩套不同樣式。`q2_country_chips` 的 fragment 用主報告版；續篇的 `.effect`／`.answers` 用續篇版。合併頁 CSS 要把其中一套改名（例如把國別 chip 限定在 `.chips .chip`），否則其中一邊會跑版。
- `.angle h3`：主報告 1.05rem＋flex（內含 `.tag` 面向字母）；續篇 1.02rem、無 flex。`.oneline`：1.22rem 對 1.18rem。這兩個在 fragment 外，不影響 placeholder，但影響合併頁整體樣式。
- fragment 內的內嵌樣式依賴 CSS 變數 `--s1`／`--s2`／`--neg`／`--muted`／`--grid`／`--ink`（定義在 v2_css.txt 的 `:root`），表格色階用 `color-mix(in srgb, var(--s1) N%, transparent)`。
