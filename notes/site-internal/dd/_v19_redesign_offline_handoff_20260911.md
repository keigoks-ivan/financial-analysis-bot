- `dd_project.research_sections` 直接生成十三個正文區塊，保留反證的證據、後果、裁定與追蹤條件，接現有版面與資料表。v19 不再派獨立散文模型，舊版回放與快速版保留。

## 離線驗證與界線

完整離線回歸 469 項全過，Python 3.9 語法檢查通過。新測試涵蓋來源逐值保留、最新逐字稿快照、引用定位、PFAS 理由被吞的反例、非法評級、修補保留原件、真實候選計算鏈、修補次數、完整性未過的阻擋、Codex 輸出與用量、獨立審核接線，以及現有模板的直接組頁。

Codex 的長輸出測試使用假 CLI 回覆驗證接收端不截斷；它不代表實際模型一定能寫完。未使用 `--output-schema` 冒充整份舊 schema 已相容受約束輸出；目前是直接 JSON 回傳後以既有驗證器驗收。CLI 指令與事件格式依本機 `codex exec --help` 及官方文件核對。

尚未證明研究品質與成本不退步。FIX 舊資料中的缺口未由程式捏造補齊；下一步須先確認資料和 CLI 登入，再以凍結材料做獨立品質對照。若要全新公司從零收集也不使用 Claude，還要另外遷移資料收集端，本輪不假稱已完成該範圍。

## 與單一 prompt 的關係

研究方法可以整理成單一 prompt。skill 是指令與相關資源的包裝，不是額外的推理能力；把同樣材料改成 prompt 並不能自行消除重複規則。研究 prompt 負責判斷與文字，既有程式負責可確定計算與檢查，獨立審核負責找錯。此次沒有改動 skill，也未宣稱單次 prompt 已證明與現流程等質。
