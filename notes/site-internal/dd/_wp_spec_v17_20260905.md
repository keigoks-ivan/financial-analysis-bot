## WP1b Stage 0 part 交稿即驗＋`finalize`（finding 編 id）
**擁有**：`scripts/validate_evidence.py`（加功能不改既有檢查語意）、`scripts/dd_evidence.py`（加 `finalize` 子命令）。**不動** coverage-axes.md 與其他檔。

功能：
1. `validate_evidence.py`：把 `check_file` 內對「單一軸」的檢查（status 合法、found 需 findings 且每條 claim/source/as_of 齊、as_of 可解析、none 需 queries_run ≥2、not_applicable 需 na_allowed＋理由）抽成 `check_axis(axis_id, axis_obj, matrix) -> (fails, warns)`，`check_file` 改呼叫它（輸出文字不變）。新增 `--part FILE`：對 part 檔（形狀 `{"coverage": {...}, "events"?: {...}}`，也接受 `numbers_*`／`prior` 類 part 時只驗 JSON 可解析並印 `skip`）逐軸跑 `check_axis`，任一 FAIL exit 1，訊息含軸名與缺哪個欄。
2. `dd_evidence.py finalize --run-dir DIR`（或 `--parts DIR --out FILE`）：依固定順序 merge `parts/` 內所有 `*.json`（prior → numbers_extra → numbers_collect|numbers_agent|numbers_flat → axes_*|batch* → events → transcripts → digest_path），merge 前逐 part 跑 `check_axis`（用 import，不 subprocess），FAIL 的 part 不 merge、列入「需重派」清單；merge 後**給每條 finding 加 `id`＝`{axis_id}#{index}`**（index 為該軸 findings 順序，從 0），已有 id 不覆寫；最後跑 strict 驗證，印 `PASS`／`FAIL`＋重派清單，exit 對應。
3. merge 語意沿用既有 `merge`（深合併，list 接尾或覆蓋，照既有），不重寫。

**驗收**：

## WP1c 無頭執行器 `scripts/dd_headless.py`
**擁有**：新檔 `scripts/dd_headless.py`、測試 `scripts/tests/test_dd_headless.py`（若 `scripts/tests/` 不存在則建）。**不動**其他檔。

功能：
1. `spawn(prompt_path, model, allowed_tools, max_turns, budget_cache_read, out_json, cwd=None, extra_args=None) -> dict`：以 subprocess 執行 `claude -p "$(cat prompt)" --model {model} --allowedTools {tools...} --max-turns N --output-format json`（prompt 由 stdin 或參數傳入，實作擇一並註明；binary 由環境變數 `DD_CLAUDE_BIN` 覆寫，預設 `claude`）。解析回傳 JSON：`result`、`num_turns`、`is_error`、`usage.{cache_read_input_tokens,cache_creation_input_tokens,output_tokens}`、`modelUsage{model:{cacheReadInputTokens,cacheCreationInputTokens,outputTokens,webSearchRequests}}`、`total_cost_usd`、`duration_ms`。回傳 dict：`{ok, num_turns, cache_read（modelUsage 各模型 cacheReadInputTokens 加總）, cache_creation, output_tokens, by_model, over_budget: cache_read > budget_cache_read, cost_usd, duration_ms, result_text, raw_path}`；原始 JSON 寫到 `out_json`。
2. `spawn_many(specs, max_parallel=4) -> list`：用 `concurrent.futures.ThreadPoolExecutor` 平行執行，spec 形狀＝WP1a 的 `spawn_list.json` 元素＋`run_dir`。
3. CLI：`dd_headless.py --prompt FILE --model sonnet --tools WebSearch Read Write --max-turns 4 --budget 2000000 --out FILE [--setting-sources user]`；印一行 `model／turns／cache_read／output／over_budget`。
4. **兩個實測並寫進檔頭 docstring**（各一次呼叫，prompt＝「只回 OK」，`--max-turns 1`，model sonnet）：(i) 預設 vs `--setting-sources user` 的 `cache_read_input_tokens`（驗證能否略過專案 CLAUDE.md，基準約 78K）；(ii) `--model fable` 是否被接受（回傳 modelUsage 的模型名）。若某旗標不存在，記錄錯誤訊息，不要硬試。
5. 已知回傳形狀樣本（2026-09-05 實測，供假 binary 測試用）：
