8　最新一季財報與指引

Q3 營運數字創紀錄，但費用指引也跟著上修。

  • Q3 總營收年增 12.4%，資產費營收年增 25%，訂閱營收年增 8%，調整後每股獲利年增 14%。四項都在往上走，其中資產費是跟著股市與 ETF 資金流起落的部分，品質比訂閱低一層。
  • Index 有機訂閱 run rate 年增 11.7%，Q2 是 11.1%，逐季加速。這是論點 H1 的核心指標，門檻是年增 10%，目前有緩衝。Analytics 有機訂閱 run rate 年增 7.5%，Q2 為 6.6%，也在回升。
  • 總留存率約 95%，年增 30bp，Index 留存逾 97%，資產管理客戶約 98%。客戶黏著沒有被 AI 與自建侵蝕的跡象，這是 Q3 對論點最有利的一項證據。
  • 永續與氣候分部仍是弱點。Climate run rate 年增 8%，Q3 出現一筆大額縮單，管理層把 Q4 淨新銷售改說持平到小幅正。私募資本方案 run rate 年增 19%，客製指數年增 26%，Real Assets 只有 2%。
  • 指引面偏保守。2026 費用指引在 Q2 上修，Q3 再說會落在上緣，利息費用指引也上調。自由現金流指引維持 14.85 到 15.45 億美元，沒有隨超預期的 Q3 調高。共識 FY1 EPS 近期反而下修 0.76%。
