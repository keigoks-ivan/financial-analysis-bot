# DD 規則必要性審查：第一輪

日期：2026-09-10。這是一份候選精簡方案，不是已修改的 skill，也不是規則退役裁決。未跑股票 DD、模型或發布流程。

## 一、這輪裁定的方向

保留基本面研究的深度，減少「每個問題都另寫一份答案、每個可能性都另建一套數字」的義務。不要另蓋 quick DD／lite DD 平行系統。

審查範圍：現行 ddreport／stock-analyst 入口、judgment-rules 全文、ROIC durability、32 條 judgment-playbook、timing-appendix、decision-layer、coverage-axes、摘要派工與 schema 的必要欄位，以及 rule ledger 的相關治理紀錄。產業專用換尺本輪保留，沒有逐一審定其門檻有效性。

重要限制：這輪確認的是要求及相依關係，不是每條規則的真實耗時排名，也沒有完成救援／誤傷效果的歷史校準。下列「退役」均指提名，不表示已有證據滿足既有 kill condition。

## 二、每份 DD 必須回答的七個核心問題

| 核心 | 必須留下的研究成果 |
|---|---|
| 商業本質 | 誰付錢、為什麼買、單位經濟與營收品質、主要分部及真正獲利來源。 |
| 產業與競爭 | 需求是否持久、競爭者如何搶走利益、客戶／供應商／政策單點，以及近期重大變化。正反方向都看。 |
| 護城河與報酬持續期 | 優勢機制、目前強度與方向分開看，ROIC 的來源，新增資本是否仍能賺超額報酬。 |
| 成長與資金需求 | 成長靠量、價、組合、併購還是回購；長大是否改善股東經濟利益，能持續多久。 |
| 財務品質與存續 | 盈餘能否變現金、營運資金與稀釋、債務及再融資、景氣下行的承受力。 |
| 治理與資本配置 | 激勵與股權、重要內部人交易、管理層如何使用現金，以及承諾和結果是否相符。 |
| 價格、反證與裁決 | 現價隱含的期待、情境報酬與永久損失風險、最強反對意見、買／等／不買的理由，以及何種證據改變主意。 |

原有用戶筆記、已掛證偽條件與前次研究照讀；不能因為精簡而略過。關鍵數字須來源、期間與口徑一致；重大缺料要明示，不能補成樂觀假設。

以上是研究骨架，不是每節固定篇幅。複雜公司可以寫得很深，簡單公司不必為湊七張表重複敘述。

## 三、第一批可合併／移出模型手寫的工作

### A1．把「想錯在哪」合併成一份反證與風險紀錄

現況：judgment-rules §12 的 steelman、§13 的 pre-mortem、§18 的自我攻擊與 trap 五問，以及 plain.fears／how_to_lose，多處要求相近內容。

提案：共用一份「證據 → 受影響假設 → 財務／估值後果 → 採納或反駁 → 觀測點」紀錄。保留三個不同視角：論點失敗、論點成功但經濟性變差、價格已反映太多期待；不把三者抹成同一種風險。各頁只引用或渲染，不要求模型每處重寫。

代價與防護：可能減少不同問法帶來的第二次思考；保留独立 reviewer，驗這三個視角是否有實質處理，不驗是否各有一段漂亮散文。

### A2．同一組增量資本報酬只推導一次

現況：§5.R／§6.D 都要求 ROIIC、再投資率與內生成長上界，§10 再核對 EPS 成長。

提案：同一個計算來源，保留三種不同判斷用途：現有資產報酬、新投資報酬、成長假設是否合理；數字不用重新抄算，解釋只寫不同之處。

防護：不可把營運成長與每股盈餘成長當成相同口徑；SBC、回購、margin、收購與負營運資金要另辨。並非把任何 ROIIC 乘式當成所有公司的硬天花板。

### A3．一份可讀的結論，不另手寫多套同義版本

現況：同時有 oneliner、thesis、reasoning、plain，以及機械輸出 decision_out。

提案：判斷模型直接寫可讀且有證據的核心解釋；頁首短句與基本面正文保留不同用途，但 fears、bets、change_my_mind 等優先由同一份內容產出。必要的簡短總結可以保留，不要求每欄全由模型重新表達。

防護：程式只能組裝既有事實和文字，不能把任意 JSON 轉換成新的投資論證；展示不可省略來源限定與不確定性。

### A4．20 欄漂移保留機械帳，文字按原因合併

現況：judgment-rules §12.3b 要每個變動欄位各寫獨立 contradictions 條目。現價一次變動，可能連帶改 IRR、EV、AR、估值燈與裁決。

提案：20 欄仍逐欄記錄新舊值；文字按「價格變動／新證據／方法變動」建立原因，讓多個欄位引用同一原因。裁決、核心假設與情境方法改變仍需實質解釋。

防護：每個變動欄位都必須映射原因，不能以一句「更新數據」掩蓋方法改變。需同步改驗證契約，不能只叫 writer 少寫。

### A5．機械計算與發布保持在程式層

估值公式、情境算術、股價位置、欄位轉換、HTML、網站同步與數字一致性驗證，不能變成判斷模型的重複工作。

現況辨別：情境計算、決策矩陣與快速版渲染已經機械化，這些不是本輪新增的節省。保留其檢查；重點是取消殘留的人工抄寫要求，而不是再加一層 agent。

## 四、第二批：把強制展開改成有理由才深入

這批涉及研究充分性及裁決輸入，需要核准後調整規則、schema／validator 與消費端；不能只刪 prompt。

| 編號／現行要求 | 我的提案／何時仍必做 | 代價與防護 |
|---|---|---|
| B1．§3.F 逐分部 TAM、SAM、滲透率、五年利潤池 | 每次仍理解市場邊界與利益流向；只有估值依賴低滲透、份額擴張、新品類或利潤池遷移時，才建立完整量化表。 | 會減少全面市場地圖；不得略過次要但高風險／高獲利／新成長分部，不能只看營收占比。 |
| B2．§6.I 所有 >10% 營收段三年量價與 margin 模型 | 先交完整分部地圖。重要分部驅動不同、mix 決定利潤、或合併預估掩蓋衰退時，展開分部模型；其餘可用合併驅動模型。 | 較粗模型可能漏 mix；獨立 reviewer 必須檢查合併模型是否掩蓋分部風險。 |
| B3．§9.D 十年併購全史與逐案 ROIIC | 激勵、資本配置與重要交易仍每次查；連續收購型公司、重大新交易或併購支撐成長時，才逐案深挖。其餘有機公司不用硬湊十年故事。 | 可能降低長期管理能力辨識；已知重要失敗交易仍須納入，不以年份截斷掩蓋。 |
| B4．§10 全套歷史倍數、PEG 多窗口、賣方目標價 | 主估值模型加真正獨立的交叉檢查；兩者衝突或結論靠 re-rate 才新增模型。共識 EPS／guidance 仍保留，目標價不是每檔必要論證。 | 會減少橫向標準化；現行 val 燈依賴 PEG／分位，過渡期仍需提供這兩項，不可直接略掉。 |
| B5．§9 無条件追加 10Y 壓測與長跑道延伸 | 論點或目前價格真正依賴第六年以後收益時必做；其他維持有意義的主要持有期分析。 | 可能低估長久期價值；要先檢查估值是否靠遠期終值，不可因難估就省掉承重假設。 |
| B6．§12／§13 每個假設固定 2Y／5Y／10Y、每個矛盾兩條交易分支 | 依假設可觀測時間窗給指標、來源、期限與反向條件；同一風險不用硬配三種期限。 | 降低版型可比性；有長期論點仍須長期證據，不可只剩下一季財報。 |
| B7．QC-53 的 32 條情境手冊 | 它本來就是条件式，不是新發現。保留作問題字典；審查「寫觀望就命中 1–4」「三個不確定假設就命中 16–17」等廣泛觸發，答案若核心研究已涵蓋即引用，不再逐條作文。 | 可能少一次提醒；保留新事件與特殊風險提示，不能只由 writer 自稱已答完。 |
| B8．12 個 common 軸及分部展開的固定查詢 | 保留全面風險初掃；共用來源可一次支撐多軸。有暴露、異常、來源衝突或重要缺料再加深，不要求每軸獨立湊查詢次數。 | 有未見風險的漏查代價；N/A 要基於業務／來源，不能因沒查到就說不適用。不能以快取過期或來源失敗當成無事。 |
| B9．舊三季與所有 optional 逐字稿逐篇摘要、每篇 ≥12 條 | 最新季的重要證據照讀；舊稿保留已驗證索引與歷史紀錄，針對承諾、數字口徑、敘事變化取原文。optional 由待解問題選，不是清單有就全摘要；撤固定摘錄條數。 | 可能少發現未預期的語氣變化；首次研究及轉機／重大事件保留跨季讀取，取用舊摘要須驗版本與引句。 |
| B10．倉位%、starter、加減碼階梯、具名機會成本比較 | DD 保留適合買／等／不買、價格與證偽條件；已知持有或用戶要求執行計畫時再做完整 PM 工作。 | 不再每份附可直接照做的部位方案；既有 dca_role、條件式裁決及下游契約須有相容設計，不能靜默刪欄。 |

這些不是給所有公司設定更短研究上限。若新證據顯示問題重要，深挖的範圍可以大於舊模板；省的是無關或重複工作，不是預先限制洞見。

## 五、這輪提名撤除的「強制作業」，不是撤除思考

1. **§9 Pattern match 的「不得說無歷史可比」**：保留有用類比，但允許無可信可比；強迫找案例會引入牽強敘事。類比不是情境估值的必要證據。
2. **每篇逐字稿 ≥12 條摘要**：改驗重要訊息与跨季變化是否涵蓋，不以條數證明品質。
3. **每模組 reasoning 行數地板**：保留承重推導及來源；一行能完整表達不補成三行，複雜口徑也不被三行上限截斷。
4. **Max DD 必填具體發生時點及恢復年數**：保留下行情境與中途資金／流動性壓力；沒有足夠依據可標未知，不能為完成欄位生成精確時間。當前 max_dd 仍有下游依賴，需一併處理。
5. **以 byte 下限證明分析完整**：正式研究以證據與關鍵問題驗收，版面另驗。既有 110KB 是 legacy v13/v14 條款，不能拿它解釋目前所有快速版耗時；本輪也不以繞過 validator 的方式交付。
6. **同一結論在多份清單重答**：如反方論證／trap／風險故事／plain fears，保留不同實質視角，撤重複產文義務。

前三項較容易界定為輸出契約調整；第四項涉及風險估計可用性；所有項目仍須對齊驗收與資料契約，不是只有删條文字。

## 六、本輪不提名直接刪除的部分

- 關鍵一手數據、期間口徑、最新資訊、用戶筆記與證偽條件。
- 財務品質、競爭與供需、治理激勵、成長再投資、合理價格與下行風險。
- 對核心論點的最強反駁，以及「生意成功但股東報酬不好」的檢查。
- 負向證據的完整處置；重大問題未解決不可把「模型跑完」當「研究已通過」。
- 跨模型獨立審查。既有曾拿掉又恢復的事故紀錄在 rule ledger，本輪沒有證據支持再拿掉。
- 特殊公司換尺：金融、未獲利、循環、轉機不可為省事全套用一般複利股模板。

## 七、真正需要另外拍板的方法論

固定 Bear 機率地板、估值燈取較嚴、runway 切點、評分扣分、90 天承繼裁決、row 8a／8b 等，都不是單純排版規則。拿掉會改變投資裁決，不能以「流程優化」名義順便撤掉。

目前文本有明顯相依與歧義：decision-layer 的 row 8b 可越過部分 Soft Veto，judgment-rules §14 則強調矩陣 max-severity。這輪不混合兩套說法；若實作精簡，先以現行 dd_decision 的可測行為作相容基線，將文字歧義交指揮者裁決，不能自行改成比較順眼的答案。

row 8a 的 100%／150% 位置門檻明文凍結至 2026-10。這輪只提出後續審計需求，沒有撤銷凍結。其他判斷變更也須依 rule ledger 記錄理由、驗收與撤回條件。

## 八、精簡後的完成條件

一次研究完成，不是全部表格都填滿，而是：

1. 七個核心問題已回答，或重要的不可知被清楚界定。
2. 決策承重假設有來源、計算與反證處置；新增重要證據已反映。
3. 估值与情境沒有內部矛盾；價格問題與生意問題分得開。
4. 能清楚說明目前判斷、信心限制、什麼會改變主意。
5. 獨立審查沒有未解決的阻斷問題。

若重大缺料使判斷做不成，交「尚不能裁決及缺什麼」，不是硬湊一個完整 DD，也不是自動當成迴避。這需要現有發布狀態契約支援，不能直接映射為買賣 enum。

## 九、建議執行順序與撤回條件

**第一步，先做 A1–A5 與無實質資訊的輸出配額精簡。** 保留既有判斷與數字契約，驗相同輸入下結果、引文与重大風險無遺失。不要宣稱目前已機械化的功能是新省幅。

**第二步，核准 B 類的條件式研究契約。** 先試 TAM／分部模型／併購全史／optional 摘要四項；每項都說明為什麼本案不展開，保留重新展開的觸發。不是增加另一份長長的 N/A 報告。

**第三步，才審決策方法與 PM 邊界。** 與凍結條款、schema、下游顯示及消費端一起處理，不能先刪判斷輸入再假裝裁決不受影響。

試行撤回條件（提案、未登記）：同一證據快照盲審若發現，因被取消的必做項導致關鍵反證漏失、重要來源／口徑錯置，或應展開的重大問題未展開，先停止該項精簡並修正觸發；不等股價結果才承認流程漏查。方法變更造成有理據的分歧不自動判錯，也不能以「兩模型同意」當作正確。

記帳只需分開：研究新增證據、判斷輸出、審查、修補，以及總完成時間。首次研究和複審分開看。這輪不承諾分鐘或百分比；靜態檔案大小不是耗時。
