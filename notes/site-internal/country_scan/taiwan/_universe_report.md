# 台灣國家掃描 · 母體快照建構報告（Phase 0）

- **快照日期**：2026-08-14
- **母體檔案**：`_universe.json`
- **門檻**：市值 ≥ NT$100億（10,000,000,000 元）
- **範圍**：台灣證券交易所（TWSE，代碼加 `.TW`）＋ 證券櫃檯買賣中心（TPEx／上櫃，代碼加 `.TWO`）普通股

## 一、建構方法

1. **股票清單來源**：TWSE ISIN 一覽表（`isin.twse.com.tw/isin/C_public.jsp`），`strMode=2`（上市）與 `strMode=4`（上櫃／興櫃合頁），編碼 Big5/MS950，以 `<tr>`/`<td>` 結構解析。
2. **證券類型過濾**：每檔證券帶 ISIN CFI 分類碼；只取 `CFI = ESVUFR`（Equity・Shares・Voting・Freely transferable，即一般普通股），排除 ETF/ETN（CFI 首碼 `C`）、認購（售）權證（CFI 首碼 `R`）、特別股（CFI 次碼 `P`，如 `EPNRAR`）、存託憑證／TDR（CFI 次碼 `D`，如 `EDSDDR`）、債券（CFI 首碼 `D`）。
   - 上市頁原始列數 32,956（含全部權證／ETF／債券等），過濾後普通股 **1,084 檔**。
   - 上櫃頁原始列數 10,699，過濾後普通股 **890 檔**。
   - 兩者合計候選母體 **1,974 檔**。
3. **快照抓取（兩段式，避免對 Yahoo 429）**：
   - **第一段（bulk quote）**：用 yfinance 內部已取得的 crumb／cookie，直接呼叫 Yahoo `v7/finance/quote` 批次端點，每批 150 檔／一次請求（此端點支援多代碼合併查詢，非逐檔請求），共約 14 批，批間 sleep 1.5 秒。**1,974 檔全數成功、零失敗、零重試**。取得欄位：市值、現價、trailingPE/forwardPE、P/B、殖利率、52 週高低。
   - **第二段（逐檔 info，僅對通過市值篩選的 671 檔跑）**：`yfinance.Ticker(x).info`（quoteSummary 多模組合併請求），批次 ≤20 檔＋批間 sleep 3 秒＋單檔間 sleep 0.3 秒，失敗重試一次。取得欄位：sector/industry（Yahoo GICS 分類）、ROE、營收成長率、盈餘成長率、毛利率／營業利益率／淨利率、總負債、總現金、負債權益比。**671 檔全數成功、零硬失敗**（`phase3_failed.json` 為空陣列）。
   - 之所以先用 bulk quote 篩過一輪market cap再對縮小後的名單跑逐檔 info，是為了把最貴的逐檔請求量從 1,974 壓到 671，同時仍完整遵守「小批次＋sleep＋失敗重試一次」的 429 防護原則。
4. **市值篩選**：取第一段 `marketCap`（yfinance 對台股回傳單位為 TWD 原值，未做任何幣別轉換），篩 ≥ NT$100億進母體。

## 四、盲區自陳

1. **7 檔候選因 Yahoo 無市值資料被排除、未納入篩選判定**：`7855.TW`（和運租車，近期由上櫃轉上市）、`7803.TW`（雲象科技-創）、`7835.TW`（永悅健康-創）、`6907.TWO`（雅特力-KY，2026-01 新掛牌）、`6913.TWO`（鴻呈）、`7772.TWO`（耀穎）、`7794.TWO`（宏碩系統，興櫃轉上櫃新股）。這些多為近期新掛牌／新轉板個股，Yahoo 尚未回填市值計算所需的流通股數欄位。**其中是否有個股實際市值達 NT$100億門檻，本輪未逐一人工查證**，屬已知缺口而非刻意排除——若後續鏡頭子頁查到其中有需要收錄的名字（例如雅特力-KY 屬 IC 設計、股價已達 176 元且有相當成交量），應個別人工核實市值後再決定是否納入。
2. **上櫃（TPEx）在市值上明顯是配角**：158 檔上櫃合格股只佔母體總市值 5.42%，代表本母體的「發現力」高度集中在上市大型股；若鏡頭子頁的敘事需要「上櫃隱形冠軍」或「小型內需股」這類題材，母體內的上櫃樣本數（158 檔）雖不算少，但個別公司市值天花板低，用市值排序容易被上市股蓋過，寫作時需注意不要讓上櫃名字系統性被市值加權敘事排擠出局。
3. **興櫃股完全未涵蓋**：TWSE ISIN 頁的 `strMode=4` 對應「上櫃」，不含興櫃（Emerging Stock Market）掛牌股；若未來要做興櫃題材需另建母體，本快照不涵蓋。
4. **市值threshold 用的是 Yahoo bulk quote 的即時（近即時）報價 marketCap，非某一固定收盤日的官方市值**：抓取時間為 2026-08-14 台北時間約 23:00（`regularMarketTime` 顯示盤後延遲報價），與 TWSE/TPEx 官方當日收盤市值可能有極小幅落差（延遲約 20 分鐘的報價機制所致），但不影響 NT$100億這個粗篩門檻的判定穩健度。
5. **Yahoo sector/industry（GICS 式分類）與 TWSE 官方產業別偶有錯位**：本報告的產業統計一律採用**TWSE 官方 33 類產業別**（`twse_industry` 欄位）而非 Yahoo `sector`／`industry`（後者对台股常見「Basic Materials／Technology」等美式粗分類，顆粒度較粗且偶有誤判，如未做交叉驗證即採用可能誤導產業敘事）；`_universe.json` 中兩套欄位皆保留供子頁 writer 交叉比對，但**電子業佔比等結構性統計一律以 TWSE 官方分類為準**。
6. **獲利品質欄位（ROE、營收成長率、毛利率等）皆為 Yahoo `Ticker.info` 回傳的 trailing 或最新一期快照，未做多年期時間序列**——若鏡頭子頁（尤其複利機器、隱形冠軍鏡頭）需要「連續 N 年 ROE 門檻」這類量化篩選，母體 JSON 本身不夠用，寫作 agent 需自行對候選名單額外查詢財報歷史數據，不能只用本檔案的單期快照下結論。
7. **金融股（金控/銀行/壽險）的 ROE／P/B／負債權益比等一般製造業慣用指標，對金融業解讀意義不同**（金融業高槓桿是產業常態非風險訊號），金融鏡頭子頁需自行注意不要直接套用一般化的財務門檻判讀 34 檔金融保險業樣本。
