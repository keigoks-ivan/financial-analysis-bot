# id2：產業深度報告（ID）管線設計（2026-10-13，持有人當日核可，本輪只建＋乾跑一次）

入口：`python3.12 scripts/id2/run.py {Theme} [--dry-run] [--until STAGE] [--resume] [--refresh] [--publish]`
產物預設只寫 `.id_build/runs/{Theme}_{date}/`（gitignored），`--publish` 才寫 docs/。程式在 `scripts/id2/run.py`＋`prompts/`，仿 dd2、直接 import `dd_headless`／`dd2/spawn.py`，不改 dd2。

## 為什麼
v4 是一個 opus writer 跑 30–80 輪。①判斷錯誤寫完才被 critic 抓到，修補最貴（6–11M token）；②熱產業樂觀偏誤：shortage × Phase II 勝率 7/24；③估值與 priced-in 數字每次重搜、來源不一致；④writer 把 11,000–14,000 字當目標而灌水；⑤WebSearch 每 session 200 次上限，sub-agent 共用，批次中途死過。

## 流程（LLM 只在四處）
| 段 | 做什麼 | 模型 | 備註 |
|---|---|---|---|
| plan | 前版 id-meta／kill 表／分歧卡標題；priced-in 輸入（weekly_cache 26 週漲幅、dd-screener Fwd P/E 與 5Y 分位，附來源、as-of、離群旗）；`id_autopsy` 基準率表 | 零 LLM | 離群值（P/E ≤0 或 >100、漲幅 >150%、週線 >21 天未更新、不在母體）標 ⚠，不得當承重證據 |
| evidence | Axis A–E 各一通，平行，各自獨立 session（搜尋上限不共用）；輸出 JSON finding（url／as_of／tier）；程式驗 as_of 與來源、編號 A1…E9 | sonnet ×5 | 跨 run 快取 `.id_build/facts/{Theme}/`，TTL：A 180 天、B/C/E 30、D 14；`--refresh` 強制重抓 |
| judge | 單輪無工具，輸出判斷 JSON：id-meta、thesis、3–4 分歧卡（含替代威脅）、D2 資本週期、D3 雙閘、D4 TAM 三情境＋對帳、D8（用程式算好的輸入）、D9 kill 表、D10、D11、`base_rate` | opus，思考上限 32K；**同 prompt 平行三次**（2026-10-14） | 數字只能引證據編號或程式輸入；文字欄以要點為單位；sd_verdict／clock_phase 取多數，2:1 加 `*_boundary` 交界標記、頁面寫「第二／第三階段交界」，1:1:1 停下交人 |

| prose | 判斷 JSON → 白話 HTML，前半（summary～mechanics）與後半（valuation～appendix）平行；沿用 template 骨架與 `id-v4.css`；不得改數字 | sonnet ×2 | 不設字數目標；保留 ≤12 張表與 KB 上界警告 |

| publish | `--publish`：複製、INDEX.md 一行、跑既有發布腳本 | 零 LLM | 本輪未實跑；index.html 卡片仍需手動 |

## 配對測試協議（供持有人 go/no-go；本輪不跑）
1. 選一個待做主題 T（建議 shortage × II 前版，才測得到基準率義務）。
2. v4 側：依 `wip/id-refresh-20260905` 分支的 `notes/site-internal/id/_wip_id_refresh_20260905/playbook_id_v4.md`（用 `git show` 讀）跑到發布前，記 jsonl 全帳 token、牆鐘。
3. id2 側：同日跑 `run.py T`，並把 v4 側的採集證據包轉成 id2 的 `evidence/{A..E}.json` 格式放進 run dir 後 `--resume`（同證據比判斷與寫作，不比搜尋運氣）。
4. 兩份都跑 `check_id.py`，再各派一個 sonnet 跑 id-review v4 J1–J10（同一份 critic 提示、只餵 excerpt）。
5. 比較表：五格燈號（sd_verdict／clock_phase／conviction／priced_in／demand_5y_multiple）、critic 🔴/🟡 數、成本、牆鐘、基準率欄是否改變裁決。
6. 通過：sd_verdict 與 clock_phase 方向相同，或差異有證據記載；🔴 不多於 v4；成本低於 v4。三者缺一，不切換。
7. 另記：id2 的「HTML 出現但判斷 JSON 沒有的數字」清單長度（散文有沒有偷加數字）。
