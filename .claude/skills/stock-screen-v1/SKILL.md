# 個股大方向判斷 v1.2

**這是篩選器，接在 DD 之前，只回答一個問題：值不值得花時間做完整 DD？**

- 不回答「買不買」。⛔ 不做估值：不 DCF、不給目標價、不給評等，只做相對位置比較。
- ⛔ 不得用它否決趨勢訊號——樣本小的框架不干擾已驗證的系統。流動性不進評分（屬風險預算層）。
- 適用：打算抱過一個景氣循環的部位。不適用：短線交易。
- ⛔ 不給總分。總分會把致命的那一格平均掉，而致命格才是重點。
- ⛔ 不是收斂面：輸出不寫檔、不進 picks／GRP／三軌／dd-screener／cockpit 任何名單，不得被引用為「某檔在篩選器上是 ○」（2026-07-07 拍板不得再蓋收斂面；本層合規的唯一方式就是不落檔）。

## 觸發路由

| 用戶說 | 走哪支 |
|---|---|
| 裸 ticker、「這檔如何」「值不值得研究」「幫我看一下這家」「先篩一下 X」「X 快篩」「X 大方向」 | **本 skill** |
| 「{ticker} DD」「個股分析」「定見」「該不該進場」「買不買」「最終判斷」 | `stock-analyst`（不經 triage，直接全套） |
| 「全套」「ddreport {ticker}」 | `ddreport` |
| 2-5 檔橫向對比 → `multi-stock-comparator-v1`；產業結構 → `industry-analyst` | |

**跑四格之前，兩道前置閘**：

1. **事件驅動閘（v1.1）**：pending 併購／被收購／私有化／分拆下市／破產重整，任一為真 → 直接輸出「**框架不適用（事件驅動）**」，不跑四格——決定報酬的是案子過不過（對價、spread、核准路徑），不是四格。（生於 R1 ZIM：已簽約下市的公司被認真評了四格。）
2. **已有 DD 短路**：先 `ls docs/dd/DD_{TICKER}_*.html`。90 天內有 → 不跑，直接報 §14 裁決＋日期＋角色，問要不要重跑。>90 天 → 可跑，但**跑完四格才准讀那份 DD**（防錨定，比照 QC-52）；分岔是訊號，不是要對齊的錯誤。

判定「值得」→ 輸出結尾一律問「要跑 `ddreport {ticker}` 嗎」——路由判錯的代價是一行字，不是漏掉一份 DD。

## 四個問題

| | 問題 | 一句話判準 |
|---|---|---|
| **供給** | 對手能不能輕易做出一樣的東西？ | 複製要幾年／產能要不要來了 |
| **價格** | 我付的價格假設了什麼？ | 隱含成長 vs 做得到的成長 |
| **漏水** | 公司每賺一塊，多少最後屬於我？ | 稀釋 ＋ 再投資報酬 |
| **存續** | 十年後這門生意還在嗎？ | 寫得出最可能的死法 |

每格答 **○ 好／△ 普通／✗ 差**。✗ 的處置（v1.1 分軌）：

| 情況 | 處置 |
|---|---|
| **產能週期型 × 供給 ✗**，或**兩格以上 ✗** | **停**。判「不值得」，不列待查事項 |
| 其餘單格 ✗ | **值得，但 DD 必須先回答這一格**——待查事項第 1 項強制寫成該格的問句 |

一格 ✗ 是「有個必須先答的問題」，不是「不能碰」；只有產能週期股的供給側崩壞不可回復，才值得一票否決。（生於 R1 兩個假陰性 TXN／3017.TW。）

## 先問 archetype，再選尺規（不得跳過）

**判定軸（v1.1）＝這門生意的價格由誰的產能決定——這家公司自己的，還是整個產業的？** 比率（capex/營收 5 年均值 ≥ 15% 且 PP&E/總資產 ≥ 30%）只當初篩，必須用這一句覆核；覆核不過就改判並在輸出註明理由。（R1 純比率誤分率 40%；三種誤分模式——租賃營運商／準獨佔重資產廠／低資本密度製造業——實例見審計檔。）

| Archetype | 判定 | 供給格問什麼 |
|---|---|---|
| **產能週期型** | 價格由產業層產能決定，且產能可在數年內大增（航運、記憶體、晶圓、礦業、電力、煉油、航空、太陽能） | 未來三年產能會不會湧出來 |
| **輕資產型** | 邊際供給成本趨近零，供給限制是無形的（軟體、品牌、平台、交易所） | 對手要複製需要多久 |
| **中間型** | 有實體產能，同時有非產能的供給限制（製程領先、料號廣度、客戶認證） | 兩者都問，取差的 |

底層是同一個問題——這家公司賣的東西，價格會不會被競爭掉——循環股用產能數字答，輕資產用護城河答。不分型就評分會給所有循環股 ✗，而產能週期底部正是最好的機會之一。

## ① 供給：價格會不會被競爭掉？

### 產能週期型——問產能，不問護城河

前瞻供給指標（公開、可查、領先期以年計；R1 命中率 5/5）：

| 產業 | 指標 | 領先期 |
|---|---|---|
| 航運／油輪 | **手持訂單佔現有船隊比** | 2–3 年 |
| 記憶體 | 三大廠 bit supply guidance、capex | 1.5–2 年 |
| 晶圓／半導體 | 新廠動工、WFE 支出 | 2–3 年 |
| 礦業 | 專案 pipeline、FID 決策 | 5–10 年 |
| 電力／資料中心 | **併網排隊** | 1–4 年 |
| 煉油／石化 | 宣告新增與關閉產能 | 3–4 年 |
| 航空 | 飛機訂單簿 | 2–5 年 |

○ 訂單簿／pipeline 歷史低檔　│　△ 中性　│　✗ 產能正在大量興建

**判 ✗ 前的強制次問句（v1.1）：產能在增，但增的是誰的？** 新增產能中該公司佔比高於現有市佔 → 那是份額擴張不是價格被競爭掉，**最高 △ 不得 ✗**，並一句寫明憑什麼（成本位置／認證／客戶指定）；低於或答不出 → 維持 ✗。只放寬、不收緊。（生於 R1 假陰性：TXN 增的是自己成本領先的 300mm，3017.TW 增的產能對應新拿的客戶份額。）

- 指標查不到就輸出「需補資料」，**不得用需求側數字（營收成長、稼動率、毛利率）代打**——那正是這格要防的東西。
- **產能在收縮不等於供給好**：收縮因需求消失（結構衰退品類）→ 照樣 ✗，品類問題進存續格。（R1 M 案例。）
- 手持訂單佔船隊比就是這個產業的建照核發戶數——運價暴漲時沒有人在看訂單簿。

### 輕資產型——問護城河，必須寫得出機制

對手要複製這門生意需要多久：○ ≥ 5 年（法規牌照、專利、實體產能、深度網路效應、高轉換成本）│ △ 2–5 年│ ✗ < 2 年

⛔ **禁令 1：不准用財務比率當護城河證據。** 毛利率高、ROIC 高是護城河的**結果**，拿結果當證明＝循環論證。必須用文字寫出機制——哪一張執照、哪一個專利、哪一種轉換成本、哪一個網路效應；寫不出來 → 供給格封頂 △。標 ○ 必須註明機制的可驗證程度——**無形的供給限制可以一夜消失**。

## ② 價格：我付的價格假設了什麼？

只做相對比較：倍數在**自身歷史區間的百分位**、相對同業溢價折價、隱含成長 vs 這門生意實際做得到的成長。

○ 低於自身中位且隱含成長低於可達成　│　△ 中段　│　✗ 接近區間高點，或隱含成長明顯過高

成長不獨立成格，它是價格的參照系——PE 30 對零成長是貴、對持續 30% 成長是便宜；**零成長的好生意用便宜價格買，完全可以**。（R1 實證：自身百分位判準三次推翻絕對倍數直覺——MA 第 5 百分位、ADBE 第 2、M 絕對 11 倍但自身 75。本輪表現最好的單一規則。）

產能週期型另看象限：

| | 需求強 | 需求弱 |
|---|---|---|
| **供給緊** | 雙引擎（貴） | **蓄壓（最佳）** |
| **供給鬆** | **假多頭（最危險）** | 雙殺 |

假多頭＝營收、EPS、動能、股價全創新高**而產能在蓋還沒交貨**（航運 2021–22、鋰 2022、太陽能 2021–23、記憶體歷次高點）。這格的股票在趨勢與品質篩選上會是完美多頭訊號——不是選股系統的錯，趨勢系統依定義只讀需求側軌跡，讀不到訂單簿。

## ③ 漏水：公司每賺一塊，多少最後屬於我？

房子不會把你的錢拿去亂投資，公司會。三種漏法：

- **A 稀釋**：淨股數 CAGR，取可得最長年限（最低 3 年）並註明年數（v1.1；免費源實得 3 年，別假裝有五年）。**SBC 扣掉回購後仍為正 → 帳面回購再大也是漏的**（看淨股數不看回購金額）。非美股股數增加要拆成因，拆不出就寫「成因未拆分」。
- **B 再投資報酬**：（ROIC − 資金成本）× 再投資比率——**看組合不看 ROIC 本身**。高 ROIC 沒機會就還錢不是缺點，低 ROIC 又一直投才是。
- **C 偽裝成成長的維持性 capex**：帳列成長型，實際是維持競爭地位所必需。

○ 股數在減 ＋ ROIC 明顯高於資金成本　│　△ 其中一項普通　│　✗ 持續稀釋，或長期把大量資金投在低於資金成本的地方

⛔ **禁令 2：ROIC 不准算兩次。** 供給格用機制（文字），漏水格用 ROIC × 再投資比率（數字）；同一事實不得跨格。

## ④ 存續：十年後這門生意還在嗎？

**如果十年後它不在了，最可能的死法是什麼？** 寫不出來＝功課沒做完，不是安全；寫得出且正在發生 → ✗；寫得出但需要現在不存在的條件 → ○。

兩層都要問：**品類存續**（還有沒有人要——技術替代、法規、習慣）與**個體存續**（撐不撐得過低谷——槓桿、再融資、契約條款）。循環股的死法通常不是品類消失，是低谷被槓桿殺死——品類 ○ 不代表個體 ○。

## 三個危險組合（兩格看似相關，實可反向）

- **供給 ○ ＋ 存續 ✗**：柯達在底片上的護城河到最後一天都完好——護城河擋同業，擋不了品類被消滅。不因供給 ○ 跳過存續格。
- **價格 ○ ＋ 漏水 ✗**：便宜是因為一直稀釋——倍數低不是折價，是市場把稀釋算進去了。
- **漏水 ○ ＋ 供給 ✗**：在被競爭掉的生意裡回購——股數在減，每股背後的東西也在減。
