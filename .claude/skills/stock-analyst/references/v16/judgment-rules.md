## 0｜北極星(v15.0拍板)

目標＝找到真值得長期投資的公司：獲利好且獲利品質好(能變現金、不靠會計調整/稀釋撐)；ROIC好且**持續期長**、增量資本仍能相近報酬再投入；產業結構與護城河都好——好價格是加分。**生意決定買不買，價格決定何時買**：好生意貴價格＝觀望+rearm等價格；爛生意便宜＝不買。第一問＝是不是好生意(產業/商模/護城河/成長/財務品質)；第二問＝價格好不好(估值，加分項非前提)。此為敘事重心憲法非新裁決閘。

**身份**：買側資深分析師+PM決策層，林區(一句話說清為何買)×蒙格(反過來想+多學科交叉驗證)×巴菲特(護城河永恆，只在好價格買好公司)。估值核心任務＝判斷股價隱含什麼預期，非預測未來值多少；低估值訊號須觸發反向驗證(錯誤定價vs已提前定價惡化)；產出＝可執行決策主線(A發生做X，B發生做Y)。**分工**：倉位%由portfolio-manager組合層決定；`decision_out`只給倉位角色+初始/目標區間+opportunity cost作PM輸入，不拍板組合佔比。(QC-11)

## 2｜§4 Munger門檻檢核(品質複利成長預設尺)

| 項目 | 標準 |
|:---|:---|
| FCF Margin(當前) | > 15% |
| 正規化FCF Margin | 5年均值>15%；單年最低谷>10% |
| ROIC(當前) | > 15%，且高於WACC |
| ROIC穩定性 | 過去10年≥70%年份ROIC>15% |
| 毛利率定價能力 | 過去10年≥70%年份毛利率持續改善 |
| 資本密集度 | Capex/Revenue<5%(優)／<10%(尚可) |
| EPS CAGR(未來3年) | > 20%(高成長)**或**12-20%且runway≥10Y高durability(明標「非高成長股，靠長runway複利達標」) |
| PEG(Non-GAAP) | **< 1.0便宜／1-2合理／> 2貴** |
| 負債安全性 | D/E<0.7；現金/Revenue 10~50% |
| 現金覆蓋總負債 | 是／否 |
| 護城河強度 | > 8分，趨勢擴大 |

**Munger三維快速評級**(ROIC穩定性+毛利率定價能力+資本密集度)：🟢三項全達標／🟡兩項達標(須說明哪維偏弱)／🔴一項或以下(護城河需強力反駁或重新評分)。另填一句最大財務弱點；三維評級傳遞至§5作定量起點。10年數據取不到→5年替代並備注「5年樣本」。價值陷阱判斷統一在§1 trap處理，本節不另設低估值四問。

**EPS CAGR口徑**：基期EPS(GAAP)/FY+1E/FY+2E/FY+3E各標來源與分析師家數；GAAP CAGR=(FY+3E÷基期)^(1/3)−1，Non-GAAP同理；說明GAAP/Non-GAAP差距來源(SBC/重組/攤銷)，台股標「不適用(法定口徑)」。**FY+3禁機械外推**：依①Runway判斷3年後成長階段②定價vs量貢獻是否遞減③(ROIC×再投資率)內生上限④給FY+3 YoY具體值+一句邏輯依據⑤FY+3E=FY+2E×(1+g)。**禁**「FY+2 growth×0.7」這類公式。

**§4.G商業模式解剖(必填三件套)**：①**單位經濟學**——「一單位」是什麼，價格×數量×單位成本×單位毛利近3年怎麼走；②**價值鏈位置+單點依賴**——誰付錢給它、它付錢給誰、議價權卡在哪個節點；證據包供應鏈位置清單含⚑單點旗標(鎖喉點/客戶獨家/近乎獨佔)者一體兩面必答：作護城河證據或集中度風險；③**營收品質拆解**——recurring vs一次性佔比、量vs價driven、合約長度/解約成本，與§10倍數、§6.B成長品質判分口徑一致。

## 3｜§3產業格局判斷

**產業時鐘位置**(必答一格，全archetype，落`industry.clock_phase`)：Phase I復甦／II擴張／III過熱／IV收縮。有canonical ID→引其`clock_phase`(**Phase II依QC-52打折**：須經自身位置閘交叉驗證後才可載入)；無ID→自判並給一句依據(capex週期位置/庫存/訂單動能，非股價)。與循環股自身`cycle_position`分工：那是個股循環位置，本欄是產業層時鐘。

**議價權三段**(各獨立判斷)：①對上游——供應商集中度/替代難度/近3年議價案例，top3>70%須列主要供應商+占比+切換成本。②對下游——客戶集中度如何影響議價地位、合約結構(長期/訂單型/spot)、近3年流失case、定價證據(提價後留存率/漲價條款比例)。③地緣曝險——核心生產地與占比/供應鏈最高集中點/政策風險路徑/分散化措施。

**供需durability裁決**(QC-39閘B，供需驅動標的必填一句)：當前供需失衡是結構性還是週期性？能撐多久？須引用`coverage.supply_demand_durability`sourced證據，裁決三選一：**結構性持久／週期性將反轉／供給可逆性高(緊缺脆弱，下行更猛)**，直接餵成長熄火normalized假設與情境樹bear機率。禁止只用當下狀態下結論而不判durability。

**單位經濟mix-shift**(必填一行)：以各段當前成長率外推3年，合併OI margin結構性**±__bp/yr**；與§6.B③增量利潤率互為驗證，差距>100bp須解釋(capex前置/一次性)，無法解釋→兩處重算。

**§3.F逐段TAM/SAM+利潤池**(E3)：每段給TAM(現/5Y)｜SAM｜滲透率｜段CAGR｜價值鏈位置｜OI池占比5年前→現｜流向，每段一句「成長天花板與被替代路徑」。取不到完整池→用「龍頭OI margin×環節營收」代理並明標「代理估算」。**硬接線**：本標的環節OI池占比5年**淨流出≥5pp**→§6.A Runway評級自動降一檔，且QC-39三軸裁決不得標「結構性轉好」；淨流入→可作估值燈盲點1救援佐證。↓流出=量增利不增警示，餵入持有年限。

## 4｜§5護城河(判斷核心)

**二維拆解**(default)：execution moat+pricing power moat，各1-10分，合併分取均值或加權。**Single-axis escape**：SaaS/銀行/保險/寡占公用事業允許「綜合分+narrative」，須明標"single-axis"並寫為何不適合二維。等級對映：10=S，9=A，7-8=B，5-6=C，<5=拒絕。

**護城河來源須sourced**：網路效應=規模閾值；無形資產=具體IP/專利數量/牌照年期；轉換成本=換供應商CapEx/時間/流程重建；規模優勢=unit cost差距、對手需多大規模追上。競爭鴻溝須給機制(時間壁壘/資本壁壘/認證壁壘，至少2個)。

**QC-23競爭威脅三級**：🟡點對點(單一產品vs單一產品)不扣分；🔴生態攻擊(對手推全棧方案/聯盟/多代合約綁定)**−1分**；⛔架構替代(客戶架構層級切換)**−2分**，thesis重評。新進入者打進top-3客戶/program一律列入。

**護城河三道數字閘**(§5結尾一行匯總)：**閘一**(Moat-to-Numbers硬gate)——合併分≥8須ROIC對最強直接同業spread為正且擴大或持平；連2年收窄仍打≥8→須具體反駁，不成立則合併分強制−1。**閘二**(QC-26 Margin結構性測試)——毛利率YoY下滑>1.5pp必做3項對照(同業同期趨勢/產品組合mix/同業相似技術margin)：同業擴張本標的下滑=結構性質變護城河−0.5分；全產業同步下滑=週期性不扣分；一次性稀釋=記錄「管理層承諾recover」列入監測。**閘三**(QC-28絕對vs相對成長)——有明確可比對手須同時呈現營收YoY%、絕對美元新增(季)、份額變化，**對手絕對美元新增≥本標的90%**→觸發「規模優勢質變」警示，護城河評分重審。

**賽局結構判定**(必填≤80字)：理性寡占/紀律鬆動/破壞性競爭，附sourced證據(上一輪下行的實際價格行為：守價/跟跌/主動降價)。**硬接線**：存在「結構性成本更低+FCF足以攻擊+承受力高」對手→pricing power分數**上限7**；破壞性競爭→威脅機率**下限30%**且成長熄火壓測須含「ASP戰」；理性寡占+sourced守價證據→可作pricing power高分佐證。

**定價事件帳**(pricing power唯一資料源)：近3年≤3個事件，日期｜提價幅度｜量與留存反應｜其後2季GM反應，是§6.B②、§3議價權下游、衰退信號、護城河「已實現價格溢價」的唯一來源，其餘一行引用不重抓。

**§5.F對手財務深度對照(E6)**：top 2-3直接對手(C可為新進)的營收成長/GM/OM/R&D強度/FCF Margin/淨現金・淨債；每家一段策略與經濟體質判斷→接賽局判定，新進入者須單獨成段。

### moat_trend(權威趨勢線，餵`moat.trend`)
Execution與Pricing Power趨勢各自獨立評估(擴大/穩定/縮減，各附3年關鍵事件)，彙整**單一權威`moat_trend`↑widening／→holding／↓narrowing**，**必附≥1個12個月內sourced data point**。**禁止寫「持平」逃避**——須選邊↑/→/↓、單一Unicode箭頭；皆擴大→↑，一擴一縮→取對thesis更關鍵維度並說明，皆縮減→↓；須前瞻(未來2-3年份額走向，引QC-39前瞻軌跡)。

**🔴QC-39閘A(防過度樂觀，硬性)**：領先玩家在最大客戶/program份額下滑(sourced)→**moat_trend不得標↑**(最多→，可↓)。例外須sourced反證且通過自我攻擊，否則一律降。
**硬接線**：**moat_trend=↓且moat等級≤B→決策矩陣Hard Veto(迴避)**(由`dd_decision.py`機械執行；本層只負責誠實給出`moat.trend`與`moat.grade`)。

### §5.R報酬持續期檢核(ROIC durability；寫前必Read `references/roic-durability.md`)

1. **當期ROIC定位**：稅後營業利益率×投入資本周轉率(直引§7.E DuPont不重算)→四象限歸位+一句敘述。低利益率×高周轉易誤判爛生意(配銷商型，先查CCC結構)；高利益率×低周轉要看再投資負擔。
2. **持續期四檢查點**(判定🟢🟡🔴+sourced證據+代理變數讀數；與QC-39軸B共用證據，不另起搜尋)：需求基礎值(客戶為何買——使用者/決策者/付款者先分開，急迫性≠持久性)／決策層級(哪一層選擇——代理變數：漲價後流失率、續約率、資料遷移時間)／價值鏈分配(利益留誰——最難取代環節；互補品收斂單一供應失定價空間)／社會容忍度(讓你收多久——必要性×政治敏感度=天花板取較小上限者，依賴監管者須寫法源、修法程序、替代方案)。
3. **再投資空間**：**內生成長率=增量ROIC×再投資率**(增量非存量)，與§6.D內生天花板對齊並寫`moat.roic_durability.endo_ceiling`。高ROIC×低再投資空間→明寫「價值主要來自既有現金流，複利貢獻有限」。**再投資率口徑**：`(Capex−D&A+ΔWC+收購淨額)÷NOPAT`。**負CCC業務**(ΔWC結構性為負)標準公式失效——改以**ROIIC為內生成長上界**，`formula_note`明寫「負CCC，改採ROIIC上界」。
**接線**：四檢查點結論是moat_trend與Runway的證據輸入之一；**社會容忍度🔴須出現在§12死法清單**。

## 5｜§6長期成長性

**成長品質7問**(每題一句裁決+關鍵數字+詳見章節)：①結構性還週期反彈？②需多少資本投入？③增量ROIC是否>資金成本？④成長變現金流還是被下輪擴張吃掉？⑤競爭者會否被吸引進來？⑥股價反映多少期待？⑦成長率下修估值撐得住嗎？須標「最弱的一題」，與trap定性+最終裁決一致。

**A｜Runway**：當前TAM(標年份)/可達TAM/當前市佔・滲透率/維持現有成長率幾年達30%滲透率/**Runway=__年**。**≥10年**=高確信支撐高溢價；**5~9年**=中等可見度估值折扣；**<5年**=短期成長股倍數保守，須有下一條成長曲線論述。

## 9｜情境樹與不對稱報酬(`scenario.json`；機率是判斷，算術歸 `dd_scenario.py`)

**情境樹年期硬規則**：①表頭終端年須=主時距終端年；②終端倍數EPS分母年期須與現價倍數同源；③終端倍數必附≥1個同業現值comp對照(高於同業最高者須具體理由)。

## 12｜§11矛盾辨識與強制裁決(`contradictions[]`；四區塊)

1. **共識清單**——列方向一致的判斷。**矛盾拓撲判定(必答一句)**：爭議集中單一軸還是瀰漫多處？集中→點名該軸，監測向其收斂；瀰漫→資料品質存疑，信心整體下修。

**4b裁決推理品質三檢(強制，每項須實答非宣告已檢查)**：①**分母爭議檢查**——引用「估值便宜」先檢查便宜的**分母**(forward EPS／FY+2 FCF／轉正年估計)是否本身即本章爭點？**是→該便宜論證無效**，須明文並設`decision_inputs.val_denominator_disputed=true`。②**證據權重三級制**：**L1已實現事實**(財報、已簽合約、信用市場定價)>**L2 sourced前瞻估計**(共識、管理層指引)>**L3敘事**(賣方觀點、傳聞)。裁決預設站L1較高側；以L2/L3反駁L1須明寫理由。③**Steelman義務(方向對稱)**：裁決為觀望/迴避→先寫「現在就買的最強論證」(3-5句，用本報告自己的數字)再逐點回應；裁決為進場→寫「現在就賣/不買的最強論證」並逐點回應。**回應只覆述原立場＝裁決不成立，重寫。**

### `triggers[]`(E12監測與觸發器，唯一居所)
每列：`n`/`text`/`type`/`maps_to`/`metric`/`threshold`/`action`/`source_freq`/`date`。**type enum**：假設驗證(H1–H3)/風險(R1–R3)/Single Thing/估值rearm/加碼/減碼/清倉/複審日期。**action enum**：加碼至…/減碼至…/清倉/重跑DD/進場首倉/維持觀望/trim回目標倉位。`date`欄填具體日期者即複審日期(**至少一列必須有date**)。**同源**：`kill_metrics[]`＝「減碼/清倉/風險」列；`rearm_trigger`＝「估值rearm/進場首倉」列；`catalysts[]`為獨立居所。假設/風險/觸發器內容**只在此一處**，其餘章節一律引用。

**§2假設與風險(`thesis`)**：持有期宣告——預設持有期/主要驅動理由，決定哪些變數是訊號哪些是噪音(<6個月：財報newsflow權重高；>2年：護城河趨勢與ROIC方向為主)。**H1/H2/H3**：每假設在2Y/5Y/10Y各有可驗證指標，**須含**①具體數字門檻②信息來源③漂移觸發條件，**禁止從上一份報告延用**。**QC-35漂移分級**：2Y假設連2季TTM偏離**≥5%**削弱/連3季**≥10%**反轉；5Y假設連4季≥5%削弱/連6季≥10%反轉；10Y假設跨2年度持續偏離削弱/跨3年度反轉(**僅標示狀態，不直接觸發動作**)。**QC-34季節性過濾**：一律用TTM或年度數據，禁單季snapshot(最新季可用但不可用於漂移判定)。**R1/R2/R3**：風險｜對應H__｜時間尺度｜監測閾值。**⚡短期**(1-2季，連2季即減倉)/**🔥中期**(4-6季，連4季才大動作)/**🐢長期**(2+年，需≥50%機率才砍倉)；禁binary discrete event(那是Single Thing職責)。**Single Thing**：1個明確、可觀測、binary discrete event，五格(描述/為什麼致命/如果發生/如何監測/機率估計12-24個月)，全報告唯一居所。**三者職責**：trap定性=靜態裁決；R1-R3=持有期過程性風險；Single Thing=單一未來specific moment。**邊際貢獻框架**：新事件問①時間軸匹配②假設關聯③邊際方向④閾值，不影響任何假設不改變估值分位＝噪音不需行動。
