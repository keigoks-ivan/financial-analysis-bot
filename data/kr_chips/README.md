# 韓股籌碼資料庫（data/kr_chips/）

韓國股市「籌碼」的長期共用資料：KOSPI 與 KOSDAQ 的指數與成交金額、上市總市值、外國人持股、外國人／機構／個人買賣超、投資人預託金、信用交易融資、借券餘額、韓元匯率。全部是日頻。網頁 `/kr-chips/` 與回測都讀這裡的資料。

**沒有包含**的項目：放空餘額與放空成交、KOSPI200 期貨與選擇權的投資人別部位、VKOSPI。韓國交易所（KRX）的資料平台 data.krx.co.kr 已全面要求登入（2026-10-17 實測所有資料端點回「LOGOUT」），這三項只有 KRX 提供，需要 KRX 會員帳號才能取得，暫未提供。

## 目錄結構

| 路徑 | 內容 |
|---|---|
| `{series}.jsonl` | 原始存檔，一天一行，鍵 `d`（YYYY-MM-DD）。**保留來源原單位**，欄位名是短名（下面逐一解釋）。這是唯一的真相來源。 |
| `csv/{series}.csv` | 由 jsonl 扁平化而來，一天一列，第一欄 `date`，欄名是英文全名，供 pandas 直接讀。每次 `build.py` 重新產生，不要手改。 |
| `_state.json` | 抓取進度：`gaps`（某天查無資料的嘗試次數，滿 3 次且超過 5 天就不再重抓）。 |
| `README.md` | 本檔。 |

jsonl 與 csv 一一對應：`kospi`、`kosdaq`、`px_kospi`、`px_kosdaq`、`inst_kospi`、`inst_kosdaq`、`deposit`、`credit`、`lend`、`usdkrw`。

## 單位約定

- **百萬韓元**（`*_million_krw`）：KOFIA 的原始單位。
- **億韓元**（`*_100m_krw`）：1 億 = 1e8 韓元。百萬韓元 → 億韓元 ÷ 100，四捨五入到小數 2 位。例：投資人預託金 2026-10-14 為 97,428,012 百萬韓元 = 974,280.12 億韓元 = 97 兆 4280 億韓元。Naver 的買賣超原本就是億韓元，不換算。
- **股**（`*_shares`）：成交量與借券的股數。
- **%**（`*_pct`）：百分比，100 表示 100%。
- **點**：指數。

買賣超一律是**買進減賣出**，正數＝買超。

## 更新方式

- 日常：`python3 scripts/kr_chips/fetch.py`（只抓缺的日子），再 `python3 scripts/kr_chips/build.py`（產生 `docs/kr-chips/data/*.json` 與 `csv/`）。
- GitHub Actions：`.github/workflows/kr-chips-daily.yml`，週一至週五台北 16:37，隔天 09:17 備援。
- 回補：`python3 scripts/kr_chips/fetch.py --backfill`（全歷史，可續跑；2026-10-17 實測全程約 30 分鐘，其中逐日的買賣超與借券各約 20 分鐘）。
- jsonl 是 append-only：同一天內容沒變就不寫，有修正就在檔尾加一行，讀入時以**同日最後一行為準**。回補完成後會整理成依日期排序、每日一行。
- 交易日曆＝KOFIA KOSPI 有收盤的日子，加上 Naver KOSPI 有 K 線的日子（Naver 當天就有，KOFIA 約晚一個交易日）。休市日沒有任何序列的資料，也不會被當成缺口。
- 副本同步到 `~/v7-backtest/data/korea_chips/`：`python3 scripts/kr_chips/sync_to_v7.py`。

## 來源與核對方式

KOFIA 金融投資協會 FreeSIS（freesis.kofia.or.kr）的端點 `POST https://freesis.kofia.or.kr/meta/getMetaDataList.do`，免登入、免 key，請求本文是 JSON：`{"dmSearch":{"tmpV40":"1000000","tmpV41":"1","tmpV1":"D","tmpV45":起日YYYYMMDD,"tmpV46":迄日YYYYMMDD,"OBJ_NM":統計代號}}`，回傳 `ds1` 列表，欄位名一律 `TMPV1`（日期）、`TMPV2`…。**欄位沒有名稱**，下面各節的標籤是用韓國媒體報導的數字逐項對出來的，沒對到的欄位在表裡明說「未核對」。單次請求可抓整段歷史（約 7,000 列 0.6 秒）；借券是逐日請求（一天約 2,800 列）。

Naver 行動版 API（m.stock.naver.com/api/index）：免登入、免 key，是 Naver 證券頁面使用的公開資料，**不是交易所原表**。

## kospi、kosdaq — 指數收盤、成交金額、上市總市值、外國人持股

- 來源：KOFIA `STATSCU0100000020BO`（KOSPI）、`STATSCU0100000030BO`（KOSDAQ）
- 最早日：KOSPI 1998-01-03；KOSDAQ 2000-11-06
- 缺口：KOFIA 在這些日子沒有資料（逐日請求也回空），Naver 有K線：KOSPI 2016-10-13、2017-03-03、2020-01-02、2020-02-21、2020-06-18、2020-11-19、2020-12-24、2021-03-17、2021-05-27、2021-06-08、2021-06-25、2021-07-09、2024-08-30、2024-09-13；KOSDAQ 2016-10-13、2017-03-03、2020-05-26、2020-08-25、2020-10-26、2021-01-28、2021-05-27、2021-06-08、2021-06-25、2021-07-09、2024-08-30、2024-09-13。頁面這些日子的成交金額、市值留白，不補數字。
- 時效：KOFIA 通常晚一個交易日公布（2026-10-17 週六查，最新是 10-15，10-16 還沒有）。

| jsonl 欄位 | csv 欄名 | 說明 | 單位 |
|---|---|---|---|
| `d` | `date` | 交易日 | |
| `c` | `close` | 收盤指數 | 點 |
| `vol` | `volume_shares` | 成交量 | 股 |
| `amt` | `turnover_million_krw`、`turnover_100m_krw` | 成交金額 | 百萬韓元、億韓元 |
| `mcap` | `market_cap_million_krw`、`market_cap_100m_krw` | 上市總市值 | 百萬韓元、億韓元 |
| `fmcap` | `foreign_holding_cap_million_krw`、`foreign_holding_cap_100m_krw` | 外國人持股市值 | 百萬韓元、億韓元 |
| `fpct` | `foreign_holding_pct` | 外國人持股比重 | % |

核對：
- 收盤指數與 Naver 的收盤逐日比對，重疊期間只有 1 日不同（KOSDAQ 2001-11-01，KOFIA 636.4、Naver 625.5），2016 年以後完全一致。
- 上市總市值：2026-08-13 KOFIA 的 KOSPI 5,619.05 兆、KOSDAQ 474.86 兆，與韓國媒體引用的交易所數字（5619 兆 0520 億、474 兆 8560 億）相符。
- 成交量單位是股（KOSPI 2026-10-15 為 385,805,100 股），不是千股。
- 外國人持股比重 ＝ 外國人持股市值 ÷ 上市總市值（KOSPI 2026-10-15 為 38.19%），內部一致。
- 成交金額未與外部報導逐日核對。

## inst_kospi、inst_kosdaq — 外國人、機構、個人買賣超

## lend — 借券餘額（全市場合計）

- 來源：KOFIA `STATSCU0100000180BO`，逐日請求，取名稱為「합계」的那一列（`130BO` 是同一份逐檔資料但沒有合計列）。
- 最早日：2009-01-02（2008 年及以前回傳 0 列）
- 缺口：2016-10 以後沒有缺日。2009-01-05、2012-01-03、2013-01-03 三個年初交易日單日變動超過 12%，疑為涵蓋檔數更新，原因未查明。
- 只有全市場合計，含 ETF、ETN，**沒有分 KOSPI／KOSDAQ**（逐檔列沒有市場欄）。頁面的佔比用 KOSPI＋KOSDAQ 上市總市值當分母，只適合看趨勢。
- 時效：KOFIA 這個統計的更新比指數統計早（2026-10-17 查，借券已有 10-16，指數統計還沒有）。
- 2023-11-06 至 2025-03-30 為全面禁止放空期間（2025-03-31 恢復）。期間餘額由禁令前一日（2023-11-03）的 81.98 兆降到 2024-08-05 的 45.58 兆，2025-03-31 為 65.69 兆。

## usdkrw — 韓元兌美元

- 來源：FRED `https://fred.stlouisfed.org/graph/fredgraph.csv?id=DEXKOUS`（聖路易聯邦準備銀行，H.10 日資料，紐約中午買入價）
- 最早日：1981-04-13
- 缺口：美國休市日沒有資料，頁面沿用前一營業日（最多連補 5 天）；FRED 約晚一週更新，最新日之後不補。2016-10 以後有 91 個交易日（多為美國休市日）本身沒有值。

| jsonl 欄位 | csv 欄名 | 說明 | 單位 |
|---|---|---|---|
| `v` | `usdkrw` | 1 美元兌韓元 | 韓元 |
